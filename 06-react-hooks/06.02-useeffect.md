### Syntax
```jsx
useEffect(() => {
  // side effect
  return () => {
    // cleanup (optional)
  };
}, [dependencies]);
```

### Dependency Array Behavior

| Array | When it runs |
|-------|-------------|
| No array | After every render |
| `[]` | Once after mount (and cleanup on unmount) |
| `[a, b]` | When `a` or `b` changes (Object.is comparison) |

### Common Patterns

```jsx
// 1. Mount only
useEffect(() => {
  console.log('Mounted');
  return () => console.log('Unmounted');
}, []);

// 2. React to prop/state change
useEffect(() => {
  console.log('User id changed:', userId);
}, [userId]);

// 3. Subscription with cleanup
useEffect(() => {
  const sub = store.subscribe(handleChange);
  return () => sub.unsubscribe();
}, []);

// 4. Timer
useEffect(() => {
  const id = setInterval(() => setTime(Date.now()), 1000);
  return () => clearInterval(id);
}, []);

// 5. Fetch with abort
useEffect(() => {
  const controller = new AbortController();

  fetch(`/api/users/${userId}`, { signal: controller.signal })
    .then(r => r.json())
    .then(setUser)
    .catch(err => {
      if (err.name !== 'AbortError') setError(err);
    });

  return () => controller.abort();
}, [userId]);

// 6. DOM manipulation
useEffect(() => {
  document.title = `${title} | My App`;
}, [title]);
```

### Cleanup Function
Runs:
- Before the next effect (when deps change)
- Before unmount

```jsx
useEffect(() => {
  console.log('Effect runs');

  return () => {
    console.log('Cleanup runs before next effect or unmount');
  };
}, [dep]);
```

### Race Condition Example
```jsx
// ❌ Race condition - old request may resolve after new one
useEffect(() => {
  fetch(`/api/search?q=${query}`)
    .then(r => r.json())
    .then(setResults);
}, [query]);

// Type "a" → "ab":
// "ab" request may resolve before "a" → wrong results shown

// ✅ Cancel previous request
useEffect(() => {
  const controller = new AbortController();

  fetch(`/api/search?q=${query}`, { signal: controller.signal })
    .then(r => r.json())
    .then(setResults)
    .catch(err => {
      if (err.name !== 'AbortError') setError(err);
    });

  return () => controller.abort();
}, [query]);

// ✅ Or use a cancelled flag
useEffect(() => {
  let cancelled = false;

  fetch(`/api/search?q=${query}`)
    .then(r => r.json())
    .then(data => {
      if (!cancelled) setResults(data);
    });

  return () => { cancelled = true; };
}, [query]);
```

### Stale Closures
```jsx
// ❌ Empty deps + reads `count` → always logs 0
useEffect(() => {
  const id = setInterval(() => {
    console.log(count); // stale!
  }, 1000);
  return () => clearInterval(id);
}, []);

// ✅ Use functional update OR add to deps
useEffect(() => {
  const id = setInterval(() => {
    setCount(prev => prev + 1); // functional - always fresh
  }, 1000);
  return () => clearInterval(id);
}, []);
```

### StrictMode Double-Invoke
In React 18 StrictMode (dev only), effects run twice on mount:
```
mount → effect → cleanup → effect
```
This surfaces bugs where cleanup isn't correct. Production only runs once.

### `useEffect` vs Event Handlers
```jsx
// ❌ Don't use useEffect to respond to user actions
const [clicked, setClicked] = useState(false);
useEffect(() => {
  if (clicked) doSomething();
}, [clicked]);
<button onClick={() => setClicked(true)} />

// ✅ Do it directly in the event handler
<button onClick={doSomething} />
```

**Rule:** If it happens because of user interaction → event handler. If because of render/sync with external world → `useEffect`.

### Real-World Deal-Breakers
- **Missing dependencies** → stale values; ESLint `exhaustive-deps` catches this.
- **Unstable deps (inline objects/functions)** → runs every render:
```jsx
// ❌ New object every render → infinite loop
useEffect(() => { ... }, [{ userId }]);
useEffect(() => { ... }, [() => {}]);
```
- **Race conditions** → use AbortController or a cancelled flag.
- **Async function directly in effect** → `useEffect(async () => {})` returns a Promise, not a cleanup.
```jsx
// ❌
useEffect(async () => { await fetch(...); }, []);

// ✅
useEffect(() => {
  (async () => { await fetch(...); })();
}, []);
```
- **Updating state in effect without deps** → infinite loop.
- **Not cleaning up subscriptions** → memory leak + state updates on unmounted components.
- **Using `useEffect` for derived state** → compute during render instead.

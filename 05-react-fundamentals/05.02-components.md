### Function Components (Modern)
```jsx
// ✅ Modern function component
function Welcome({ name }) {
  return <h1>Hello, {name}</h1>;
}

// ✅ Arrow function
const Welcome = ({ name }) => <h1>Hello, {name}</h1>;

// ✅ With TypeScript
type WelcomeProps = { name: string; age?: number };
function Welcome({ name, age = 0 }: WelcomeProps) {
  return <h1>Hello, {name} ({age})</h1>;
}

// Usage
<Welcome name="Alice" age={30} />
```

### Class Components (Legacy - avoid in new code)
```jsx
class Welcome extends React.Component {
  render() {
    return <h1>Hello, {this.props.name}</h1>;
  }
}
```

**Why avoid class components:**
- More boilerplate (`this`, `bind`, lifecycle methods)
- Harder to reuse logic (no hooks)
- React team recommends function components + hooks

### Component Naming
```jsx
// ✅ PascalCase - React treats as component
function UserCard() { return <div />; }

// ❌ lowercase - React treats as HTML element
function userCard() { return <div />; }
<userCard />  // renders <usercard> DOM node, not the component!
```

### Component Return Types
```tsx
// Components can return:
// - JSX.Element
// - null (renders nothing)
// - string, number
// - array of elements (React 16+)
// - Fragment
// - Portal
// - boolean (renders nothing - useful for conditionals)

function Conditional({ show }: { show: boolean }) {
  return show && <div>Visible</div>; // false → renders nothing
}
```

### Composition Over Inheritance
```jsx
// ❌ Inheritance (don't do this in React)
class FancyButton extends Button { ... }

// ✅ Composition
function FancyButton({ children, ...props }) {
  return (
    <Button {...props} className="fancy">
      {children}
    </Button>
  );
}
```

### Real-World Deal-Breakers
- **Lowercase component names** → React treats as DOM element.
- **Defining components inside components** → creates new component type every render → unmounts/remounts entire subtree, losing state:
```jsx
// ❌ BAD
function Parent() {
  const Child = () => <div />; // new type every render!
  return <Child />;
}

// ✅ GOOD - define outside
const Child = () => <div />;
function Parent() {
  return <Child />;
}
```
- **Huge components** → >300 lines is hard to test and reason about. Extract subcomponents.
- **Too many props (prop drilling)** → 10+ props passed through layers → use context or composition.

### Synthetic Events
React wraps native DOM events in **SyntheticEvent** - a cross-browser wrapper with the same interface as native events.

```jsx
function Button() {
  function handleClick(event) {
    console.log(event.type);       // 'click'
    console.log(event.target);     // DOM element clicked
    console.log(event.currentTarget); // element with the listener
    event.preventDefault();
    event.stopPropagation();
  }

  return <button onClick={handleClick}>Click</button>;
}
```

**Benefits:**
- Consistent API across browsers
- Works with React's event delegation (single listener at root)
- `event.nativeEvent` accesses the underlying browser event

### Passing Arguments to Handlers
```jsx
// ❌ Calls immediately
<button onClick={handleDelete(id)}>Delete</button>

// ✅ Arrow function wrapper
<button onClick={() => handleDelete(id)}>Delete</button>

// ✅ Curried handler
function handleDelete(id) {
  return (event) => { ... };
}
<button onClick={handleDelete(id)}>Delete</button>

// ✅ data-* attribute
<button data-id={id} onClick={handleClick}>Delete</button>
function handleClick(e) {
  const id = e.currentTarget.dataset.id;
}
```

### Common Event Handlers

| React Event | Native Equivalent | Common Use |
|-------------|-------------------|-----------|
| `onClick` | click | Buttons, links |
| `onChange` | input/change | Form inputs |
| `onSubmit` | submit | Forms |
| `onFocus` / `onBlur` | focus/blur (bubbles in React) | Form validation |
| `onKeyDown` / `onKeyUp` | keydown/keyup | Keyboard shortcuts |
| `onMouseEnter` / `onMouseLeave` | mouseenter/mouseleave | Hover effects |
| `onScroll` | scroll | Scroll tracking |
| `onLoad` / `onError` | load/error | Images |

### Form Events
```jsx
function LoginForm() {
  const [email, setEmail] = useState('');

  function handleSubmit(event) {
    event.preventDefault(); // stops page reload
    console.log('Submitted:', email);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
      />
      <button type="submit">Login</button>
    </form>
  );
}
```

### Keyboard Events
```jsx
function SearchBox() {
  function handleKeyDown(e) {
    if (e.key === 'Enter') {
      submitSearch();
    } else if (e.key === 'Escape') {
      clearInput();
    }
  }

  return <input onKeyDown={handleKeyDown} />;
}
```

### Real-World Deal-Breakers
- **Forgetting `event.preventDefault()` on form submit** → page reloads, state lost.
- **`onClick={handleClick()}`** → calls during render, not on click.
- **`onChange` is `input` in React** → React's `onChange` fires on every keystroke, unlike native `change`.
- **Event handlers receiving wrong types** → `onChange` gives a change event, `onSubmit` gives a submit event. Type them properly in TS.
- **Overusing `stopPropagation`** → breaks parent handlers and event delegation.
- **`onScroll` on window** → use `useEffect` with `window.addEventListener`; React's `onScroll` only works on scrollable elements.
- **Async event handlers + `event` access** → React 17+ doesn't pool events anymore, so accessing `event` after await is fine. Before React 17 it wasn't.

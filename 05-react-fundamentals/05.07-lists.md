### Syntax
```jsx
function TodoList({ todos }) {
  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>{todo.title}</li>
      ))}
    </ul>
  );
}
```

### Keys - The Rules
Keys help React identify which items changed, were added, or removed. They must be:
- **Unique among siblings** (not globally)
- **Stable** (don't change between renders)
- **Predictable** (not random)

```jsx
// ✅ Stable ID from data
{todos.map(todo => <TodoItem key={todo.id} todo={todo} />)}

// ✅ Fallback: stable composite key
{items.map(item => <Row key={`${item.type}-${item.id}`} item={item} />)}

// ❌ Index as key (breaks on reorder/insert/delete)
{todos.map((todo, index) => <TodoItem key={index} todo={todo} />)}

// ❌ Math.random() - new key every render
{todos.map(todo => <TodoItem key={Math.random()} todo={todo} />)}
```

### Why Index Keys Are Dangerous
```jsx
// Initial list: ['A', 'B', 'C'] → keys: [0, 1, 2]
// Insert 'X' at start: ['X', 'A', 'B', 'C'] → keys: [0, 1, 2, 3]
// React sees:
//   key 0: was 'A', now 'X' → UPDATE (reuses old A component with X data!)
//   key 1: was 'B', now 'A' → UPDATE
//   key 2: was 'C', now 'B' → UPDATE
//   key 3: new 'C' → MOUNT
// → Uncontrolled inputs keep old values, animations break, state is wrong

// With stable IDs: React sees old keys shifted + one new key → correct behavior
```

### Filtering & Sorting
```jsx
function UserList({ users, searchTerm }) {
  const filtered = users
    .filter(u => u.name.toLowerCase().includes(searchTerm.toLowerCase()))
    .sort((a, b) => a.name.localeCompare(b.name));

  return (
    <ul>
      {filtered.map(u => <li key={u.id}>{u.name}</li>)}
    </ul>
  );
}
```

### Nested Lists
```jsx
function CategoryList({ categories }) {
  return (
    <ul>
      {categories.map(category => (
        <li key={category.id}>
          {category.name}
          <ul>
            {category.items.map(item => (
              <li key={item.id}>{item.name}</li>
            ))}
          </ul>
        </li>
      ))}
    </ul>
  );
}
```

### Fragment with Keys
```jsx
function DefinitionList({ items }) {
  return (
    <dl>
      {items.map(item => (
        <React.Fragment key={item.id}>
          <dt>{item.term}</dt>
          <dd>{item.definition}</dd>
        </React.Fragment>
      ))}
    </dl>
  );
}
```

### Real-World Deal-Breakers
- **Index as key with dynamic lists** → state/input values jump to wrong items on reorder.
- **Missing keys** → React warning, unpredictable behavior.
- **Duplicate keys** → React renders incorrectly (last one wins for reconciliation).
- **Random keys** → full remount on every render; terrible performance.
- **`.map()` returning nothing for some items** → `undefined` in array → React error. Use `.filter()` first.
- **Mutating array before render** → use non-mutating methods (`.filter`, `.map`, `.slice`).

## 5.13 Children

### Subtopic Tree

### Basic Usage
```jsx
function Box({ children }) {
  return <div className="box">{children}</div>;
}

// All valid
<Box>Plain text</Box>
<Box><span>Element</span></Box>
<Box>{[<span key="1">A</span>, <span key="2">B</span>]}</Box>
<Box /> // undefined children
```

### `React.Children` Utilities
```jsx
import { Children } from 'react';

function List({ children }) {
  const count = Children.count(children);

  return (
    <div>
      <p>{count} items</p>
      {Children.map(children, (child, i) =>
        child ? <div key={i}>{child}</div> : null
      )}
    </div>
  );
}
```

**Note:** Modern React rarely needs `React.Children`. Prefer arrays and `.map()`.

### Function as Children
```jsx
function MouseTracker({ children }) {
  const [pos, setPos] = useState({ x: 0, y: 0 });

  useEffect(() => {
    const handler = (e) => setPos({ x: e.clientX, y: e.clientY });
    window.addEventListener('mousemove', handler);
    return () => window.removeEventListener('mousemove', handler);
  }, []);

  return children(pos);
}

<MouseTracker>
  {({ x, y }) => <p>Mouse at {x}, {y}</p>}
</MouseTracker>
```

### TypeScript Typing
```tsx
import { ReactNode, ReactElement } from 'react';

// Most permissive
type Props = { children: ReactNode };

// Only JSX elements
type Props2 = { children: ReactElement };

// String or elements
type Props3 = { children: ReactNode | string };

// Function as child
type Props4 = { children: (data: Data) => ReactNode };

// Optional
type Props5 = { children?: ReactNode };
```

**`ReactNode` types:**
```typescript
type ReactNode =
  | ReactElement
  | string
  | number
  | boolean
  | null
  | undefined
  | ReactPortal
  | Iterable<ReactNode>;
```

### Real-World Deal-Breakers
- **Assuming children is a single element** → can be array, string, null, etc. Use `React.Children.count` or array checks.
- **Mutating children** → children are immutable React elements; clone via `cloneElement` (legacy) or restructure.
- **`React.Children.map` vs `children.map`** → `children` may not be an array. `React.Children.map` handles all cases.
- **Using `cloneElement`** → legacy pattern; prefer passing props through context or restructuring.
- **Not typing `children`** → TypeScript will infer `any` or `ReactNode`; be explicit for clarity.

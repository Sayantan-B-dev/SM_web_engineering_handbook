## 5.3 Props

### Syntax
```jsx
// Parent
<UserCard name="Alice" age={30} isAdmin={true} />

// Child - destructured (recommended)
function UserCard({ name, age, isAdmin }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>Age: {age}</p>
      {isAdmin && <span>Admin</span>}
    </div>
  );
}

// Or with `props` object
function UserCard(props) {
  return <h2>{props.name}</h2>;
}
```

### Default Values
```jsx
// ✅ Default parameters (modern)
function Button({ variant = 'primary', size = 'md', children }) {
  return <button className={`btn btn-${variant} btn-${size}`}>{children}</button>;
}

// ❌ defaultProps (deprecated for function components)
Button.defaultProps = { variant: 'primary' };
```

### Children Prop
```jsx
// children is a special prop
function Card({ children, title }) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div className="card-body">{children}</div>
    </div>
  );
}

// Usage
<Card title="Welcome">
  <p>Any JSX content here</p>
  <button>Action</button>
</Card>
```

### Spread Props
```jsx
function Input({ label, ...rest }) {
  return (
    <label>
      {label}
      <input {...rest} />
    </label>
  );
}

// Usage - all native input attributes pass through
<Input label="Email" type="email" placeholder="you@example.com" required />
```

### Render Props Pattern
```jsx
// Component takes a function as a prop
function MouseTracker({ render }) {
  const [position, setPosition] = useState({ x: 0, y: 0 });

  useEffect(() => {
    const handler = (e) => setPosition({ x: e.clientX, y: e.clientY });
    window.addEventListener('mousemove', handler);
    return () => window.removeEventListener('mousemove', handler);
  }, []);

  return render(position);
}

// Usage
<MouseTracker render={({ x, y }) => <p>Mouse: {x}, {y}</p>} />
```

**Modern alternative:** custom hooks (`useMousePosition()`) - cleaner and more composable.

### Props are Read-Only
```jsx
// ❌ NEVER mutate props
function Bad({ user }) {
  user.name = 'Hacked'; // mutation!
  return <p>{user.name}</p>;
}

// ✅ Treat props as immutable - create a copy if needed
function Good({ user }) {
  const displayName = user.name.toUpperCase();
  return <p>{displayName}</p>;
}
```

### Real-World Deal-Breakers
- **Mutating props** → breaks React's data flow, causes subtle bugs.
- **Prop drilling through 5+ levels** → use Context or component composition.
- **Passing functions inline without memo** → `onClick={() => doSomething(id)}` creates a new function each render → breaks `React.memo` on children.
- **Boolean props written as `prop="false"`** → string `"false"` is truthy. Use `prop={false}`.
- **Not using TypeScript/propTypes** → runtime errors from wrong types. Always type props.
- **Passing `key` as a prop** → `key` is React-reserved; not accessible via `props.key`. Use a different name.

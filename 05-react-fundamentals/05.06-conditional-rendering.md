## 5.6 Conditional Rendering

### Subtopic Tree
- `if`/`else` before return
- Ternary operator
- Logical AND (`&&`)
- Logical OR (`||`)
- Nullish coalescing (`??`)
- Early returns
- Switch statements
- Rendering nothing (`null`, `false`, `undefined`)
- Avoiding falsy-value rendering

### Patterns

```jsx
// 1. If/else (early return)
function Greeting({ isLoggedIn }) {
  if (!isLoggedIn) return <p>Please log in</p>;
  return <p>Welcome back!</p>;
}

// 2. Ternary
function Status({ isActive }) {
  return <span>{isActive ? 'Active' : 'Inactive'}</span>;
}

// 3. Logical AND
function Notification({ message }) {
  return (
    <div>
      {message && <p className="alert">{message}</p>}
    </div>
  );
}

// 4. Nullish coalescing
function UserName({ name }) {
  return <p>{name ?? 'Anonymous'}</p>;
}

// 5. Switch
function Icon({ type }) {
  switch (type) {
    case 'success': return <CheckIcon />;
    case 'error':   return <XIcon />;
    case 'warning': return <WarningIcon />;
    default:        return null;
  }
}
```

### The `&&` Falsy Value Trap
```jsx
// ❌ Renders "0" when count is 0
function Cart({ count }) {
  return <div>{count && <p>{count} items</p>}</div>;
  // count = 0 → renders "0"
}

// ✅ Explicit boolean check
function Cart({ count }) {
  return <div>{count > 0 && <p>{count} items</p>}</div>;
}

// ✅ Or ternary
function Cart({ count }) {
  return <div>{count ? <p>{count} items</p> : null}</div>;
}
```

**Rule:** `0`, `''`, `NaN`, `false`, `null`, `undefined` are all falsy. `&&` returns the falsy value itself. Use explicit boolean coercion (`count > 0`) or ternary.

### Rendering Nothing
```jsx
function Conditional({ show }) {
  if (!show) return null;      // renders nothing
  return <div>Visible</div>;
}

// These all render nothing:
return false;
return null;
return undefined;
return true;   // also renders nothing
return <></>;  // empty fragment
```

### Real-World Deal-Breakers
- **`{count && ...}` with numeric 0** → renders `0`. Use `{count > 0 && ...}`.
- **Nested ternaries** → unreadable:
```jsx
// ❌ Hard to read
{status === 'loading' ? <Spinner /> : status === 'error' ? <Error /> : <Data />}

// ✅ Extract to function or early returns
function renderContent(status) {
  if (status === 'loading') return <Spinner />;
  if (status === 'error') return <Error />;
  return <Data />;
}
```
- **Returning empty string `''`** → renders as text node (empty but present). Return `null` instead.
- **Conditional rendering with side effects** → don't `setState` during conditional render; use `useEffect`.

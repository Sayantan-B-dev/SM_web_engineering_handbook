### Syntax & Rules
JSX is **syntactic sugar** for `React.createElement()`. It looks like HTML but compiles to JavaScript function calls.

```jsx
// JSX
const element = <h1 className="title">Hello, {name}</h1>;

// Compiles to (React 17+ automatic runtime)
import { jsx as _jsx } from 'react/jsx-runtime';
const element = _jsx('h1', { className: 'title', children: ['Hello, ', name] });

// Or classic runtime
const element = React.createElement('h1', { className: 'title' }, 'Hello, ', name);
```

### Key Rules
1. **Must return a single root element** (or a Fragment).
2. **All tags must be closed** - `<img />`, `<br />`, `<input />`.
3. **`class` → `className`**, `for` → `htmlFor`.
4. **Attributes are camelCase** - `onclick` → `onClick`, `tabindex` → `tabIndex`.
5. **JS expressions go in `{}`** - `{2 + 2}`, `{user.name}`, `{items.map(...)}`.
6. **Statements are NOT allowed in `{}`** - no `if`, `for`, `while`. Use expressions or IIFEs.
7. **JSX comments** - `{/* comment */}` (not `//` or `/* */`).

```jsx
// ❌ Multiple roots
return (
  <h1>Title</h1>
  <p>Body</p>
);

// ✅ Fragment
return (
  <>
    <h1>Title</h1>
    <p>Body</p>
  </>
);

// ✅ Wrapper div (if you need a real DOM node)
return (
  <div>
    <h1>Title</h1>
    <p>Body</p>
  </div>
);
```

### Expressions in JSX
```jsx
const name = 'Alice';
const user = { age: 30 };
const items = ['a', 'b', 'c'];

// Any JS expression works
<p>{name}</p>
<p>{2 + 2}</p>
<p>{user.age > 18 ? 'Adult' : 'Minor'}</p>
<p>{items.length} items</p>
<p>{items.join(', ')}</p>
<p>{new Date().toLocaleDateString()}</p>

// Function calls
<p>{formatName(name)}</p>

// Immediately invoked
<p>{(() => 'computed')()}</p>

// ❌ Statements don't work
<p>{if (x) { return 'yes' }}</p> // SyntaxError
<p>{for (let i = 0; i < 3; i++) {}}</p> // SyntaxError
```

### Attributes
```jsx
// HTML attributes
<div className="container" id="main" data-testid="wrapper">
  <label htmlFor="email">Email</label>
  <input id="email" type="email" tabIndex={0} />
</div>

// Boolean attributes - bare or explicit
<input disabled />              // ✅
<input disabled={true} />       // ✅
<input disabled={false} />      // ✅ (removes attribute)

// Custom attributes (data-*, aria-*)
<button data-action="save" aria-label="Save document">Save</button>

// Event handlers
<button onClick={handleClick}>Click</button>
<input onChange={(e) => setName(e.target.value)} />

// String vs expression
<div className="box" />         // static string
<div className={'box ' + size} /> // dynamic
<div className={`box ${size}`} /> // template literal
```

### Inline Styles
```jsx
// ❌ String (doesn't work)
<div style="color: red; font-size: 16px" />

// ✅ Object with camelCase
<div style={{ color: 'red', fontSize: '16px', marginTop: 10 }} />
// Note: numeric values auto-append 'px' for most properties

// Dynamic styles
<div style={{ backgroundColor: isActive ? 'blue' : 'gray' }} />

// Spread multiple style objects
const base = { padding: 10, borderRadius: 8 };
const active = { background: 'blue' };
<div style={{ ...base, ...active }} />
```

### Spreading Props
```jsx
const buttonProps = {
  type: 'submit',
  disabled: false,
  onClick: handleSubmit,
  'aria-label': 'Submit form',
};

// ✅ Spread all at once
<button {...buttonProps}>Submit</button>

// ✅ Combine with explicit props (later wins)
<button {...buttonProps} disabled={isLoading}>Submit</button>

// ⚠️ Order matters
<button disabled={isLoading} {...buttonProps}>Submit</button>
// disabled from buttonProps overrides isLoading!
```

### Fragments
```jsx
// ✅ Short syntax (no key support)
<>
  <li>Item 1</li>
  <li>Item 2</li>
</>

// ✅ Full syntax (supports key)
<React.Fragment key={item.id}>
  <dt>{item.term}</dt>
  <dd>{item.definition}</dd>
</React.Fragment>

// ❌ Can't use short syntax with key
< key={item.id}> // SyntaxError
```

### XSS Safety
```jsx
// ✅ JSX auto-escapes - safe
const userInput = '<script>alert("xss")</script>';
<p>{userInput}</p>
// Renders as literal text: <script>alert("xss")</script>

// ❌ dangerouslySetInnerHTML - escape hatch, XSS risk
<p dangerouslySetInnerHTML={{ __html: userInput }} />
// Executes the script!

// ✅ Sanitize first if you must use it
import DOMPurify from 'dompurify';
<p dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(userInput) }} />
```

### Real-World Deal-Breakers
- **Returning multiple roots without Fragment** → compile error.
- **Using `class` instead of `className`** → React warning, no styling applied.
- **Forgetting to close self-closing tags** → `<img>` without `/>` → syntax error.
- **`onClick={handleClick()}`** → calls immediately on render; use `onClick={handleClick}` or `onClick={() => handleClick(id)}`.
- **String style prop** → `style="color: red"` silently ignored.
- **`dangerouslySetInnerHTML` without sanitization** → XSS vulnerability.
- **Fat arrow returning object literal without parens** → `() => { id: 1 }` returns `undefined`; use `() => ({ id: 1 })`.

## 12.10 Parallel Routes

### Subtopic Tree
- `@slot` folder convention
- Multiple pages in one layout
- Independent loading/error states per slot
- `default.tsx` fallback
- Conditional rendering with `useSelectedLayoutSegment`
- Modal patterns

### Syntax
```
app/dashboard/
├── @team/
│   └── page.tsx
├── @analytics/
│   └── page.tsx
├── layout.tsx
└── page.tsx
```

```tsx
// app/dashboard/layout.tsx
export default function Layout({
  children,
  team,
  analytics,
}: {
  children: React.ReactNode;
  team: React.ReactNode;
  analytics: React.ReactNode;
}) {
  return (
    <div className="grid grid-cols-3">
      <div>{children}</div>
      <div>{team}</div>
      <div>{analytics}</div>
    </div>
  );
}
```

### `default.tsx` Fallback
```tsx
// app/dashboard/@team/default.tsx - shown when slot is not matched
export default function Default() {
  return null;
}
```

### Real-World Deal-Breakers
- **Missing `default.tsx`** → build error on direct navigation.
- **Parallel route without matching page** → slot renders `default.tsx`.
- **Too many parallel slots** → complex layouts; use sparingly.

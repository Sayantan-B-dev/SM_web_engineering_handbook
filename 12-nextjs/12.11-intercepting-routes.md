## 12.11 Intercepting Routes

### Subtopic Tree
- `(.)` - same level
- `(..)` - one level up
- `(..)(..)` - two levels up
- `(...)` - root
- Modal patterns
- `@modal` parallel slot
- Hard navigation fallback

### Syntax
```
app/
├── feed/
│   └── page.tsx
├── photo/
│   └── [id]/
│       └── page.tsx
└── @modal/
    └── (.)photo/
        └── [id]/
            └── page.tsx  # intercepts /photo/:id from /feed
```

```tsx
// app/@modal/(.)photo/[id]/page.tsx
export default function PhotoModal({ params }: { params: Promise<{ id: string }> }) {
  return (
    <Modal>
      <Photo id={(await params).id} />
    </Modal>
  );
}
```

### How It Works
- **Soft navigation** (from `/feed`) → intercepted route renders in modal.
- **Hard navigation** (direct URL, refresh) → full page renders `/photo/:id`.

### Real-World Deal-Breakers
- **Wrong number of dots** → `(..)` when you need `(.)`; route won't intercept.
- **No fallback route** → hard navigation 404s; always create the full page at `photo/[id]/page.tsx`.
- **Modal without close handling** → use `router.back()` to dismiss.

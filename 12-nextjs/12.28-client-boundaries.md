## 12.15 Client Boundaries

### Subtopic Tree
- `'use client'` subtree
- Everything imported becomes client
- Server Components as `children`
- Third-party library wrapping
- Client Component importing Server Component (not allowed)

### Server as Children
```tsx
'use client';
export default function ClientWrapper({ children }) {
  const [open, setOpen] = useState(false);
  return <div>{open && children}</div>;
}
```
```tsx
// page.tsx - Server Component
<ClientWrapper>
  <ServerData />  {/* Server Component as children */}
</ClientWrapper>
```

### Real-World Deal-Breakers
- **Client Component importing Server Component directly** → build error. Use `children`.
- **Entire app in `'use client'`** → everything ships to client.

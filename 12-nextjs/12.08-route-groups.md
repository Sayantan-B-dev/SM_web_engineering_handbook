## 12.8 Route Groups

### Subtopic Tree
- `(folderName)` syntax
- Organization without URL impact
- Multiple root layouts
- Group-specific layouts
- Common patterns: `(marketing)`, `(shop)`, `(auth)`

### Syntax
```
app/
├── (marketing)/
│   ├── layout.tsx      # marketing layout
│   ├── page.tsx        # /
│   ├── about/page.tsx  # /about
│   └── pricing/page.tsx # /pricing
├── (shop)/
│   ├── layout.tsx      # shop layout (different from marketing)
│   ├── cart/page.tsx   # /cart
│   └── products/page.tsx # /products
└── layout.tsx          # root layout
```

### Multiple Root Layouts
```tsx
// app/(marketing)/layout.tsx
export default function MarketingLayout({ children }) {
  return <html><body className="marketing">{children}</body></html>;
}

// app/(shop)/layout.tsx
export default function ShopLayout({ children }) {
  return <html><body className="shop">{children}</body></html>;
}
```

### Real-World Deal-Breakers
- **Duplicate paths across groups** → `(marketing)/about` and `(shop)/about` both map to `/about` → build error.
- **Forgetting route groups don't affect URLs** → `/about` not `/(marketing)/about`.
- **Multiple root layouts with `global-error.tsx`** → error boundary must be in each root layout's group.

## 12.27 Dynamic Rendering

### Subtopic Tree
- Request-time rendering
- `cookies()`, `headers()`, `searchParams`
- `no-store` fetch
- When route becomes dynamic
- Dynamic APIs

### Syntax
```tsx
import { cookies } from 'next/headers';

export default async function Page() {
  const cookieStore = await cookies();
  const theme = cookieStore.get('theme');
  return <div className={theme?.value}>...</div>;
}
```

### Real-World Deal-Breakers
- **`cookies()` in a static route** → route becomes dynamic; build-time prerender fails.
- **`headers()` without dynamic rendering** → error.

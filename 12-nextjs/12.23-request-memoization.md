## 12.31 Request Memoization

### Subtopic Tree
- Automatic `fetch` deduplication
- Same URL + options = one request
- Per-request lifecycle
- Not the same as Data Cache

### How It Works
Next.js extends `fetch` to automatically memoize requests with the same URL and options. Call `fetch` for the same data in multiple components; it executes once per request.

```tsx
async function getItem() {
  const res = await fetch('https://.../item/1'); // executed once
  return res.json();
}

const item1 = await getItem(); // cache MISS
const item2 = await getItem(); // cache HIT
```

### Real-World Deal-Breakers
- **Confusing memoization with Data Cache** → memoization is per-request only; Data Cache persists.
- **Different fetch options** → not deduplicated; must match URL and options.

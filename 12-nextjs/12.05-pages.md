## 12.5 Pages

### Subtopic Tree
- `page.tsx` as route entry
- Async Server Components
- Props: `params`, `searchParams`
- Metadata (static and dynamic)
- `generateStaticParams`
- `generateMetadata`
- Page vs layout relationship

### Basic Page
```tsx
// app/blog/[slug]/page.tsx
export default async function Page({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const post = await getPost(slug);
  return <article><h1>{post.title}</h1><p>{post.content}</p></article>;
}
```

### Dynamic Metadata
```tsx
export async function generateMetadata({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const post = await getPost(slug);
  return { title: post.title, description: post.excerpt };
}
```

### Static Params (SSG)
```tsx
export async function generateStaticParams() {
  const posts = await getPosts();
  return posts.map(post => ({ slug: post.slug }));
}
```

### Real-World Deal-Breakers
- **`params` not awaited** → Next.js 15+ requires `await params`. Synchronous access is deprecated.
- **Missing `generateStaticParams`** → dynamic routes are rendered on-demand, not prerendered.
- **Metadata in a Client Component** → can't export `metadata` from a `'use client'` file. Use `generateMetadata` in Server Components.

## 12.33 Next.js Performance

### Subtopic Tree
- Automatic optimizations
- `@next/bundle-analyzer`
- `next/image` optimization
- `next/font` optimization
- Route prefetching
- Prerendering
- Server Components (zero client JS)
- Core Web Vitals

### Automatic Optimizations
Next.js enables by default: Server Components, code-splitting by route, prefetching, prerendering, and caching.

### Bundle Analysis
```bash
npm install @next/bundle-analyzer
```
Use the plugin to analyze JavaScript bundle size and identify large modules and dependencies.

### Image Optimization
```tsx
import Image from 'next/image';

<Image src="/hero.jpg" width={800} height={600} alt="Hero" priority />
```

### Font Optimization
```tsx
import { Inter } from 'next/font/google';
const inter = Inter({ subsets: ['latin'] });
```

### Real-World Deal-Breakers
- **Not using `next/image`** → no automatic format negotiation, lazy loading, or width/height enforcement.
- **`priority` on every image** → defeats LCP prioritization.
- **No bundle analysis** → silent bundle growth.

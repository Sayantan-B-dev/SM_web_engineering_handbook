### Tag System
Next.js uses a tag-based system to track which cached content needs invalidation. Explicit tags are set by developers using `cacheTag()`; implicit tags are set by Next.js based on route path.

### Real-World Deal-Breakers
- **No tags on dynamic content** → can't selectively invalidate.
- **`revalidateTag` without tag on fetch** → no effect.

## 12.17 `use server`

### Subtopic Tree
- Server Actions
- File-level vs inline
- Async requirement
- Form actions
- `useActionState`
- `useFormStatus`
- Security (validation, auth)

### Server Action
```tsx
'use server';

export async function createPost(formData: FormData) {
  const title = formData.get('title');
  await db.post.create({ data: { title } });
  revalidatePath('/posts');
}
```

### Real-World Deal-Breakers
- **No validation** → public endpoint, anyone can call.
- **No authorization** → any user can mutate.
- **Assuming private** → Server Actions are HTTP endpoints.

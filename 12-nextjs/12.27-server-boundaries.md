## 12.14 Server Boundaries

### Subtopic Tree
- Server ↔ Client boundary
- Module dependency boundary
- Serializable props
- Server Actions as exception
- `server-only` / `client-only` packages
- Provider placement

### Serialization Rules
| Type | Serializable? |
|------|--------------|
| Primitives | ✅ |
| Plain objects | ✅ |
| Arrays | ✅ |
| Server Actions | ✅ |
| Functions | ❌ |
| Class instances | ❌ |
| Symbols | ❌ |

### Real-World Deal-Breakers
- **Passing `new Intl.NumberFormat()`** → runtime error. Pass formatted string.
- **No `server-only` guard** → server module imported by client leaks secrets.
- **Provider in Server Component** → build error; providers need `'use client'`.

## 12.13 Client Components

### Subtopic Tree
- `'use client'` directive
- Entry points
- Serializable props
- Bundle size impact
- Interactivity, hooks, browser APIs
- Boundary placement
- Provider pattern

### Client Component
```tsx
'use client';
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>;
}
```

### Real-World Deal-Breakers
- **`'use client'` on parent** → entire subtree becomes client-bundled. Push to leaves.
- **Non-serializable props** → functions, class instances, Symbols error at the boundary.
- **`'use client'` after imports** → silently ignored; directive must be first line.

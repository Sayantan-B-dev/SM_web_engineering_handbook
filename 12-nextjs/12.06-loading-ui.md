### Automatic Loading UI
```tsx
// app/dashboard/loading.tsx
export default function Loading() {
  return <DashboardSkeleton />;
}
```
Next.js automatically wraps the page in `<Suspense>` with this component as fallback.

### Manual Suspense for Granular Streaming
```tsx
import { Suspense } from 'react';

export default function Page() {
  return (
    <>
      <Header />  {/* static - renders immediately */}
      <Suspense fallback={<FeedSkeleton />}>
        <Feed />  {/* async - streams when ready */}
      </Suspense>
      <Suspense fallback={<SidebarSkeleton />}>
        <Sidebar />  {/* async - streams independently */}
      </Suspense>
    </>
  );
}
```

### Real-World Deal-Breakers
- **Skeleton that doesn't match content layout** → CLS when content streams in.
- **`loading.tsx` at the root** → every navigation shows the root loading state, even for fast routes. Place `loading.tsx` at segment level.
- **No `loading.tsx` for slow routes** → users see a blank page until the server responds.

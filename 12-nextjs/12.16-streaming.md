### How Streaming Works
Next.js uses chunked transfer encoding to send parts of the response as they become ready. The static shell (layouts, navigation, fallbacks) renders first, then dynamic content streams in.

```tsx
import { Suspense } from 'react';

<Suspense fallback={<Skeleton />}>
  <SlowData />
</Suspense>
```

### Real-World Deal-Breakers
- **No `<Suspense>` boundaries** → entire page blocks until every async component resolves.
- **Fallback very different from content** → CLS.

### How Layouts Work
Layouts wrap pages and **persist across navigations within their segment**. Unlike pages, they don't re-render when you navigate between sibling routes.

```tsx
// app/dashboard/layout.tsx
export default function DashboardLayout({ children }: { children: React.ReactNode }) {
  return (
    <div className="dashboard">
      <DashboardNav />  {/* persists across /dashboard/* */}
      <main>{children}</main>
    </div>
  );
}
```

### Layout vs Template

| Layout | Template |
|--------|----------|
| Persists across navigation | Re-mounts on navigation |
| State preserved | State reset |
| Effects don't re-run | Effects re-run |

```tsx
// app/template.tsx - re-mounts on every navigation
export default function Template({ children }: { children: React.ReactNode }) {
  return <div className="animate-fade-in">{children}</div>;
}
```

### Real-World Deal-Breakers
- **Assuming layouts re-render** → they don't. If a layout depends on `usePathname`, it won't update on navigation unless it's a Client Component.
- **Putting data fetching in layouts** → layouts don't re-fetch on navigation. Fetch in pages or use `usePathname`.
- **Root layout without `<html>` and `<body>`** → build error.

## 12.18 Serialization

### Subtopic Tree
- RSC payload
- Serializable types
- Server Actions exception
- Class instance conversion
- Error messages

### Real-World Deal-Breakers
- **Passing `Symbol`** → error.
- **Assuming `Date` works everywhere** → timezone shifts; pass ISO strings.
- **Silent data loss** → non-serializable values may become `undefined`.

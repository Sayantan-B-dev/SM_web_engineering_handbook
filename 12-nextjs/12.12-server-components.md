## 12.12 Server Components

### Subtopic Tree
- Default in App Router
- Async components
- Direct DB access
- No JS to client
- No hooks/state
- RSC payload
- Data fetching with `await`
- Heavy library elimination

### Server Component
```tsx
// app/users/page.tsx - Server Component by default
import { db } from '@/lib/db';

export default async function UsersPage() {
  const users = await db.user.findMany(); // direct DB access
  return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>;
}
```

### Real-World Deal-Breakers
- **Using hooks in Server Components** → build error. Use Client Components for interactivity.
- **`process.env.SECRET` in Client Component** → leaked. Only Server Components can safely access secrets.
- **Assuming Server Components hydrate** → they never hydrate; they run only on the server.

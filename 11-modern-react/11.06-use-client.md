## 11.6 `use client`

### Subtopic Tree
- Exact placement rules
- Syntax (single/double quotes, not backticks)
- Effect on imports (transitive dependencies)
- Effect on rendering (creates boundary)
- When it's needed (only with RSC)
- When it has no effect (already client)
- Interaction with `children`
- Common mistakes

### Placement Rules
- Must be at the **very beginning of the file**, above any imports or other code (comments are OK).
- Must use **single or double quotes** - not backticks.
- Only needed in files that are part of the Server → Client boundary.

```jsx
'use client'; // ✅ correct - first line

// ❌ Wrong
// 'use client'; - inside a comment, ignored
import x from 'y';
'use client'; // not first line - ignored
```

### Effect on Transitive Dependencies
```jsx
// ClientComponent.tsx
'use client';
import { formatDate } from './formatters';  // ← becomes client code
import Button from './button';              // ← becomes client code

export default function RichTextEditor({ timestamp }) {
  const date = formatDate(timestamp);
  return <Button />;
}
```

As dependencies of `RichTextEditor`, `formatDate` and `Button` will also be evaluated on the client **regardless of whether their modules contain `'use client'`**.

### A Single Module Can Be Both
A single module may be evaluated on the server when imported from server code and on the client when imported from client code.

### When `'use client'` Has No Effect
- When imported from another client-rendered module - it's already client.
- When placed in a file that's never imported by server code.

### Common Mistakes
```jsx
// ❌ Mistake 1: Directive after imports
import { useState } from 'react';
'use client'; // ignored!
```

```jsx
// ❌ Mistake 2: Backticks
`use client`; // ignored
```

```jsx
// ❌ Mistake 3: Putting it on every file
// Only needed at the boundary - not on leaf client-only utilities
```

### Real-World Deal-Breakers
- **Directive not first line** → silently ignored; component treated as Server Component → hooks error.
- **Backticks instead of quotes** → silently ignored.
- **`'use client'` on a Server Component** → no effect if the file is never imported by client code.
- **Assuming `'use client'` makes everything client** → it makes the module and its imports client. It doesn't change the render tree.

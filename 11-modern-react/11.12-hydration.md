## 11.11 Hydration (Modern React)

### Hydration with RSC
Server Components **never hydrate** - they run exclusively on the server and never ship JavaScript to the client. Only Client Components hydrate.

```
Server Components → rendered to RSC payload → streamed to client → no hydration
Client Components → rendered on server (SSR) → hydrated on client
```

### Selective Hydration
React 18+ hydrates Suspense boundaries independently. If a user interacts with a boundary that isn't hydrated yet, React **prioritizes** hydrating that boundary first.

```jsx
<Suspense fallback={<Skeleton />}>
  <Sidebar /> {/* may hydrate first if user clicks it */}
</Suspense>
<Suspense fallback={<Skeleton />}>
  <Feed />
</Suspense>
```

### Priority-Based Hydration
1. Boundaries the user is interacting with.
2. Boundaries already in viewport.
3. Others in the background.

### Hydration with Streaming
Streaming and selective hydration work together: the server streams HTML for each Suspense boundary as it resolves, and the client hydrates boundaries in priority order.

### Mismatch Avoidance
Hydration mismatches are **less common with RSC** because Server Components don't run on the client. But Client Components can still mismatch:

```jsx
// ❌ Mismatch - server time ≠ client time
'use client';
function Clock() {
  return <p>{new Date().toISOString()}</p>;
}

// ✅ Use useId for stable IDs
'use client';
import { useId } from 'react';
function Form() {
  const id = useId();
  return <><label htmlFor={id}>Name</label><input id={id} /></>;
}
```

### Real-World Deal-Breakers
- **Expecting Server Components to hydrate** → they don't. Only Client Components hydrate.
- **Hydration mismatch in Client Components** → whole subtree client-renders from scratch, wasting SSR.
- **No Suspense boundaries** → selective hydration has nothing to work with.
- **`window`/`localStorage` in Client Component render** → mismatch on server. Guard with `useEffect` or `typeof window`.
- **Heavy Client Components** → hydration is expensive; keep client boundaries at the leaves.

### What TanStack Start Is
TanStack Start is a **full-stack React framework** built around TanStack Router. It adds the server pieces: full-document SSR, streaming, server functions, and deployment adapters. It's **Vite-powered** and has first-class **Cloudflare Workers** support.

```tsx
// server function - type-safe RPC
import { createServerFn } from '@tanstack/react-start';

const getRecipes = createServerFn({ method: 'GET' })
  .validator((data: { category: string }) => data)
  .handler(async ({ data }) => {
    return db.recipe.findMany({ where: { category: data.category } });
  });

// Usage in component - fully typed
const recipes = await getRecipes({ data: { category: 'dinner' } });
```

### Server Functions
Server functions let you define server-only logic that's callable from the client with full type safety. Start handles serialization across the client/server boundary. Use `createCsrfMiddleware()` to protect from cross-site requests.

### Streaming
TanStack Start supports streaming via `ReadableStream` and async generators. Server functions can stream data to the client as it becomes available.

### TanStack Query Integration
Start deeply integrates with TanStack Query for:
- **Prefetching** in route loaders
- **Caching** via the same `QueryClient`
- **Hydration** - server-prefetched data is dehydrated and hydrated on the client

### Real-World Deal-Breakers
- **No CSRF middleware** → server functions are callable from other origins. Always add `createCsrfMiddleware()`.
- **Server function without validation** → public endpoint; validate every input with `validator()`.
- **Not using TanStack Query** → Start leans on Query for data management and caching; without it, you rebuild caching manually.
- **RSC support not yet stable** → still in active development; don't plan around it for production yet.

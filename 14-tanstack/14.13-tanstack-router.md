### Type Safety
TanStack Router is **built to be as type-safe as possible** within TypeScript's limits. It fully infers types and **tenaciously pipes them through the entire routing experience** - params, search params, context, and loader data all flow through the route tree automatically.

```tsx
const Route = createFileRoute('/users/$userId')({
  loader: ({ params }) => fetchUser(params.userId), // userId: string - typed
  component: () => {
    const { userId } = Route.useParams(); // string - typed
    const user = Route.useLoaderData(); // User - typed
    return <h1>{user.name}</h1>;
  },
});
```

### File-Based Routing
TanStack Router uses the filesystem to define route hierarchy:

```
src/routes/
├── __root.tsx          # root layout
├── index.tsx           # /
├── about.tsx           # /about
├── users/
│   ├── index.tsx       # /users
│   └── $userId.tsx     # /users/:userId
└── posts/
    ├── index.tsx       # /posts
    └── $postId.tsx     # /posts/:postId
```

### Route Loaders
Loaders run **before render**, fetching data so the component renders with data ready. Loaders run in parallel, preload on intent, and cache results.

```tsx
export const Route = createFileRoute('/users/$userId')({
  loader: async ({ params, context: { queryClient } }) => {
    return queryClient.ensureQueryData(userOptions(params.userId));
  },
  component: UserPage,
});
```

### Search Params Validation (Zod)
```tsx
import { z } from 'zod';

const searchSchema = z.object({
  page: z.number().default(1),
  filter: z.string().optional(),
});

export const Route = createFileRoute('/users/')({
  validateSearch: searchSchema,
  component: () => {
    const { page, filter } = Route.useSearch(); // page: number, filter?: string
    return <UserList page={page} filter={filter} />;
  },
});
```

### Real-World Deal-Breakers
- **Not using `validateSearch`** → search params are `string | undefined`; runtime errors from `parseInt(undefined)`.
- **Loader throws without error boundary** → route error boundary catches it; if none, app crashes.
- **No `staleTime` on loader prefetch** → loader prefetches, component refetches immediately. Set `staleTime` in the query options.
- **File-based routing without the Vite plugin** → route tree not generated; imports fail.

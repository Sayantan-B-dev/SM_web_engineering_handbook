## 14.2 Queries

### Subtopic Tree
- `useQuery` hook
- Query states: `isPending`, `isError`, `isSuccess`, `isFetching`
- Query function requirements (must throw/reject on error)
- Dependent queries (`enabled`)
- Parallel queries
- Query options factory (`queryOptions`)
- `useQueries` for dynamic parallel queries
- Background refetching
- `placeholderData` vs `initialData`
- `select` for data transformation

### Basic Query
```tsx
import { useQuery } from '@tanstack/react-query';

function Todos() {
  const { data, isPending, isError, error } = useQuery({
    queryKey: ['todos'],
    queryFn: async () => {
      const res = await fetch('/api/todos');
      if (!res.ok) throw new Error('Failed to fetch');
      return res.json();
    },
  });

  if (isPending) return <Spinner />;
  if (isError) return <Error error={error} />;
  return <ul>{data.map(t => <li key={t.id}>{t.text}</li>)}</ul>;
}
```

### Query Options Factory
```tsx
import { queryOptions } from '@tanstack/react-query';

const userOptions = (id: string) => queryOptions({
  queryKey: ['user', id],
  queryFn: () => fetchUser(id),
  staleTime: 5 * 60 * 1000,
});

// Usage
useQuery(userOptions(id));
queryClient.prefetchQuery(userOptions(id));
```

### `select` - Transform Data
```tsx
const { data: names } = useQuery({
  queryKey: ['users'],
  queryFn: fetchUsers,
  select: (users) => users.map(u => u.name), // data is string[]
});
```

### `placeholderData` vs `initialData`

| `initialData` | `placeholderData` |
|---------------|-------------------|
| Persisted to cache | Not persisted |
| `isPlaceholderData` is `false` | `isPlaceholderData` is `true` |
| Considered "real" data | Temporary until real data arrives |

### Real-World Deal-Breakers
- **Query function not throwing on error** → TanStack Query treats non-ok responses as success. Always `throw` or reject.
- **`initialData` for data that doesn't exist yet** → makes the query appear successful with empty data.
- **Not using `queryOptions` factory** → query keys and options scattered across files, hard to reuse in prefetch.
- **`enabled: false` without a dependent key** → query never runs; check that the key includes the dependency.

### v4 Performance (2026)
Tailwind CSS v4.3's new engine (Oxide) delivers **builds 5× faster than v3**. The final CSS file stays under 10 kB automatically. No manual cleanup needed. Tree-shaking happens automatically.

```css
/* v4 CSS-first config */
@theme {
  --color-primary: oklch(0.6 0.2 250);
  --font-sans: 'Inter', system-ui, sans-serif;
  --spacing-4: 1rem;
}
```

### Component Extraction, Not `@apply`
> "Build components, not CSS classes. In Tailwind v4, you create reusable UI through your framework. Extract your Button, Card, and Nav into actual React components. Drop the `@apply` habit. It was a workaround. Real components are the better answer."

### Class Ordering
```tsx
// Layout → sizing → typography → colors → states
<div className="flex items-center gap-4 w-full p-4 text-sm font-medium text-gray-900 bg-white hover:bg-gray-50">
```

### Real-World Deal-Breakers
- **`@apply` everywhere** → recreates the CSS architecture Tailwind was designed to avoid. Extract components instead.
- **No `tailwind-merge`** → conflicting classes (`p-2 p-4`) resolve unpredictably. Use `cn()`.
- **No class ordering convention** → class strings become unreadable walls.
- **Using PostCSS over Vite plugin** → 2-5× slower HMR.
- **Tailwind v3 patterns in v4** → `tailwind.config.js` is replaced by `@theme` in CSS.

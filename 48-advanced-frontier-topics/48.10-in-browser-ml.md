### Additional Pitfalls
- **Shipping a large model in the critical path.** Download size and memory decide feasibility, not benchmark scores.
- **No fallback.** Device and browser variance guarantee gaps.
- **Measuring only on a development machine.** Throttle and test on mid-tier hardware.
- **Telemetry leaking the input.** The privacy benefit disappears if prompts are logged.
- **Ignoring battery and thermals.** Sustained inference drains and throttles.

### Real-World Deal-Breakers
- **No WebGPU fallback** → 15% of users can't use the API. Provide WebGL/WASM fallback.
- **Large model loading without caching** → 8-12 seconds on Fast 3G. Use Cache API or OPFS.
- **Main-thread contention** → model inference on the main thread blocks React rendering. Use a Web Worker.

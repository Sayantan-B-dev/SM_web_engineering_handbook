## 48.11 AI Agents

### Subtopic Tree
- A2UI v0.9: Google's framework-agnostic standard for declaring UI intent
- AG-UI: Agent User Interaction Protocol
- MCP Apps: open-ended generative UI from Anthropic and OpenAI

- CrewAI + CopilotKit integration

### The Protocols
A2UI v0.9 allows **local or remote agents to communicate with any client application using a common language**, ensuring your agent can generate your UI using your existing component catalog on any device.

AG-UI (Agent User Interaction Protocol) enables developers to build interactive AI applications by combining a powerful backend (ADK) with a flexible frontend protocol.

WebMCP is a proposed open web standard that lets you **expose JavaScript functions and HTML forms as structured tools** to browser-based agents.

### PLASMA
PLASMA (Persistent Living Application Surface for Mutating Agents) is an **event-sourced protocol** that enables conversational AI agents to create, evolve, and maintain interactive web applications through **incremental mutations**.

### Deeper Explanation: Autonomy Is A Scope Decision

Agents at the frontier act across tools and systems, so the engineering question is no longer "does it work" but "what is it allowed to do, and how do we know it did it". That produces a small set of non-negotiables: a bounded loop (steps, time, cost), narrow tools with per-call authorisation, human approval for consequential actions, idempotency keys for every mutating call, and a complete trace of prompts, decisions, and results.

### Additional Pitfalls
- **Unbounded loops with production credentials.** The highest-risk configuration in this chapter.
- **Tools that expose broad capability.** One `run_sql` tool is an incident generator.
- **No audit trail.** You cannot investigate what happened or why.
- **Approvals designed as blanket gates.** They become rubber-stamps; gate by consequence.
- **Measuring only success rate.** Cost and steps per task are product metrics.

### Real-World Deal-Breakers
- **No max steps** → the agent loops forever. Cap iterations.
- **No tool validation** → the agent hallucinates tool names and arguments.
- **No human-in-the-loop for destructive actions** → the agent deletes production data.
- **No observability** → you can't debug agent decisions.

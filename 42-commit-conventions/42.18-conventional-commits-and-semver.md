## 42.9 Conventional Commits and SemVer

### Subtopic Tree
- The direct mapping: `fix` → PATCH, `feat` → MINOR, `BREAKING CHANGE` → MAJOR
- Automated version bumping
- Semantic Release
- Commitizen version management
- Pre-release cycles (alpha, beta, rc)

### The SemVer Mapping

| Commit type | SemVer bump | Example |
|-------------|-------------|---------|
| `fix` | PATCH | 1.2.3 → 1.2.4 |
| `perf` | PATCH | 1.2.3 → 1.2.4 |
| `feat` | MINOR | 1.2.3 → 1.3.0 |
| `BREAKING CHANGE:` or `!` | **MAJOR** | 1.2.3 → 2.0.0 |
| `docs`, `style`, `refactor`, `test`, `build`, `ci`, `chore` | None | No version bump |

### Automated Version Bumping
Tools like **semantic-release**, **Commitizen**, and **standard-version** read the commit history and automatically determine the next version:

```bash
# Commit history since last release:
feat(api): add user export
fix(auth): resolve token loop

# semantic-release determines: MINOR bump (feat present)
# New version: 1.2.3 → 1.3.0

# If the history included a BREAKING CHANGE:
# New version: 1.2.3 → 2.0.0
```

### Commitizen Version Management
Commitizen helps teams maintain consistent commit messages and **automatically manage version numbers using semantic versioning** and **generate and maintain changelogs**.

```bash
# Interactive commit with Commitizen
cz commit

# Bump version and update changelog
cz bump
```

### Pre-Release Cycles
```bash
# Alpha releases
feat(api): add experimental endpoint
# → 2.0.0-alpha.1

# Beta releases
fix(api): resolve alpha feedback
# → 2.0.0-beta.1

# Release candidate
feat(api): finalize endpoint
# → 2.0.0-rc.1

# Final release
# → 2.0.0
```

### Real-World Deal-Breakers
- **`fix` for a feature** → no MINOR bump. Consumers miss the feature because they don't upgrade.
- **`feat` for a breaking change** → MINOR bump instead of MAJOR. Consumers' code breaks on upgrade.
- **No `BREAKING CHANGE:` footer** → the MAJOR bump is missed. This is the **most dangerous commit convention mistake**.
- **`chore` for a user-facing change** → no version bump, but behavior changed. Consumers are confused.

### The Search Stack
```text
Query → Embed → Vector search (pgvector, Qdrant) → Top-K
     → Rerank (cross-encoder) → Results → Stream to UI
```

### Hybrid Search with Reranking
```typescript
async function search(query: string, limit = 10) {
  const embedding = await embed(query);

  const [vectorResults, keywordResults] = await Promise.all([
    vectorDB.search({ vector: embedding, limit: limit * 2 }),
    bm25Search(query, limit * 2),
  ]);

  const merged = reciprocalRankFusion([vectorResults, keywordResults]);
  const reranked = await crossEncoder.rerank(query, merged);
  return reranked.slice(0, limit);
}
```

### Streaming Search Results
```tsx
function AISearch() {
  const { messages, input, handleInputChange, handleSubmit } = useChat({
    api: '/api/search',
  });

    <>
      <form onSubmit={handleSubmit}>

      </form>
```

### Deeper Explanation: Search Ranks, AI Answers

The strongest search products are hybrid: retrieval finds the evidence deterministically, and the model composes an answer with citations. That split matters because each half fails differently:

- **Retrieval failures** (missing or irrelevant documents) cannot be fixed by prompting; they need chunking, hybrid search, and reranking.
- **Generation failures** (unsupported claims, ignoring context) are fixed with grounding instructions, citations, and validation.
- **Filter failures** (permissions, freshness, scope) are the security-critical ones: filter at query time, per user, and never rely on the model to exclude what it should not see.

Also design for the *follow-up*: an answer usually triggers a refined query, so keeping the retrieval context (documents + scores) around lets the next turn be cheap and precise.

### Additional Pitfalls
- **Answer-only UX with no sources.** Users cannot verify and you cannot debug; always show citations with links.
- **Retrieval without permission filters.** The most common data leak in AI features.
- **No "no results" behaviour.** The model will invent an answer from nothing; instruct and enforce an explicit empty state.
- **Ignoring latency budget.** Reranking plus generation can exceed 3 s; stream the answer and show sources as they arrive.
- **No feedback controls.** Thumbs and "report wrong answer" are the cheapest quality signals you will ever get.

### Real-World Deal-Breakers
- **Pure vector search for exact matches** → "React 19" and "React 18" are semantically similar. Use hybrid search.
- **No reranking** → top-K vector results are often not the most relevant.
- **No streaming** → users wait for all results before seeing anything.
- **No metadata filtering** → irrelevant results from the wrong category or time period.

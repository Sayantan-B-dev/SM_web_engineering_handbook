### The Mental Model
An agent is a model with **a loop and tools**: it reads files, writes code, runs commands, observes failures, and iterates. That makes it useful for tasks with objective feedback (a failing test, a type error, a broken build) and unreliable for tasks whose success is subjective (naming, architecture, product judgement).

The practical consequences:

- **Feedback loops are leverage.** Give the agent a fast, reliable verifier (`pnpm test`, `tsc --noEmit`, a smoke test) and its quality jumps. Without one it drifts confidently.
- **Repositories matter.** Clear structure, small files, consistent conventions, and good types make agents dramatically more effective â€” the same properties that help new humans.
- **Permissions are the safety boundary.** Filesystem scope, network access, and credentials granted to an agent determine the blast radius of a mistake.
- **Review is not optional.** Agent output is a *proposal*; the code review, tests, and CI are what make it production.

```bash
# A bounded, verifiable agent task: scope + acceptance + stop condition
# prompt: "In packages/api/src, add rate limiting to POST /orders so that a user
#          cannot exceed 5 requests/second. Accept: unit test proving the 6th
#          request is rejected, no changes outside this folder, run pnpm -w test api."
```

### Real-World Deal-Breakers
- **No verifier in the loop.** An agent without tests or a typechecker will confidently produce plausible, broken code.
- **Unlimited permission scope.** Agents with production credentials, network installs, and delete rights turn a mistake into an incident.
- **Vague task framing.** "Improve the codebase" produces churn; bounded tasks with acceptance criteria produce commits.
- **No diff review.** Merging agent output unread is how subtle regressions and licence problems ship.
- **Ignoring cost per task.** Long autonomous loops are metered; measure spend per merged change.
- **Treating agent chat as documentation.** Decisions belong in ADRs and commit messages, not in a discarded conversation.

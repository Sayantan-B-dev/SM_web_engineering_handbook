## 37.6 Security Headers

### Subtopic Tree
- `Content-Security-Policy`
- `Strict-Transport-Security` (HSTS)
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY` (or `frame-ancestors`)
- `Referrer-Policy`
- `Permissions-Policy`
- `Cross-Origin-Opener-Policy` (COOP)
- `Cross-Origin-Embedder-Policy` (COEP)
- `Cross-Origin-Resource-Policy` (CORP)
- `X-XSS-Protection: 0` (disable legacy auditor)

### The MANDATORY Headers (Every Response)
```typescript
app.use('*', async (c, next) => {
  await next();
  c.header('X-Content-Type-Options', 'nosniff');
  c.header('X-Frame-Options', 'DENY');
  c.header('X-XSS-Protection', '0');
  c.header('Referrer-Policy', 'strict-origin-when-cross-origin');
  c.header('Permissions-Policy', 'camera=(), microphone=(), geolocation=(), payment=()');
  c.header('Strict-Transport-Security', 'max-age=63072000; includeSubDomains; preload');
  c.header('Cross-Origin-Opener-Policy', 'same-origin');
  c.header('Cross-Origin-Embedder-Policy', 'require-corp');
  c.header('Cross-Origin-Resource-Policy', 'same-origin');
});
```
These are mandatory on every Worker response.

### Header Reference

| Header | Purpose | Recommended Value |
|--------|---------|-------------------|
| `Strict-Transport-Security` | Force HTTPS for future requests | `max-age=63072000; includeSubDomains; preload` |
| `X-Content-Type-Options` | Prevent MIME sniffing | `nosniff` |
| `X-Frame-Options` | Prevent clickjacking | `DENY` |
| `Referrer-Policy` | Control referrer leakage | `strict-origin-when-cross-origin` |
| `Permissions-Policy` | Disable unused browser features | `camera=(), microphone=(), geolocation=()` |
| `Cross-Origin-Opener-Policy` | Isolate browsing context | `same-origin` |
| `Cross-Origin-Embedder-Policy` | Enable cross-origin isolation | `require-corp` |
| `Cross-Origin-Resource-Policy` | Prevent cross-origin reads | `same-origin` |

---

### Deeper Explanation: Six Headers That Cover Most Browser Threats

| Header | Value (baseline) | Prevents |
|---|---|---|
| `Content-Security-Policy` | nonce-based `script-src`, `frame-ancestors 'none'`, `object-src 'none'`, `base-uri 'none'` | XSS execution, clickjacking, injection |
| `Strict-Transport-Security` | `max-age=63072000; includeSubDomains` | Downgrade and cookie theft |
| `X-Content-Type-Options` | `nosniff` | MIME confusion attacks |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | URL/token leakage to third parties |
| `Permissions-Policy` | deny what you do not use (`camera=(), microphone=()`) | Feature abuse in iframes |
| `Cross-Origin-Opener-Policy` / `-Embedder-Policy` | `same-origin` / `credentialless` | Cross-window attacks; enables isolation features |

Set them at the edge so error pages, static assets, and API responses all carry them consistently, and assert them in CI (a header regression is invisible until exploited).

### Additional Pitfalls
- **Headers only on the HTML document.** APIs and error pages need them too.
- **`X-Frame-Options` alone.** It cannot express allow-lists; use `frame-ancestors`.
- **CSP that breaks your app, then gets relaxed to `unsafe-inline`.** Fix the cause (nonce everything, remove inline handlers).
- **No CI assertion.** Someone will remove a header while debugging.
- **Ignoring `Permissions-Policy` for embedded widgets.** Third-party frames inherit capabilities they should not have.

### Real-World Deal-Breakers
- **No HSTS** → MITM downgrade to HTTP is possible. Add `Strict-Transport-Security` with a long max-age.
- **No `X-Content-Type-Options: nosniff`** → MIME sniffing attacks. Add it to every response.
- **No `X-Frame-Options`** → clickjacking. Use `DENY` or CSP's `frame-ancestors 'none'`.
- **No COOP/COEP** → no `SharedArrayBuffer`, no high-resolution timers, and no cross-origin isolation.
- **`X-XSS-Protection: 1`** → the legacy XSS auditor is buggy and can introduce vulnerabilities. Set it to `0` and rely on CSP.

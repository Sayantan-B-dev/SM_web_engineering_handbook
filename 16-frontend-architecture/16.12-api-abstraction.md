## 16.12 API Abstraction

### Subtopic Tree
- API client layer (no `fetch` in components)
- Generated clients (OpenAPI, tRPC, GraphQL codegen)
- Repository pattern
- Data transfer objects (DTOs)
- Adapters (API response → domain model)
- Error handling
- Caching (React Query, SWR)
- Retry and timeout policies
- Mocking for tests

### API Client Layer
```typescript
// ❌ Component fetches directly
function UserProfile({ id }) {
  const [user, setUser] = useState(null);
  useEffect(() => {
    fetch(`/api/users/${id}`).then(r => r.json()).then(setUser);
  }, [id]);
  return <h1>{user?.name}</h1>;
}

// ✅ Components use a hook backed by an API client
function UserProfile({ id }) {
  const { data } = useQuery(userQueries.detail(id));
  return <h1>{data.name}</h1>;
}

// api/userQueries.ts
export const userQueries = {
  detail: (id: string) => queryOptions({
    queryKey: ['user', id],
    queryFn: () => userApi.get(id),
  }),
};

// api/userApi.ts
export const userApi = {
  get: async (id: string): Promise<User> => {
    const res = await client.get(`/users/${id}`);
    return userAdapter.fromApi(res.data);
  },
};

// api/adapters/userAdapter.ts
export const userAdapter = {
  fromApi: (dto: UserDTO): User => ({
    id: dto.id,
    name: `${dto.first_name} ${dto.last_name}`,
    email: dto.email_address,
  }),
};
```

### Why Adapters?
API responses have a different shape than your domain model. `first_name`/`last_name` vs `name`. `email_address` vs `email`. **Adapters isolate your app from API changes.** When the backend renames a field, you change one adapter, not 40 components.

### Generated Clients
- **OpenAPI → TypeScript** - `openapi-typescript` generates types; `orval` generates typed clients + React Query hooks.
- **tRPC** - end-to-end type safety without codegen; server and client share types.
- **GraphQL Codegen** - generates typed hooks from your schema.

### Real-World Deal-Breakers
- **`fetch` scattered across components** → no error handling consistency, no retry, no caching.
- **No adapter layer** → backend renames a field; 40 components break.
- **Types not shared with backend** → drift; runtime errors in production.
- **No retry/timeout** → flaky networks break the app.
- **Mocking `fetch` in every test** → brittle. Mock the API client layer instead.

## 16.11 Dependency Boundaries

### Subtopic Tree
- Acyclic dependency graph
- Dependency direction rules (UI → domain, not reverse)
- Layered architecture enforcement
- Forbidden imports
- Circular dependency detection
- Tools: `dependency-cruiser`, `madge`, `eslint-plugin-boundaries`, `nx-enforce-module-boundaries`
- Public vs private APIs

### Enforcing Boundaries with ESLint
```json
// .eslintrc.json
{
  "plugins": ["boundaries"],
  "settings": {
    "boundaries/elements": [
      { "type": "ui", "pattern": "src/ui/*" },
      { "type": "features", "pattern": "src/features/*" },
      { "type": "shared", "pattern": "src/shared/*" }
    ]
  },
  "rules": {
    "boundaries/element-types": ["error", {
      "default": "disallow",
      "rules": [
        { "from": "ui", "allow": ["features", "shared"] },
        { "from": "features", "allow": ["shared"] },
        { "from": "shared", "allow": ["shared"] }
      ]
    }]
  }
}
```

### Circular Dependency Detection
```bash
# madge
npx madge --circular src/

# dependency-cruiser
npx depcruise --validate .dependency-cruiser.js src/
```

```javascript
// .dependency-cruiser.js
module.exports = {
  forbidden: [
    {
      name: 'no-circular',
      severity: 'error',
      from: {},
      to: { circular: true },
    },
    {
      name: 'no-ui-to-features',
      severity: 'error',
      from: { path: '^src/ui' },
      to: { path: '^src/features' },
    },
  ],
};
```

### Real-World Deal-Breakers
- **No enforcement** → boundaries decay within weeks. Lint rules are the only way.
- **Circular dependencies** → subtle runtime bugs, broken tree-shaking.
- **Reaching into internals** → `import { internalFn } from '@/features/auth/private/utils'`. Use public APIs.
- **No CI check** → boundaries violated in a PR nobody notices.

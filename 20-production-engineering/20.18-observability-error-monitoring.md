### Error Boundary + Monitoring
```tsx
class ErrorBoundary extends React.Component {
  componentDidCatch(error: Error, errorInfo: React.ErrorInfo) {
    // Send to Sentry / Datadog / Faro
    captureException(error, { extra: errorInfo });
  }

  render() {
    if (this.state.hasError) {
      return <ErrorFallback />;
    }
    return this.props.children;
  }
}
```

### Datadog RUM (Micro-Frontends)
Datadog RUM supports micro-frontend architectures with a build plugin that **automatically attributes frontend telemetry data to the correct service and version at runtime** - no manual instrumentation.

### Real-World Deal-Breakers
- **No sourcemaps uploaded** → stack traces are minified; errors are undebuggable.
- **No PII filtering** → user data (emails, tokens) logged to third-party services.
- **No error boundaries** → a single component error crashes the entire app.
- **No release tracking** → you can't correlate errors with deploys. Always tag errors with `app.version`.

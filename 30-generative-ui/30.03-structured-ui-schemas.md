### The Mental Model
Generative UI works because the model does not emit HTML â€” it emits **a tree of your components described by a schema you control**. That single constraint turns an unconstrained text problem into a validation problem: any output can be checked, repaired, or rejected before it reaches the renderer. The schema is therefore the most important design artifact in the feature; the prompt is an implementation detail of it.

Three design rules keep it safe and useful:

- **Bounded vocabulary.** Components come from a fixed registry, props use enums and unions, and free text is confined to a small number of string fields.
- **No arbitrary values in structural fields.** No URLs, no HTML, no style objects. A `href` must be a key the app resolves, never a model-supplied link.
- **Composition, not DOM.** The model assembles your primitives (`Card`, `Metric`, `Table`, `Form`) and never invents layout with raw markup.

```ts
import { z } from 'zod';

const Metric = z.object({ type: z.literal('metric'), label: z.string().max(40), value: z.number(), unit: z.enum(['usd', 'pct', 'count']).optional() });
const Table = z.object({ type: z.literal('table'), columns: z.array(z.string().max(24)).min(1).max(6), rows: z.array(z.array(z.union([z.string(), z.number(), z.null()]))).max(50) });
const Section = z.object({ type: z.literal('section'), title: z.string().max(60).optional(), children: z.array(Metric).max(4).optional(), table: Table.optional() });
const AssistantReply = z.object({ type: z.literal('reply'), message: z.string().max(600), sections: z.array(Section).max(6) });

export type AssistantReply = z.infer<typeof AssistantReply>;
```

### Real-World Deal-Breakers
- **Free-form HTML from the model.** XSS and unstylable UI in one move; always render through a schema and a registry.
- **Unbounded arrays and strings.** A 5 000-row table will freeze the tab; constrain with `.max()` and paginate.
- **Raw URLs in the schema.** The model can be manipulated into emitting phishing links; map keys to routes instead.
- **No schema version.** Cached payloads and logs must map to the schema that produced them.
- **Validation skipped on the client side only.** Validate where you render *and* where you persist.
- **Letting the model choose arbitrary component names.** Registry lookups by model-supplied strings invite typos and dead ends; use a discriminated union instead.

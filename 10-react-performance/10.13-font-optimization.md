## 10.13 Font Optimization

### Subtopic Tree
- Self-host fonts (avoid external requests)
- `.woff2` format (best compression)
- `font-display: swap` / `optional`
- Preload critical fonts
- Subset fonts (latin only, if applicable)
- System font stack (zero cost)
- `size-adjust` / metric overrides to reduce CLS
- Variable fonts (one file, many weights)

### The Font Loading Problem
Web fonts block text rendering. A user stares at invisible text (FOIT) or a flash of unstyled text (FOUT) while the font downloads.

### Best Practices

**1. Self-host:**
```html
<link rel="preload" as="font" type="font/woff2" href="/fonts/Inter-var.woff2" crossorigin />
```
Self-hosting avoids a connection to Google Fonts (DNS + TLS + request). Preload starts the fetch with the HTML.

**2. `font-display: swap`:**
```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter-var.woff2') format('woff2');
  font-display: swap; /* show fallback immediately, swap when font loads */
}
```

**3. Subset:**
If you only need Latin characters, subset the font to Latin - a 300KB font becomes 40KB.

**4. Variable fonts:**
One variable font file covers all weights (100-900) vs. multiple static files.

**5. System font stack:**
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```
Zero network cost, instant render. Use this if you don't need a custom font.

**6. `size-adjust` to reduce CLS:**
```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter.woff2') format('woff2');
  size-adjust: 100.06%; /* match fallback metrics */
}
```
Matches the custom font's metrics to the fallback → less layout shift when the font swaps in.

### Next.js `next/font`
Downloads font files at build time, self-hosts them, preloads them, and applies `font-display: swap` automatically - no additional network requests at runtime.

### Real-World Deal-Breakers
- **Google Fonts `<link>` without preconnect** → extra DNS + TLS + request before text can render.
- **No `font-display`** → text is invisible (FOIT) until the font loads.
- **Loading 8 font weights when you use 2** → 8× the download.
- **No subsetting** → downloading Cyrillic, Greek, and Vietnamese glyphs for a Latin-only site.
- **Custom font when system fonts would do** → unnecessary network cost and complexity.

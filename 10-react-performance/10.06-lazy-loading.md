## 10.6 Lazy Loading

### Subtopic Tree
- `React.lazy` + `Suspense`
- Dynamic `import()`
- Route-based lazy loading
- Component-level lazy loading
- Conditional lazy loading (on interaction)
- `next/dynamic` (Next.js)
- Preloading lazy components
- Lazy loading vs code splitting relationship

### Syntax
```jsx
import { lazy, Suspense } from 'react';

const HeavyChart = lazy(() => import('./HeavyChart'));

function Dashboard() {
  return (
    <Suspense fallback={<Spinner />}>
      <HeavyChart />
    </Suspense>
  );
}
```

### Route-Based Lazy Loading
```jsx
const Home = lazy(() => import('./routes/Home'));
const About = lazy(() => import('./routes/About'));
const Dashboard = lazy(() => import('./routes/Dashboard'));

<BrowserRouter>
  <Suspense fallback={<LoadingSpinner />}>
    <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/about" element={<About />} />
      <Route path="/dashboard" element={<Dashboard />} />
    </Routes>
  </Suspense>
</BrowserRouter>
```
Each route becomes a separate chunk. Users downloading the dashboard don't download the reports code.

### Component-Level Lazy Loading
```jsx
const HeavyDataTable = lazy(() => import('./HeavyDataTable'));

function Dashboard() {
  const [showTable, setShowTable] = useState(false);
  return (
    <>
      <button onClick={() => setShowTable(true)}>Show Table</button>
      {showTable && (
        <Suspense fallback={<div>Loading table...</div>}>
          <HeavyDataTable />
        </Suspense>
      )}
    </>
  );
}
```
The table's JS only downloads when the user clicks the button.

### Preloading
A dynamic import is a network request - the interaction that triggers it has a gap the user reads as a broken button. Preload on hover or idle:
```jsx
// Preload on mouse enter
<button onMouseEnter={() => import('./HeavyChart')} onClick={() => setShow(true)}>
  Show Chart
</button>
```

### `React.lazy` Constraint
The dynamic import **must return a module with a `default` export**:
```jsx
// ✅
const Comp = lazy(() => import('./Comp')); // './Comp' has default export

// ❌ Throws
const Comp = lazy(() => import('./utils')); // named exports only
```

### Real-World Deal-Breakers
- **Lazy-loading components needed on first paint** → adds a round trip before content shows; keep above-the-fold components eager.
- **No Suspense wrapper** → runtime error.
- **Lazy-loading a tiny component** → overhead (extra chunk request) outweighs benefit; only lazy-load heavy/rare components.
- **No preload for interactive-triggered chunks** → a click feels broken while the chunk downloads.
- **Lazy loading during SSR without `next/dynamic`** → `React.lazy` isn't SSR-compatible; use `next/dynamic` with `ssr: false`.

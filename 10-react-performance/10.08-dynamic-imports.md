## 10.8 Dynamic Imports

### Subtopic Tree
- `import()` syntax (returns Promise)
- `import()` vs `React.lazy` vs `next/dynamic`
- Conditional imports (feature flags, user actions)
- `import.meta.glob` (Vite)
- Importing non-React modules (utils, data, WASM)
- Error handling for failed chunk loads
- Retry logic for chunk load failures

### Syntax
```javascript
// Returns a Promise for the module namespace object
const module = await import('./heavy-module');
module.default;  // default export
module.named;    // named export

// Destructured
const { heavyFn, config } = await import('./heavy-module');
```

### Conditional Dynamic Imports
```javascript
// Feature flag
if (ENABLE_ANALYTICS) {
  import('./analytics').then(m => m.init());
}

// User action
async function openEditor() {
  const { Editor } = await import('./Editor');
  editor = new Editor(document.getElementById('root'));
}

// Environment
if (import.meta.env.DEV) {
  import('./dev-tools');
}
```

### Vite `import.meta.glob`
```javascript
// Eagerly import all markdown files (bundled)
const docs = import.meta.glob('./docs/*.md', { eager: true });

// Lazy import all markdown files (separate chunks)
const docs = import.meta.glob('./docs/*.md');
// docs['./docs/intro.md']() → Promise<module>
```

### Error Handling
Chunk load failures happen (deploys, network). Always handle:
```javascript
try {
  const { Chart } = await import('./Chart');
  new Chart(...);
} catch (err) {
  // Retry once, then fall back to a static component
  console.error('Failed to load Chart:', err);
  showFallback();
}
```

### Real-World Deal-Breakers
- **No error handling on dynamic import** → a deploy-time chunk hash mismatch → white screen for users with stale sessions.
- **`import()` inside render without memoization** → fires a network request every render.
- **Importing a module for its side effects only via `import()`** → the chunk loads but nothing runs unless you call the side effect.
- **Assuming `import()` returns `default`** → it returns the module namespace; use `.default` or destructure named exports.

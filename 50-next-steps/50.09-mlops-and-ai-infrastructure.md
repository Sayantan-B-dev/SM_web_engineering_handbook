### The Lifecycle

```text
collect      -> usage traces, thumbs, golden set, domain documents
build        -> prompt version, retrieval config, model choice, tools
evaluate     -> offline harness + online A/B; gate on both
deploy       -> versioned prompt + model, canary, feature flag
monitor      -> quality, latency, cost, refusals, hallucinations
iterate      -> back to build with evidence, not vibes
```

The difference from classic MLOps: the "model" is often a *prompt plus retrieval configuration*, and it changes several times a week rather than monthly. That means your release process, not your training pipeline, is the critical path.

### Evaluation Gates

```typescript
type EvalCase = {
  id: string;
  input: string;
  expected: { contains?: string[]; notContains?: string[]; matches?: RegExp };
};

export async function runEval(cases: EvalCase[], prompt: PromptVersion) {
  const results = await Promise.all(cases.map(async (c) => {
    const out = await callModel(prompt, c.input);
    const pass =
      (c.expected.contains ?? []).every((s) => out.includes(s)) &&
      (c.expected.notContains ?? []).every((s) => !out.includes(s)) &&
      (!c.expected.matches || c.expected.matches.test(out));
    return { id: c.id, pass, out };
  }));

  const passRate = results.filter((r) => r.pass).length / results.length;
  return { passRate, results, gateOk: passRate >= 0.95 };   // CI blocks below the gate
}
```

A prompt change without an evaluation run is a refactor with no tests. It will silently degrade quality - usually on the edge cases that matter most.

### Cost Control

```text
Cache         exact-match responses (normalised prompt hash)         biggest win
Route         small model first, escalate on low confidence          high volume
Batch         non-urgent work in batches at a discount               exports, digests
Constrain     max tokens, structured output, stop sequences          prevents runaways
Deduplicate   identical concurrent requests -> single in-flight call  burst protection
```

```typescript
// Deduplicate concurrent identical requests: a common burst pattern in dashboards
const inFlight = new Map<string, Promise<Response>>();

export function memoCall(key: string, fn: () => Promise<Response>) {
  const existing = inFlight.get(key);
  if (existing) return existing;
  const p = fn().finally(() => inFlight.delete(key));
  inFlight.set(key, p);
  return p;
}
```

### Observability For AI

| Signal | Why |
|---|---|
| Tokens in/out per route and user | cost allocation and abuse detection |
| Latency to first token | perceived speed |
| Refusal and parse-failure rate | quality regression signal |
| Citation coverage (RAG) | grounding health |
| Cost per active user per day | unit economics |

### Deeper Explanation: The Discipline Is The Evaluation Set

Anyone can wire an LLM call. The professional differentiator is the **evaluation set** - a curated collection of real inputs with expected properties - and the discipline to run it before every prompt or model change.

Without it, every improvement is a guess and every regression is discovered by users. With it, prompt engineering becomes engineering: measurable, reversible, and defensible in review.

### Additional Pitfalls

- **No evaluation on prompt changes.** Quality drifts downward in ways nobody can attribute.
- **One model for all tasks.** Paying premium prices for classification work.
- **Logging full prompts and responses.** PII in telemetry, and prompts may contain customer data.
- **No timeout or cancellation.** A stalled provider call holds a request slot and a customer.
- **Fine-tuning before retrieval.** RAG is faster to ship, cheaper to change, and adequate for most needs.

### Real-World Deal-Breakers
- **No spend cap** - one runaway loop or abusive user produces a five-figure invoice.
- **No evaluation gate** - a prompt "improvement" ships with worse output and no way to prove it.
- **PII into third-party prompts without a data agreement** - a compliance and contractual breach.
- **No fallback model** - one provider incident takes the product's AI features down entirely.

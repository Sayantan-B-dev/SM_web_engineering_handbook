## 9.6 Compiler Configuration

### Subtopic Tree
- Babel plugin options
- `compilationMode` (`infer`, `annotation`, `syntax`, `all`)
- Memoization options
- Validation options

- `enableReanimatedCheck`
- Logger

### Basic Configuration
```javascript
// babel.config.js
module.exports = {
  plugins: [
    ['babel-plugin-react-compiler', {
      // Configuration options here
    }],
  ],
};
```

### `compilationMode`
Controls which functions the compiler optimizes.

| Mode | Behavior |
|------|----------|
| `'infer'` (default) | Intelligent heuristics: PascalCase components, `use` hooks, JSX creators |
| `'annotation'` | Only functions with `"use memo"` |
| `'syntax'` | Only Flow component/hook syntax (won't work with TypeScript) |
| `'all'` | Compile all top-level functions (may compile non-React functions) |

```javascript
module.exports = {
  plugins: [
    ['babel-plugin-react-compiler', {
      compilationMode: 'infer', // default
    }],
  ],
};
```

### File-Based Configuration (`sources`)
```javascript
module.exports = {
  plugins: [
    ['babel-plugin-react-compiler', {
      sources: (filename) => {
        // Don't compile test files
        if (filename.includes('__tests__')) return 'none';

        // Opt-in for new features
        if (filename.includes('src/features/new')) return 'opt-in';

        // Opt-out for legacy code
        if (filename.includes('src/legacy')) return 'opt-out';

        // Compile all others
        return 'all';
      },
    }],
  ],
};
```

### Memoization Options

| Option | Default | Purpose |
|--------|---------|---------|
| `enablePreserveExistingMemoizationGuarantees` | `true` | Preserve `useMemo`/`useCallback` referential equality guarantees |
| `validatePreserveExistingMemoizationGuarantees` | `true` | Validate that manual memoized values are also memoized by compiler |
| `enablePreserveExistingManualUseMemo` | `false` | Keep existing `useMemo`/`useCallback` calls instead of pruning |

### Validation Options

| Option | Default | Checks |
|--------|---------|--------|
| `validateHooksUsage` | `true` | Rules of Hooks (conditional calls, loops, nested) |
| `validateRefAccessDuringRender` | `true` | `ref.current` not accessed during render |
| `validateNoSetStateInRender` | `true` | No unconditional `setState` during render |
| `validateNoSetStateInEffects` | `false` | No synchronous `setState` in effects |
| `validateExhaustiveMemoizationDependencies` | `true` | Manual memo deps are exhaustive |
| `validateExhaustiveEffectDependencies` | `'off'` | Effect deps: `'off'` / `'all'` / `'missing-only'` / `'extra-only'` |
| `validateMemoizedEffectDependencies` | `false` | Effect deps are memoized (prevent infinite renders) |
| `validateNoDerivedComputationsInEffects` | `false` | No derived data computed in effects |

### Real-World Deal-Breakers
- **`compilationMode: 'all'`** → may compile utility functions, causing incorrect optimizations.
- **Disabling validation rules** → compiler may miss real bugs.
- **`enablePreserveExistingManualUseMemo: true`** → double memoization (manual + compiler) adds overhead.
- **`sources` function returning wrong mode** → files you think are compiled aren't (or vice versa).

## 9.9 Compiler Performance

### Subtopic Tree
- Build time impact
- Bundle size impact
- Runtime performance gains
- React DevTools verification
- Benchmarking
- Rust port (3x-10x faster)
- When compiler isn't enough

### Build Time Impact
- React Compiler runs as a Babel plugin, so it adds overhead to every build.
- **Rust port** (2026): ~3x faster than TypeScript original, up to 10x in isolated transforms. Vercel reported **>40% faster compilation** on v0.

### Bundle Size Impact
- Code size increases are kept **minimal** to not impact initial load.
- Real-world measurement: ~400 components compiled → bundle: 6.03 MB → 6.25 MB (**+3.6%**).
- With Rolldown integration: **17% increase** to bundler binary size (not app bundle).

### Runtime Performance Gains
- **30% cheaper re-renders** on average in one large codebase adoption.
- **Fewer re-renders** - JSX memoization prevents child re-renders when props haven't changed.
- **More granular than manual memoization** - conditional memoization, per-scope recalculation.

### Verification
React DevTools shows a **"Memo ✨" badge** on optimized components. If the badge is missing, the component wasn't optimized (check for violations).

### When Compiler Isn't Enough
> **"React Compiler reduces routine memoization, but it does not eliminate legitimate performance bottlenecks."**

Situations where you still need to profile and optimize manually:
- **Algorithmic complexity** - no compiler can fix O(n²) logic.
- **Network waterfalls** - data fetching patterns need architectural changes.
- **Large lists** - virtualization (`react-window`, TanStack Virtual) is still needed.
- **Web Workers** - CPU-heavy work still needs off-main-thread processing.
- **Bundle size** - code splitting and tree shaking are separate concerns.

### Benchmarking
Use:
- **React Profiler** - measure render times before/after.
- **Lighthouse** - overall performance scores.
- **React DevTools** - verify "Memo ✨" badge.
- **Bundle analyzer** - measure size impact.

### Real-World Deal-Breakers
- **Enabling compiler without measuring** → you don't know if it helped or hurt.
- **Assuming compiler fixes all performance issues** → algorithmic problems remain.
- **Not checking "Memo ✨" badge** → components may be silently skipped.
- **Build time regression on large codebases** → consider Rust port or selective compilation.
- **Bundle size growth > 5%** → review compiled output; may indicate over-memoization.

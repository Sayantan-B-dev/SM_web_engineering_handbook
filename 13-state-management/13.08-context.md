## 13.8 Context

### Subtopic Tree
- `createContext` + `useContext`
- Provider / consumer
- Default values
- Re-render behavior (all consumers re-render on value change)
- Splitting context for performance
- Context vs prop drilling
- When NOT to use context

### Basic Context
```jsx
const ThemeContext = createContext('light');

function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Toolbar />
    </ThemeContext.Provider>
  );
}

function Toolbar() {
  const theme = useContext(ThemeContext);
  return <div className={theme}>Toolbar</div>;
}
```

### Performance: Split Contexts
```jsx
// ❌ Single context - all consumers re-render on any change
const AppContext = createContext();
<AppContext.Provider value={{ user, theme, cart }}>
  {children}
</AppContext.Provider>

// ✅ Split - only relevant consumers re-render
<UserContext.Provider value={user}>
  <ThemeContext.Provider value={theme}>
    <CartContext.Provider value={cart}>
      {children}
    </CartContext.Provider>
  </ThemeContext.Provider>
</UserContext.Provider>
```

### Context + Reducer Pattern
```jsx
const StateContext = createContext();
const DispatchContext = createContext();

function Provider({ children }) {
  const [state, dispatch] = useReducer(reducer, initial);
  return (
    <StateContext.Provider value={state}>
      <DispatchContext.Provider value={dispatch}>
        {children}
      </DispatchContext.Provider>
    </StateContext.Provider>
  );
}
```
Consumers that only dispatch don't re-render on state changes.

### When NOT to Use Context
- **Prop drilling 1-2 levels** → just pass props.
- **Frequently changing data** → re-renders all consumers.
- **Local UI state** → keep it local.
- **Server state** → use React Query.

### Real-World Deal-Breakers
- **Unmemoized provider value** → all consumers re-render on every provider render.
```jsx
// ❌ New object every render
<Ctx.Provider value={{ user, login }}>
```
- **Context for global state** → "context hell", unnecessary re-renders.
- **Missing default/sentinel** → `useContext(Ctx)` returns `undefined`; runtime error.
- **Provider inside a component that re-renders frequently** → all consumers re-render.

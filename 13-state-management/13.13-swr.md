### Basic Usage
```tsx
import useSWR from 'swr';

const fetcher = (url) => fetch(url).then(r => r.json());

function Profile() {
  const { data, error, isLoading } = useSWR('/api/user', fetcher);

  if (isLoading) return <Spinner />;
  if (error) return <Error />;
  return <h1>{data.name}</h1>;
}
```

### Key Features
- **Stale-while-revalidate** - return cached data immediately, revalidate in background.
- **Automatic revalidation** - on focus, reconnect, interval.
- **Deduplication** - multiple components using the same key share one request.
- **Mutations** - optimistic updates with `mutate()`.

### Real-World Deal-Breakers
- **Not setting a `revalidateOnFocus` policy** → refetches on every tab focus; may be undesired.
- **Using `useSWR` for mutations** → use `useSWRMutation` or `mutate`.
- **No error handling** → silent failures.

### What Tool Calling Is
Function calling provides a way to control the output of LLMs so they generate structured responses more reliably. When you use a function call, you describe the function parameters using a JSON schema in the API call. The LLM itself doesn't call these functions - it generates the call, and **you execute it**.

```typescript
const tools = [
  {
    type: 'function',
    function: {
      name: 'get_weather',
      description: 'Get current weather for a location',
      parameters: {
        type: 'object',
        properties: {
          location: { type: 'string', description: 'City name' },
          unit: { type: 'string', enum: ['celsius', 'fahrenheit'] },
        },
        required: ['location'],
      },
    },
  },
];

const response = await openai.chat.completions.create({
  model: 'gpt-4.1',
  messages: [{ role: 'user', content: 'What is the weather in Kolkata?' }],
  tools,
  tool_choice: 'auto',
});

// The model returns a tool call, not a text response
if (response.choices[0].message.tool_calls) {
  const call = response.choices[0].message.tool_calls[0];
  const args = JSON.parse(call.function.arguments);
  // args = { location: 'Kolkata', unit: 'celsius' }

  // YOU execute the function
  const weather = await getWeather(args.location, args.unit);

  // Send the result back to the model
  const finalResponse = await openai.chat.completions.create({
    model: 'gpt-4.1',
    messages: [
      ...messages,
      response.choices[0].message,
      { role: 'tool', tool_call_id: call.id, content: JSON.stringify(weather) },
    ],
  });
}
```

### Tool Calling vs Structured Outputs

| Tool Calling | Structured Outputs |
|-------------|-------------------|
| Model invokes a function | Model returns JSON matching a schema |
| For actions (DB queries, API calls) | For data extraction |
| Multi-turn (call → result → respond) | Single-turn |
| Model decides **when** to call | You force the shape |

**Rule:** If the output will drive a database query, order creation, task queue, workflow, or third-party API call, use Function Calling. If you just need a parseable JSON object with no external action, use Structured Outputs.

### Real-World Deal-Breakers
- **Trusting tool arguments without validation** → the model can hallucinate arguments. Always validate with Zod or similar.
- **No tool error handling** → if a tool fails, the model doesn't know. Return structured errors so it can retry.
- **Too many tools** → the model gets confused. Keep tool count under 10-15.
- **No `tool_choice` control** → the model may call a tool when you want a text response. Use `tool_choice: 'none'` or `'required'`.

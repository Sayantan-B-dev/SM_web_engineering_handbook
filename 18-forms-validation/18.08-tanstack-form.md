## 18.2 TanStack Form

### Subtopic Tree
- Framework-agnostic core + React adapter
- `useForm` hook
- `form.Field` render prop pattern
- `form.Field` `children` as function
- Validators: `onChange`, `onBlur`, `onSubmit`, `onChangeAsync`, `onBlurAsync`
- Field-level subscriptions
- `form.Subscribe`
- `form.setFieldValue`
- Array fields (`mode="array"`)
- Zod integration
- DevTools
- v1 stable (32+ releases in 30 days)

### The Core Differentiator
TanStack Form optimizes for **TypeScript type inference throughout the entire form lifecycle**. It has **first-class TypeScript inference that React Hook Form can't match**. Field APIs expose typed state, synchronous and asynchronous validators, and explicit subscriptions.

**Best for:** Large typed forms with nested values, custom validation timing, async validation, framework portability (React, Vue, Angular, Solid, Lit).

### Basic Usage
```tsx
import { useForm } from '@tanstack/react-form';
import { z } from 'zod';

const schema = z.object({
  email: z.string().email(),
  password: z.string().min(8),
});

function LoginForm() {
  const form = useForm({
    defaultValues: { email: '', password: '' },
    validators: {
      onChange: schema,
    },
    onSubmit: async ({ value }) => {
      await login(value);
    },
  });

  return (
    <form onSubmit={(e) => { e.preventDefault(); form.handleSubmit(); }}>
      <form.Field
        name="email"
        children={(field) => (
          <>
            <input
              value={field.state.value}
              onChange={(e) => field.handleChange(e.target.value)}
              onBlur={field.handleBlur}
            />
            {field.state.meta.errors.length > 0 && (
              <span role="alert">{field.state.meta.errors.join(', ')}</span>
            )}
          </>
        )}
      />
      <button type="submit">Login</button>
    </form>
  );
}
```

### Field-Level Subscriptions
Unlike RHF, TanStack Form gives you **typed field state** with explicit subscriptions. Only the component using `form.Field` re-renders when that field changes.

### Async Validation
```typescript
<form.Field
  name="username"
  validators={{
    onChangeAsync: async ({ value }) => {
      const available = await checkUsername(value);
      return available ? undefined : 'Username taken';
    },
    onChangeAsyncDebounceMs: 500,
  }}
  children={(field) => ...}
/>
```

### Array Fields
```tsx
<form.Field name="items" mode="array">
  {(field) => (
    <>
      {field.state.value.map((_, i) => (
        <form.Field key={i} name={`items[${i}].name`}>
          {(subField) => <input value={subField.state.value} onChange={...} />}
        </form.Field>
      ))}
      <button onClick={() => field.pushValue({ name: '' })}>Add</button>
    </>
  )}
</form.Field>
```

### Real-World Deal-Breakers
- **API is still evolving** → TanStack Form v1 is stable but newer than RHF. Expect more breaking changes.
- **Smaller ecosystem** → fewer tutorials, fewer UI-kit integrations. Most shadcn/ui docs default to RHF.
- **More verbose than RHF** → the render-prop pattern is more explicit but requires more code.
- **Not needed for simple forms** → RHF is the safer default for most product forms.

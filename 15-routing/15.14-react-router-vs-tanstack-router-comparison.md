## 15.13 React Router vs TanStack Router - Comparison

### Subtopic Tree
- Routing philosophy: UI-first vs state-first
- Type safety: manual vs inferred
- Data loading: loaders vs loaders + SWR caching
- Search params: manual parsing vs Zod validation
- Error boundaries: `ErrorBoundary` export vs `errorComponent`
- Preloading: limited vs intent/viewport/render
- Framework: React Router Framework mode vs TanStack Start
- Maturity: 2014 vs 2023

### Comparison Table

| Feature | React Router v7 | TanStack Router |
|---------|----------------|-----------------|
| **Philosophy** | UI-first | State-first |
| **Type safety** | Manual (codegen in Framework mode) | 100% inferred from route tree |
| **Search params** | Manual parsing | Zod validation, structured JSON |
| **Loaders** | `loader` function | `loader` + `loaderDeps` + SWR caching |
| **Error boundaries** | `ErrorBoundary` export | `errorComponent` per route |
| **Preloading** | Limited | `intent`, `viewport`, `render` |
| **File-based routing** | Framework mode only | First-class, recommended |
| **Full-stack** | Framework mode (Remix) | TanStack Start |
| **Maturity** | Since 2014 | Stable v1 December 2023 |

### When to Choose

| Choose React Router v7 | Choose TanStack Router |
|------------------------|----------------------|
| Team already knows React Router | Team wants maximum type safety |
| Need framework mode with SSR | Treat URL as first-class state |
| Prefer UI-first mental model | Prefer state-first mental model |
| Need largest ecosystem | Want built-in SWR caching |
| Migrating from v6 | Starting greenfield with TypeScript |

### Real-World Deal-Breakers
- **Choosing without evaluating both** → migrating later is costly.
- **React Router for a TypeScript-heavy app with complex URL state** → TanStack Router's type inference is significantly better.
- **TanStack Router for a team unfamiliar with TypeScript** → the type-first philosophy has a learning curve.
- **Assuming TanStack Router is "new and unstable"** → stable since December 2023, production adoption at scale.

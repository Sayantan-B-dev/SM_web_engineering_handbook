### Three Modes of React Router v7
React Router v7 ships in **three modes**, each building on the last: Declarative, Data, and Framework.

| Mode | Configuration | Capabilities |
|------|--------------|-------------|
| **Declarative** | `<BrowserRouter>` + `<Routes>` | `<Link>`, `useNavigate`, URL-to-component matching only |
| **Data** | `createBrowserRouter` + `<RouterProvider>` | Loaders, actions, `useFetcher`, pending states |
| **Framework** | Vite plugin + file conventions | SSR, codegen, type-safe href, rendering strategies |

### Declarative Mode
```jsx
import { BrowserRouter, Routes, Route, Link } from 'react-router';

function App() {
  return (
    <BrowserRouter>
      <nav><Link to="/">Home</Link> <Link to="/about">About</Link></nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/users/:userId" element={<UserPage />} />
      </Routes>
    </BrowserRouter>
  );
}
```

### Data Mode
```jsx
import { createBrowserRouter, RouterProvider } from 'react-router';

const router = createBrowserRouter([
  {
    path: '/',
    Component: Root,
    children: [
      { index: true, Component: Home },
      {
        path: 'users/:userId',
        loader: userLoader,
        Component: UserPage,
      },
    ],
  },
]);

function App() {
  return <RouterProvider router={router} />;
}
```

### Framework Mode
Framework mode wraps data mode with a Vite plugin, turning React Router into the Remix architecture. It adds **type-safe href**, a codegen-based Route Module API, intelligent code splitting, and a choice of SPA, SSR, or static rendering strategies.

### Real-World Deal-Breakers
- **Using Declarative mode for data-heavy apps** → no loaders, no actions, manual fetching with `useEffect`.
- **Mixing modes in one app** → confusing mental model. Pick one.
- **`createBrowserRouter` without `<RouterProvider>`** → router never mounted; blank page.
- **Assuming Framework mode is required for SSR** → Data mode can work with external SSR setups; Framework mode is opinionated.

## 15.2 React Router v7 (Deep Dive)

### Subtopic Tree
- v7 breaking changes from v6
- `react-router` as single package (no more `react-router-dom`)
- Route Module API (`loader`, `action`, `Component`, `ErrorBoundary`)
- Type-safe href (`href()` function)
- Code splitting via `lazy`
- `shouldRevalidate` for controlling revalidation
- Data strategy (`dataStrategy`)
- Middleware (v7.3+)
- `useFetcher` vs `useSubmit`
- `HydrateFallback` for client loaders

### v7 Breaking Changes
- **Single package** - `react-router-dom` is merged into `react-router`. Import everything from `react-router`.
- **`json()` and `defer()` removed** - return raw objects/`Promise` directly.
- **`useLoaderData` type inference** - via codegen in Framework mode.
- **Middleware** - new middleware system (v7.3+).
- **`future` flags from v6 are now defaults**.

### Route Module API
Route modules are the foundation of React Router's data features. They define data loading, actions, revalidation, error boundaries, and more.

```tsx
// routes/user.tsx
import type { Route } from './+types/user';

export async function loader({ params }: Route.LoaderArgs) {
  return { user: await getUser(params.userId) };
}

export async function action({ request }: Route.ActionArgs) {
  const formData = await request.formData();
  return await updateUser(formData);
}

export function ErrorBoundary({ error }: Route.ErrorBoundaryProps) {
  return <div>Error: {error.message}</div>;
}

export default function UserPage({ loaderData }: Route.ComponentProps) {
  return <h1>{loaderData.user.name}</h1>;
}
```

### `useFetcher` vs `useSubmit`

| | `useFetcher` | `useSubmit` |
|--|-------------|------------|
| Navigation | No | Yes (adds history entry) |
| Use case | Like, toggle, inline edit, autocomplete | Form submission with navigation |
| State | Per-fetcher independent state | Global navigation state |

```tsx
// useFetcher - no navigation, background sync
function LikeButton({ postId }) {
  const fetcher = useFetcher();
  return (
    <fetcher.Form method="post" action={`/posts/${postId}/like`}>
      <button>{fetcher.state === 'submitting' ? '...' : 'Like'}</button>
    </fetcher.Form>
  );
}
```

### Real-World Deal-Breakers
- **Importing from `react-router-dom`** → v7 removed the package. Use `react-router`.
- **`json()` for loader returns** → removed; return objects directly.
- **No `HydrateFallback` with `clientLoader`** → blank screen while client loader runs.
- **Missing `shouldRevalidate`** → all routes revalidate after every action, even unrelated ones.

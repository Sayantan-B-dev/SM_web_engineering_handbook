## 15.10 TanStack Router - Route Loaders

### Subtopic Tree
- `loader` function (route property)
- `loaderDeps` for dependency tracking
- SWR caching built-in
- Parallel loader execution
- `beforeLoad` for context and guards
- `Route.useLoaderData()` for typed data
- `router.invalidate()` for manual revalidation
- Preloading with loaders

### Basic Loader
```tsx
export const Route = createFileRoute('/users/$userId')({
  loader: ({ params }) => fetchUser(params.userId),
  component: UserPage,
});

function UserPage() {
  const user = Route.useLoaderData(); // User - typed
  return <h1>{user.name}</h1>;
}
```

### `loaderDeps` - Dependency Tracking
```tsx
export const Route = createFileRoute('/products')({
  validateSearch: z.object({ page: z.number().default(1) }),
  loaderDeps: ({ search }) => ({ page: search.page }),
  loader: ({ deps }) => fetchProducts(deps.page),
});
```
`loaderDeps` tells the router which search params the loader depends on. When those change, the loader re-runs.

### `beforeLoad` - Context and Guards
```tsx
export const Route = createFileRoute('/dashboard')({
  beforeLoad: async ({ context }) => {
    if (!context.auth.user) throw redirect({ to: '/login' });
    return { user: context.auth.user }; // inherited context
  },
  loader: ({ context }) => fetchDashboard(context.user.id),
});
```

### Real-World Deal-Breakers
- **No `loaderDeps`** → loader doesn't re-run when search params change.
- **`beforeLoad` without `throw redirect()`** → unauthenticated users see blank page.
- **Loader without error handling** → error propagates to route's `errorComponent`.

# 46. REACT KOLKATA COMMUNITY PARTICIPATION - Complete Deep Dive

## 46.14 Summary: React Kolkata Community Participation Deal-Breaker Checklist

| Area | Deal-Breaker | Consequence |
|------|-------------|-------------|
| **Meetups** | Not registering in advance | Offline meetups have limited seats |
| **Meetups** | Only attending online | Miss networking and mentorship |
| **Meetups** | Not bringing a specific question | Conversations stay generic |
| **Workshops** | No pre-requisites listed | Participants arrive without setup |
| **Lightning Talks** | Covering too much | One idea per talk |
| **Lightning Talks** | No timer | You run over |
| **Project Showcases** | Treating Parbon like a hackathon | It's not. Submit your best work. |
| **Project Showcases** | Missing the submission window | Portal closes 5th April |
| **Buildathons** | Assuming buildathons require coding | Miro Buildathon was visual thinking |
| **Quizzes** | No explanations | Quizzes without answers don't teach |
| **Networking** | Only talking to people you came with | Miss valuable connections |
| **Networking** | No follow-up | Connections fade |
| **Mentorship** | Not applying for Project Parbon | Miss the mentorship prize |
| **Mentorship** | No follow-through | Mentor-mentee relationship requires effort |
| **Community Champions** | Waiting to be invited | Champions volunteer |
| **Call for Speakers** | Thinking you're not experienced enough | Lightning talks are for first-timers |
| **Call for Speakers** | No abstract | Speakers selected on clear proposals |
| **Project Parbon** | Missing the WhatsApp community | Updates and support happen there |
| **Open Source** | Submitting AI-generated PRs | You become part of the problem |
| **Open Source** | Not reading `CONTRIBUTING.md` | PR rejected |
| **Partnerships** | No partnership strategy | Communities operate in silos |

---

**The Big Rule:** React Kolkata is **not a spectator sport**. The community's value is created by **participation** - speaking at a lightning talk, mentoring a Project Parbon finalist, contributing to the open-source repository, organizing a workshop, or simply showing up to a meetup with a specific question. Communities like React Kolkata, React Siliguri, and West Bengal Tech exist because **technical talent exists everywhere, but structured opportunities don't**. Be part of the structure.

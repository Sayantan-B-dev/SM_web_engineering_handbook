## 4.12 Mapped Types

### Subtopic Tree
- Basic mapped types
- Key remapping (`as`)
- Modifiers (`+`/`-` for `readonly` and `?`)
- Homomorphic vs non-homomorphic
- Combining with conditional types
- Template literal key remapping

### Syntax
```typescript
// Basic mapped type
type Mapped<T> = {
  [K in keyof T]: T[K];
};

// Make all properties optional
type MyPartial<T> = {
  [K in keyof T]?: T[K];
};

// Make all properties readonly
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K];
};

// Remove readonly
type Mutable<T> = {
  -readonly [K in keyof T]: T[K];
};

// Remove optional
type Required2<T> = {
  [K in keyof T]-?: T[K];
};
```

### Real-World Mapped Types

```typescript
// Nullable — all properties can be null
type Nullable<T> = {
  [K in keyof T]: T[K] | null;
};

// Getters — transform each property to a getter function
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

interface Person {
  name: string;
  age: number;
}

type PersonGetters = Getters<Person>;
// { getName: () => string; getAge: () => number }

// Setters
type Setters<T> = {
  [K in keyof T as `set${Capitalize<string & K>}`]: (value: T[K]) => void;
};

// Pick by value type
type PickByType<T, V> = {
  [K in keyof T as T[K] extends V ? K : never]: T[K];
};

interface Mixed {
  name: string;
  age: number;
  active: boolean;
  score: number;
}

type OnlyStrings = PickByType<Mixed, string>;
// { name: string }

type OnlyNumbers = PickByType<Mixed, number>;
// { age: number; score: number }
```

### Key Remapping with `as`
```typescript
// Remove keys starting with underscore
type RemovePrivate<T> = {
  [K in keyof T as K extends `_${string}` ? never : K]: T[K];
};

interface Config {
  _internal: string;
  public: string;
  _secret: number;
  visible: number;
}

type PublicConfig = RemovePrivate<Config>;
// { public: string; visible: number }

// Prefix all keys
type Prefixed<T, P extends string> = {
  [K in keyof T as `${P}${string & K}`]: T[K];
};

type PrefixedUser = Prefixed<Person, 'user_'>;
// { user_name: string; user_age: number }
```

### Combining with Conditional Types
```typescript
// Deep partial
type DeepPartial<T> = {
  [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K];
};

// Deep readonly
type DeepReadonly<T> = {
  readonly [K in keyof T]: T[K] extends object ? DeepReadonly<T[K]> : T[K];
};

// Unwrap promises in object properties
type UnwrapPromises<T> = {
  [K in keyof T]: Awaited<T[K]>;
};

interface ApiData {
  user: Promise<User>;
  posts: Promise<Post[]>;
}

type ResolvedData = UnwrapPromises<ApiData>;
// { user: User; posts: Post[] }
```

### Real-World Deal-Breakers
- **Mapped types on unions** → `{ [K in keyof (A | B)]: ... }` distributes unexpectedly.
- **`keyof` on arrays** → includes `length`, `push`, `pop`, etc. Use `keyof T[number]` for element keys.
- **Key remapping with non-string keys** → `as` clause must produce `string | number | symbol`.
- **Deep mapped types can be slow** → deeply nested conditional + mapped types cause compiler lag.
- **Homomorphic vs non-homomorphic** → `[K in keyof T]` preserves modifiers (homomorphic); `[K in 'a' | 'b']` doesn't.

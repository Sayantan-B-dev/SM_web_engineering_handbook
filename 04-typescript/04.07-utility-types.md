## 4.7 Utility Types

### Subtopic Tree
- `Partial<T>`
- `Required<T>`
- `Readonly<T>`
- `Pick<T, K>`
- `Omit<T, K>`
- `Record<K, V>`
- `Exclude<T, U>`
- `Extract<T, U>`
- `NonNullable<T>`
- `ReturnType<T>`
- `Parameters<T>`
- `ConstructorParameters<T>`
- `InstanceType<T>`
- `Awaited<T>`
- `ThisParameterType<T>`
- `OmitThisParameter<T>`
- `Uppercase`, `Lowercase`, `Capitalize`, `Uncapitalize`

### Object Utilities
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

// Partial — all properties optional
type PartialUser = Partial<User>;
// { id?: number; name?: string; ... }

// Required — all properties required
type RequiredUser = Required<PartialUser>;

// Readonly — all properties readonly
type ReadonlyUser = Readonly<User>;

// Pick — select specific keys
type UserPreview = Pick<User, 'id' | 'name'>;
// { id: number; name: string }

// Omit — exclude specific keys
type SafeUser = Omit<User, 'password'>;
// { id: number; name: string; email: string }

// Record — object with specific key/value types
type UserMap = Record<string, User>;
type Roles = Record<'admin' | 'user' | 'guest', string[]>;
```

### Union Utilities
```typescript
type Status = 'active' | 'inactive' | 'pending' | null;

type ActiveStatus = Exclude<Status, null>;      // 'active' | 'inactive' | 'pending'
type NonNullStatus = NonNullable<Status>;       // same as above
type PendingOnly = Extract<Status, 'pending'>;  // 'pending'
```

### Function Utilities
```typescript
function createUser(name: string, age: number): User {
  return { id: 1, name, age } as User;
}

type Params = Parameters<typeof createUser>; // [name: string, age: number]
type Return = ReturnType<typeof createUser>; // User

// Practical: wrap functions with logging
function withLogging<T extends (...args: any[]) => any>(fn: T) {
  return (...args: Parameters<T>): ReturnType<T> => {
    console.log('Calling with:', args);
    return fn(...args);
  };
}
```

### Promise Utilities
```typescript
type PromiseValue = Awaited<Promise<string>>; // string
type NestedAwait = Awaited<Promise<Promise<number>>>; // number

async function fetchUser(): Promise<User> { /* ... */ }
type UserData = Awaited<ReturnType<typeof fetchUser>>; // User
```

### String Utilities
```typescript
type Upper = Uppercase<'hello'>;       // 'HELLO'
type Lower = Lowercase<'HELLO'>;       // 'hello'
type Cap = Capitalize<'hello'>;        // 'Hello'
type Uncap = Uncapitalize<'Hello'>;    // 'hello'

// Combined with template literals
type Getter<T extends string> = `get${Capitalize<T>}`;
type NameGetter = Getter<'name'>; // 'getName'
```

### Real-World Patterns
```typescript
// Form state: all fields optional except required ones
type FormState<T> = Partial<T> & Pick<T, 'id'>;

// API update payload: only allow certain fields
type UpdateUserPayload = Partial<Pick<User, 'name' | 'email'>>;

// Deep partial (recursive)
type DeepPartial<T> = {
  [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K];
};

// Deep readonly
type DeepReadonly<T> = {
  readonly [K in keyof T]: T[K] extends object ? DeepReadonly<T[K]> : T[K];
};
```

### Real-World Deal-Breakers
- **`Partial<T>` is shallow** → nested objects remain required. Use `DeepPartial`.
- **`Omit` doesn't validate keys** → `Omit<User, 'nonexistent'>` doesn't error; it just returns `User`.
- **`Record<string, T>` is too broad** → allows any string key; consider union of literal keys.
- **`ReturnType` on overloaded functions** → returns the last overload's return type only.
- **`Parameters` on generic functions** → resolves to the constraint, not the specific type.

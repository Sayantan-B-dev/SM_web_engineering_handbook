## 4.3 Type Aliases

### Subtopic Tree
- Basic aliases
- Union aliases
- Intersection aliases
- Function type aliases
- Tuple aliases
- Generic aliases
- Recursive type aliases
- Template literal type aliases
- Type alias vs interface

### Syntax
```typescript
// Primitive alias
type ID = string | number;

// Object shape
type Point = {
  x: number;
  y: number;
};

// Union
type Status = 'pending' | 'success' | 'error';

// Intersection
type Admin = User & { permissions: string[] };

// Function type
type Handler = (event: Event) => void;
type AsyncHandler<T> = (input: T) => Promise<void>;

// Tuple
type Coordinate = [latitude: number, longitude: number];

// Generic alias
type Result<T, E = Error> =
  | { success: true; data: T }
  | { success: false; error: E };

// Recursive
type JSONValue =
  | string
  | number
  | boolean
  | null
  | JSONValue[]
  | { [key: string]: JSONValue };

// Template literal
type CSSValue = `${number}px` | `${number}rem` | `${number}%`;
```

### Real-World Patterns

```typescript
// API response wrapper
type ApiResponse<T> =
  | { status: 'loading' }
  | { status: 'success'; data: T }
  | { status: 'error'; error: string };

function handleResponse<T>(res: ApiResponse<T>) {
  switch (res.status) {
    case 'loading': return 'Loading...';
    case 'success': return res.data;    // T
    case 'error':   return res.error;   // string
  }
}

// Branded types (nominal typing)
type UserId = string & { readonly __brand: 'UserId' };
type PostId = string & { readonly __brand: 'PostId' };

function getUser(id: UserId) { /* ... */ }
const userId = 'abc' as UserId;
getUser(userId);       // ✅
// getUser('abc');     // ❌ Error: string not assignable to UserId
```

### Real-World Deal-Breakers
- **Aliases don't create new types** → `type A = string; type B = string` — A and B are interchangeable.
- **Complex type aliases slow down the compiler** → deeply recursive conditional types can cause "Type instantiation is excessively deep".
- **No declaration merging** → can't extend a type alias across files.
- **Circular type aliases** → `type A = B; type B = A;` → error.
- **Over-aliasing** → `type Name = string` adds no value; just use `string`.

## 2.3 Specificity

### Subtopic Tree
- Specificity calculation (A, B, C, D or 0-0-0-0)
- Inline styles
- ID selectors
- Class, attribute, pseudo-class selectors
- Type, pseudo-element selectors
- Universal selector (0 specificity)
- `:is()`, `:where()`, `:not()`, `:has()` specificity
- Specificity in cascade layers

### Specificity Values

| Category | Examples | Points |
|----------|----------|--------|
| Inline style | `style="..."` | 1-0-0-0 |
| ID | `#header` | 0-1-0-0 |
| Class, attribute, pseudo-class | `.btn`, `[type="text"]`, `:hover` | 0-0-1-0 |
| Type, pseudo-element | `div`, `::before` | 0-0-0-1 |
| Universal | `*` | 0-0-0-0 |

```css
/* Specificity: 0-0-0-1 */
p { color: blue; }

/* Specificity: 0-0-1-0 */
.text { color: green; }

/* Specificity: 0-1-0-0 */
#intro { color: red; }

/* Higher specificity wins regardless of order */
#intro { color: red; }  /* wins */
.text { color: green; }
```

### `:is()`, `:where()`, `:not()`, `:has()`

```css
/* :is() takes the specificity of its most specific argument */
:is(h1, h2, h3).title { }  /* specificity: 0-0-1-1 (class + type) */

/* :where() always has ZERO specificity — perfect for resets */
:where(h1, h2, h3) { margin: 0; }  /* specificity: 0-0-0-0 */

/* :not() takes specificity of its argument */
:not(.active) { opacity: 0.5; }  /* specificity: 0-0-1-0 */

/* :has() — parent selector, takes specificity of argument */
.card:has(img) { padding: 0; }  /* specificity: 0-0-1-1 */
```

**Real-world trick**: Use `:where()` for base styles that should be easily overridden:

```css
/* Zero specificity reset — any class can override */
:where(ul, ol) {
  list-style: none;
  padding: 0;
  margin: 0;
}

/* Then .nav-list can add styles without fighting specificity */
.nav-list { display: flex; gap: 1rem; }
```

**Real-world deal-breaker**: Deeply nested selectors like `.page .content .card .title .link` have specificity 0-0-5-0. They're impossible to override without `!important` or equally deep selectors. Keep specificity flat: use single classes (BEM, utility classes) for the vast majority of styles.

### `:has()` — The Parent Selector
```css
/* Style a form group when its input is invalid */
.form-group:has(input:invalid) {
  border-color: red;
}

/* Style a card differently when it contains an image */
.card:has(> img) {
  padding-top: 0;
}

/* Style a label when its checkbox is checked */
label:has(input:checked) {
  font-weight: bold;
}
```

**Real-world deal-breaker**: `:has()` is now widely supported but can cause performance issues if used with complex selectors on large DOMs. Use it for targeted enhancements, not global layout logic.

## 2.8 CSS Variables (Custom Properties)

### Subtopic Tree
- Declaration (`--name: value`)
- Usage (`var(--name)`)
- Fallback values (`var(--name, fallback)`)
- Scope (inheritance, `:root`, local)
- Theming
- Dynamic values via JS
- `@property` for typed custom properties
- Limitations

### Syntax
```css
:root {
  --color-primary: #3b82f6;
  --color-text: #1f2937;
  --spacing-unit: 0.25rem;
  --radius: 8px;
  --font-body: 'Inter', system-ui, sans-serif;
}

.button {
  background: var(--color-primary);
  color: white;
  padding: calc(var(--spacing-unit) * 3) calc(var(--spacing-unit) * 6);
  border-radius: var(--radius);
  font-family: var(--font-body);
}

/* Fallback value */
.text {
  color: var(--color-text, #333);  /* #333 if --color-text is undefined */
}
```

### Theming with Variables
```css
:root {
  --bg: #ffffff;
  --text: #1a1a1a;
  --border: #e5e7eb;
}

[data-theme="dark"] {
  --bg: #111827;
  --text: #f9fafb;
  --border: #374151;
}

body {
  background: var(--bg);
  color: var(--text);
}

.card {
  border: 1px solid var(--border);
}
```

**Real-world trick**: Variables cascade and inherit. Override them on a component to theme just that component:

```css
.alert-danger {
  --alert-bg: #fef2f2;
  --alert-text: #991b1b;
  --alert-border: #fecaca;
}

.alert {
  background: var(--alert-bg, #f3f4f6);
  color: var(--alert-text, #1f2937);
  border: 1px solid var(--alert-border, #e5e7eb);
}
```

### Dynamic Values via JS
```javascript
// Read a variable
const primary = getComputedStyle(document.documentElement)
  .getPropertyValue('--color-primary');

// Set a variable
document.documentElement.style.setProperty('--color-primary', '#ef4444');

// Set on a specific element
element.style.setProperty('--progress', `${percent}%`);
```
```css
.progress-bar {
  width: var(--progress, 0%);
  transition: width 0.3s ease;
}
```

### `@property` — Typed Custom Properties
```css
@property --gradient-angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}

.animated-gradient {
  background: linear-gradient(var(--gradient-angle), #3b82f6, #8b5cf6);
  animation: rotate 3s linear infinite;
}

@keyframes rotate {
  to { --gradient-angle: 360deg; }
}
```

**Real-world trick**: Without `@property`, you cannot animate custom properties (they're treated as strings). `@property` gives them a type and makes them animatable.

### Limitations & Deal-Breakers
- **Variables are resolved at computed-value time, not parse time** → you can't use them in media query conditions:
```css
/* ❌ Does NOT work */
@media (min-width: var(--breakpoint)) { }

/* ✅ Use a preprocessor variable or a different approach */
```
- **Variables don't work in `@media` or `@container` queries** → use preprocessor variables (Sass) or hardcoded values.
- **`var()` in shorthand properties** → if the variable is invalid, the entire shorthand becomes invalid:
```css
/* If --size is undefined, font becomes invalid entirely */
font: var(--size) sans-serif;
```
- **No type safety** → `--color: 10px` is valid as a string; errors surface only when used in a property that rejects the value.

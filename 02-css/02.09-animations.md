## 2.9 Animations

### Subtopic Tree
- `@keyframes`
- `animation-name`, `animation-duration`, `animation-timing-function`, `animation-delay`, `animation-iteration-count`, `animation-direction`, `animation-fill-mode`, `animation-play-state`
- `animation` shorthand
- Multi-step animations
- Chained animations
- Performance: `transform` and `opacity` vs layout properties
- `will-change`
- Scroll-driven animations
- `prefers-reduced-motion`

### Syntax
```css
@keyframes slide-in {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

.element {
  animation: slide-in 0.3s ease-out forwards;
  /* name duration timing-function fill-mode */
}

/* Multi-step animation */
@keyframes bounce {
  0%   { transform: translateY(0); }
  25%  { transform: translateY(-20px); }
  50%  { transform: translateY(0); }
  75%  { transform: translateY(-10px); }
  100% { transform: translateY(0); }
}

.bouncing {
  animation: bounce 1s ease infinite;
}
```

### Animation Properties Reference

| Property | Values | Default |
|----------|--------|---------|
| `animation-name` | `@keyframes` name | `none` |
| `animation-duration` | `0.3s`, `300ms` | `0s` |
| `animation-timing-function` | `ease`, `linear`, `ease-in-out`, `cubic-bezier()`, `steps()` | `ease` |
| `animation-delay` | `0.1s` | `0s` |
| `animation-iteration-count` | `1`, `infinite`, `3` | `1` |
| `animation-direction` | `normal`, `reverse`, `alternate`, `alternate-reverse` | `normal` |
| `animation-fill-mode` | `none`, `forwards`, `backwards`, `both` | `none` |
| `animation-play-state` | `running`, `paused` | `running` |

### Performance: Only Animate `transform` and `opacity`
```css
/* ❌ Triggers layout + paint + composite on every frame */
@keyframes bad {
  from { left: 0; width: 100px; }
  to   { left: 100px; width: 200px; }
}

/* ✅ Runs on compositor thread, 60fps */
@keyframes good {
  from { transform: translateX(0) scaleX(1); }
  to   { transform: translateX(100px) scaleX(2); }
}
```

**Real-world deal-breaker**: Animating `width`, `height`, `top`, `left`, `margin`, or `font-size` triggers layout on every frame, causing jank on low-end devices. Stick to `transform` and `opacity` for smooth 60fps animations.

### `will-change`
```css
.animated-element {
  will-change: transform;  /* hints browser to promote to its own layer */
}

/* Remove after animation to free memory */
.animated-element.idle {
  will-change: auto;
}
```

**Real-world deal-breaker**: Overusing `will-change` creates too many compositor layers, consuming GPU memory and causing crashes on low-end devices. Apply it only when needed and remove it after.

### Scroll-Driven Animations (Modern)
```css
/* Animate as user scrolls */
@keyframes reveal {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}

.reveal {
  animation: reveal linear;
  animation-timeline: view();        /* based on element visibility in viewport */
  animation-range: entry 0% entry 100%;
}

/* Progress bar tied to scroll */
.progress {
  animation: grow linear;
  animation-timeline: scroll(root);
}

@keyframes grow {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}
```

### Respecting `prefers-reduced-motion`
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

**Real-world deal-breaker**: Ignoring `prefers-reduced-motion` can trigger vestibular disorders (dizziness, nausea) in sensitive users. Always provide a reduced-motion path.

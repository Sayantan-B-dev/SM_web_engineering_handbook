## 2.4 Flexbox

### Subtopic Tree
- Container properties: `display: flex`, `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `align-content`, `gap`
- Item properties: `flex-grow`, `flex-shrink`, `flex-basis`, `flex`, `align-self`, `order`
- Main axis vs cross axis
- `min-width: 0` / `min-height: 0` for shrinking
- `margin: auto` for alignment
- Flexbox vs Grid decision

### Core Concepts
Flexbox is a **one-dimensional** layout system — it distributes space along a single axis (row or column). The main axis is defined by `flex-direction`; the cross axis is perpendicular.

```css
/* Container */
.container {
  display: flex;
  flex-direction: row;         /* row | row-reverse | column | column-reverse */
  flex-wrap: wrap;             /* nowrap | wrap | wrap-reverse */
  justify-content: space-between; /* main axis alignment */
  align-items: center;          /* cross axis alignment */
  align-content: flex-start;   /* multi-line cross axis alignment */
  gap: 1rem;                   /* spacing between items */
}

/* Items */
.item {
  flex: 1 1 200px;  /* grow shrink basis */
  /* Equivalent to: */
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 200px;
}
```

### `justify-content` vs `align-items`

| Property | Axis | Values |
|----------|------|--------|
| `justify-content` | Main axis | `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly` |
| `align-items` | Cross axis | `flex-start`, `flex-end`, `center`, `baseline`, `stretch` |
| `align-content` | Multi-line cross axis | Same as `justify-content` |

### Real-World Patterns

```css
/* Perfect centering */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* Nav bar: logo left, links right */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem;
}

/* Card with footer pushed to bottom */
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}
.card-body { flex: 1; }  /* grows to fill space */
.card-footer { margin-top: auto; }  /* alternative */

/* Responsive grid-like layout without media queries */
.grid-auto {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.grid-auto > * {
  flex: 1 1 250px;  /* grow, shrink, minimum 250px */
}

/* Sidebar + main content */
.layout {
  display: flex;
}
.sidebar {
  flex: 0 0 250px;  /* fixed width, no grow/shrink */
}
.main {
  flex: 1;  /* fill remaining space */
  min-width: 0;  /* CRITICAL: allows shrinking below content size */
}
```

### The `min-width: 0` Trap
By default, flex items have `min-width: auto`, which means they won't shrink below their content size. This causes overflow when content is wide (long text, tables, images).

```css
/* ❌ Text overflows the flex item */
.flex-item {
  flex: 1;
}

/* ✅ Text wraps/truncates properly */
.flex-item {
  flex: 1;
  min-width: 0;  /* or min-height: 0 for column direction */
}

/* Truncate text inside flex item */
.flex-item {
  flex: 1;
  min-width: 0;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

**Real-world deal-breaker**: Forgetting `min-width: 0` on flex children causes horizontal overflow, broken layouts, and scrollbars that appear from nowhere. This is the #1 flexbox bug.

### `margin: auto` for Alignment
```css
/* Push item to the right */
.navbar .user-menu {
  margin-left: auto;
}

/* Center item vertically in a column */
.column-item {
  margin-block: auto;
}
```

**Real-world trick**: `margin: auto` in flexbox absorbs all free space in that direction. It's more powerful than `justify-content` for individual items.

### Flexbox vs Grid Decision

| Use Flexbox when... | Use Grid when... |
|---------------------|-----------------|
| One-dimensional layout (row OR column) | Two-dimensional layout (rows AND columns) |
| Content determines size | Layout determines size |
| Navigation bars, toolbars, card contents | Page layouts, dashboards, galleries |
| Items should grow/shrink to fill space | Precise control over rows and columns |

**Real-world deal-breaker**: Using Flexbox for a 2D grid layout (like a photo gallery with rows and columns) leads to fragile `flex-basis` hacks. Use Grid instead.

### Syntax
```css
.button {
  background: #3b82f6;
  transform: scale(1);
  transition: background 0.2s ease, transform 0.15s ease-out;
  /* property duration timing-function */
}

.button:hover {
  background: #2563eb;
  transform: scale(1.05);
}

/* Single transition */
.card {
  transition: box-shadow 0.3s ease;
}
.card:hover {
  box-shadow: 0 10px 30px rgb(0 0 0 / 0.15);
}
```

### Shorthand Order
```css
/* transition: property duration timing-function delay; */
transition: opacity 0.3s ease-in 0.1s;
```

### What Can Be Transitioned
Anything with an intermediate value: colors, lengths, percentages, opacity, transform, filter, box-shadow. **Cannot** transition: `display`, `position`, `z-index` (step changes), `content`.

### Transitioning `display` (Modern)
```css
/* Use @starting-style and transition-behavior for enter/exit animations */
dialog {
  opacity: 0;
  transform: scale(0.95);
  transition: opacity 0.3s, transform 0.3s, display 0.3s allow-discrete;
}

dialog[open] {
  opacity: 1;
  transform: scale(1);

  @starting-style {
    opacity: 0;
    transform: scale(0.95);
  }
}

/* allow-discrete enables transitioning display and content-visibility */
```

### Real-World Patterns

```css
/* Smooth hover lift */
.card {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgb(0 0 0 / 0.1);
}

/* Underline slide-in */
.link {
  position: relative;
}
.link::after {
  content: '';
  position: absolute;
  bottom: -2px;
  left: 0;
  width: 100%;
  height: 2px;
  background: currentColor;
  transform: scaleX(0);
  transform-origin: right;
  transition: transform 0.3s ease;
}
.link:hover::after {
  transform: scaleX(1);
  transform-origin: left;
}

/* Fade in on mount (with JS adding class) */
.fade-in {
  opacity: 0;
  transition: opacity 0.5s ease;
}
.fade-in.visible {
  opacity: 1;
}
```

### Timing Functions
```css
transition-timing-function: ease;          /* default: slow start, fast middle, slow end */
transition-timing-function: linear;        /* constant speed */
transition-timing-function: ease-in;       /* slow start */
transition-timing-function: ease-out;      /* slow end */
transition-timing-function: ease-in-out;   /* slow start and end */
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);  /* custom */
transition-timing-function: steps(4, end); /* stepped */
```

**Real-world trick**: `cubic-bezier(0.4, 0, 0.2, 1)` (Material Design's standard curve) feels natural for UI transitions.

### Deal-Breakers
- **Transitioning `all`** → transitions properties you didn't intend; can cause layout thrashing. Always specify properties explicitly.
- **Transitioning on page load** → elements animate from their initial state on first render. Use a class toggle or `@starting-style`.
- **Long durations** → transitions > 400ms feel sluggish. Keep UI transitions 150–300ms.
- **No `prefers-reduced-motion`** → same accessibility issue as animations.

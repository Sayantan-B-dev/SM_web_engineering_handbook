## 2.6 Responsive Design

### Subtopic Tree
- Media queries (`min-width`, `max-width`, `orientation`, `prefers-color-scheme`, `prefers-reduced-motion`, `hover`, `pointer`)
- Mobile-first vs desktop-first
- Breakpoints strategy
- Fluid typography (`clamp()`)
- Fluid spacing
- Responsive images (`srcset`, `sizes`, `<picture>`)
- Viewport meta tag
- Container queries (modern alternative)
- Intrinsic layouts (content-driven, not breakpoint-driven)

### Mobile-First Approach
Start with styles for the smallest screen, then add complexity with `min-width` media queries. This is the standard because mobile devices have less powerful CPUs and slower networks — you want the simplest baseline.

```css
/* Base styles: mobile */
.card {
  padding: 1rem;
  font-size: 1rem;
}

/* Tablet and up */
@media (min-width: 768px) {
  .card {
    padding: 1.5rem;
    font-size: 1.125rem;
  }
}

/* Desktop and up */
@media (min-width: 1024px) {
  .card {
    padding: 2rem;
    display: grid;
    grid-template-columns: 1fr 2fr;
  }
}
```

### Breakpoints Strategy
Don't chase device widths. Use **content-driven breakpoints** — resize your browser until the layout breaks, then add a breakpoint there.

```css
/* Common breakpoint set (but adjust to your content) */
/* sm: 640px  — large phones */
/* md: 768px  — tablets */
/* lg: 1024px — laptops */
/* xl: 1280px — desktops */
/* 2xl: 1536px — large screens */
```

**Real-world trick**: Use `em` units in media queries instead of `px`. `em` respects user font size preferences:

```css
@media (min-width: 48em) { }  /* 768px at default 16px, but respects zoom */
```

### Fluid Typography with `clamp()`
```css
/* clamp(min, preferred, max) */
h1 {
  font-size: clamp(1.75rem, 1rem + 3vw, 3rem);
  /* min: 1.75rem, preferred: fluid, max: 3rem */
}

/* Fluid spacing */
.section {
  padding: clamp(2rem, 5vw, 6rem);
}

/* Fluid container */
.container {
  width: min(90%, 1200px);
  margin-inline: auto;
}
```

**Real-world trick**: `clamp()` eliminates most typography media queries. The `preferred` value uses `vw` to scale smoothly between min and max.

### Responsive Images

```html
<!-- srcset: let browser choose based on viewport -->
<img
  src="image-800.jpg"
  srcset="image-400.jpg 400w, image-800.jpg 800w, image-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, (max-width: 1200px) 50vw, 800px"
  alt="Description"
  width="800"
  height="600"
  loading="lazy"
>

<!-- picture: art direction or format fallback -->
<picture>
  <source media="(min-width: 800px)" srcset="wide.avif" type="image/avif">
  <source media="(min-width: 800px)" srcset="wide.webp" type="image/webp">
  <source srcset="narrow.avif" type="image/avif">
  <img src="fallback.jpg" alt="Description" width="800" height="600">
</picture>
```

**Real-world deal-breaker**: Not setting `width` and `height` on images causes Cumulative Layout Shift (CLS) when the image loads and pushes content down. Always set intrinsic dimensions or `aspect-ratio`.

### Viewport Meta Tag
```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

**Real-world deal-breaker**: Omitting this tag makes mobile browsers render at 980px and zoom out, making text tiny and touch targets unusable.

### Preference Media Queries

```css
/* Dark mode */
@media (prefers-color-scheme: dark) {
  :root { --bg: #111; --text: #eee; }
}

/* Reduced motion */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* Hover capability (don't show hover effects on touch) */
@media (hover: hover) {
  .card:hover { transform: translateY(-4px); }
}

/* Pointer precision */
@media (pointer: coarse) {
  .button { min-height: 44px; min-width: 44px; }  /* touch targets */
}
```

### Real-World Deal-Breakers
- **Desktop-first media queries** → mobile users download desktop CSS and override it; slower and more complex.
- **Too many breakpoints** → maintenance nightmare. Use content-driven breakpoints and intrinsic layouts (flex/grid wrapping) to reduce the need.
- **Fixed pixel widths** → `width: 1200px` breaks on smaller screens. Use `max-width` with percentage widths.
- **Text at fixed `px` sizes** → doesn't respect user font size settings. Use `rem`.
- **Ignoring `prefers-reduced-motion`** → can cause nausea and dizziness for users with vestibular disorders.

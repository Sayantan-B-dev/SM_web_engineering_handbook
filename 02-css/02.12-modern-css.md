### Native CSS Nesting
```css
/* No preprocessor needed */
.card {
  padding: 1rem;
  background: white;

  .title {
    font-size: 1.5rem;
    font-weight: 600;
  }

  &:hover {
    box-shadow: 0 4px 12px rgb(0 0 0 / 0.1);
  }

  @media (min-width: 768px) {
    padding: 2rem;
  }
}
```

### Logical Properties
```css
/* Physical (avoid) */
margin-left: 1rem;
margin-right: 1rem;
padding-top: 0.5rem;
padding-bottom: 0.5rem;

/* Logical (preferred — works with RTL) */
margin-inline: 1rem;      /* left + right */
padding-block: 0.5rem;   /* top + bottom */
margin-inline-start: 1rem; /* left in LTR, right in RTL */
border-inline-end: 1px solid; /* right in LTR, left in RTL */
```

**Real-world trick**: Logical properties make internationalization (RTL languages like Arabic, Hebrew) automatic. No separate stylesheet needed.

### `color-mix()` and Modern Color
```css
:root {
  --primary: oklch(60% 0.25 250);
  --primary-light: color-mix(in oklch, var(--primary) 30%, white);
  --primary-dark: color-mix(in oklch, var(--primary) 70%, black);
  --primary-transparent: color-mix(in srgb, var(--primary) 50%, transparent);
}

/* Relative colors (modern) */
.button:hover {
  background: oklch(from var(--primary) calc(l - 0.1) c h);
}
```

**Real-world trick**: `oklch()` is perceptually uniform — equal lightness steps look equal to the human eye. Use it for generating color scales.

### `text-wrap: balance` and `pretty`
```css
h1, h2, h3 {
  text-wrap: balance;  /* evenly distributes text across lines */
}

p {
  text-wrap: pretty;   /* avoids orphans and widows */
}
```

### Popover API
```html
<button popovertarget="menu">Open Menu</button>
<div id="menu" popover>
  <ul>
    <li><a href="/profile">Profile</a></li>
    <li><a href="/settings">Settings</a></li>
  </ul>
</div>
```
```css
[popover] {
  border: none;
  border-radius: 8px;
  box-shadow: 0 8px 24px rgb(0 0 0 / 0.15);
}

/* Animate popover */
[popover] {
  opacity: 0;
  transform: translateY(-8px);
  transition: opacity 0.2s, transform 0.2s, display 0.2s allow-discrete;
}
[popover]:popover-open {
  opacity: 1;
  transform: translateY(0);
}
@starting-style {
  [popover]:popover-open {
    opacity: 0;
    transform: translateY(-8px);
  }
}
```

**Real-world trick**: The Popover API provides native top-layer rendering, light-dismiss, and focus management — eliminating custom JS for tooltips, dropdowns, and menus.

### View Transitions API
```css
/* Simple cross-fade between pages */
@view-transition {
  navigation: auto;
}

/* Named transitions */
.hero-image {
  view-transition-name: hero;
}

::view-transition-old(hero) {
  animation: fade-out 0.3s ease;
}
::view-transition-new(hero) {
  animation: fade-in 0.3s ease;
}
```

### `@scope`
```css
@scope (.card) to (.card__footer) {
  /* Styles apply only within .card, stopping at .card__footer */
  img { border-radius: 8px; }
  p { margin: 0; }
}
```

### Real-World Deal-Breakers
- **Using modern CSS without checking support** → `:has()`, `@scope`, Popover API, View Transitions are relatively new. Check caniuse.com and provide fallbacks.
- **`text-wrap: balance` on long paragraphs** → browsers limit it to ~6 lines for performance. Use on headings only.
- **`oklch()` on very old browsers** → no support in IE/older Safari. Provide `rgb()` fallback or use `@supports`.
- **Native nesting specificity** → nested rules use `&` and have the same specificity as if written flat; don't assume it reduces specificity.

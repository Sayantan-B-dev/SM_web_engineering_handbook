## 2.5 Grid

### Subtopic Tree
- Container properties: `display: grid`, `grid-template-columns`, `grid-template-rows`, `grid-template-areas`, `gap`, `justify-items`, `align-items`, `justify-content`, `align-content`
- Item properties: `grid-column`, `grid-row`, `grid-area`, `justify-self`, `align-self`
- Track sizing: `fr`, `minmax()`, `auto`, `min-content`, `max-content`, `fit-content()`
- `repeat()` and `auto-fill` vs `auto-fit`
- Named lines and areas
- Subgrid
- Masonry (experimental)

### Core Syntax
```css
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;      /* 3 columns: 1:2:1 ratio */
  grid-template-rows: auto 1fr auto;        /* header, content, footer */
  gap: 1rem;
}

/* Named areas — most readable for complex layouts */
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100dvh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
```

### `repeat()` and Responsive Grids

```css
/* Fixed columns */
grid-template-columns: repeat(3, 1fr);

/* Responsive without media queries — auto-fit */
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

/* auto-fill vs auto-fit */
/* auto-fill: creates empty tracks to fill row */
/* auto-fit: collapses empty tracks, items stretch to fill */
```

**Real-world trick**: `repeat(auto-fit, minmax(250px, 1fr))` creates a fully responsive grid where items are at least 250px wide and stretch to fill the row. No media queries needed.

### Track Sizing Functions

| Function | Behavior |
|----------|----------|
| `1fr` | One fraction of free space |
| `minmax(min, max)` | At least min, at most max |
| `auto` | Content-based, stretches to fill |
| `min-content` | Smallest possible (longest word) |
| `max-content` | Largest possible (no wrapping) |
| `fit-content(limit)` | Content size, capped at limit |

```css
/* Sidebar that's at least 200px but grows to 300px max */
grid-template-columns: minmax(200px, 300px) 1fr;

/* Content-based columns */
grid-template-columns: max-content 1fr;  /* label + input */

/* Responsive with minmax */
grid-template-columns: repeat(auto-fit, minmax(min(250px, 100%), 1fr));
/* min() prevents overflow on very small screens */
```

### Spanning and Placement

```css
/* Span 2 columns */
.wide { grid-column: span 2; }

/* Explicit placement */
.featured {
  grid-column: 1 / 3;    /* from line 1 to line 3 (spans 2) */
  grid-row: 1 / 2;
}

/* Using named lines */
.grid {
  grid-template-columns: [sidebar-start] 250px [sidebar-end main-start] 1fr [main-end];
}
.sidebar { grid-column: sidebar-start / sidebar-end; }
```

### Subgrid
```css
/* Parent defines columns */
.parent {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Child aligns to parent's grid */
.child {
  display: grid;
  grid-column: span 3;
  grid-template-columns: subgrid;  /* inherits parent's column tracks */
}
```

**Real-world trick**: Subgrid is perfect for card layouts where the header, body, and footer of each card should align across all cards in a row.

### Real-World Layout Patterns

```css
/* Holy grail layout */
.holy-grail {
  display: grid;
  grid-template:
    "header header header" auto
    "nav    main   aside"  1fr
    "footer footer footer" auto
    / 200px  1fr    200px;
  min-height: 100dvh;
}

/* Dashboard */
.dashboard {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 1rem;
}
.widget-large { grid-column: span 8; }
.widget-small { grid-column: span 4; }
.widget-full  { grid-column: 1 / -1; }  /* full width */

/* Centering anything */
.center {
  display: grid;
  place-items: center;  /* shorthand for align-items + justify-items */
}
```

### Real-World Deal-Breakers
- **`grid-template-columns: repeat(auto-fit, minmax(300px, 1fr))` on narrow screens** → items overflow if viewport < 300px. Use `minmax(min(300px, 100%), 1fr)`.
- **Forgetting `min-height: 0` on grid items** → same overflow issue as flexbox.
- **Using Grid for simple 1D layouts** → overkill; Flexbox is simpler.
- **Not using `gap`** → using margins between grid items creates uneven spacing at edges.
- **`grid-area` conflicts** → overlapping named areas cause implicit grid creation and unexpected placement.

## 2.13 Accessible UI (CSS)

### Subtopic Tree
- Color contrast
- Focus indicators
- `prefers-reduced-motion`
- `prefers-contrast`
- Touch target sizes
- `:focus-visible` vs `:focus`
- Hover-only interactions
- Text zoom (200% reflow)
- Dark mode contrast
- Screen reader-only content (`.sr-only`)

### Color Contrast
```css
/* WCAG AA: 4.5:1 for normal text, 3:1 for large text (18pt+ or 14pt+ bold) */
/* WCAG AAA: 7:1 for normal text, 4.5:1 for large text */

:root {
  --text: #1f2937;         /* on white: ~14:1 ✅ */
  --text-muted: #6b7280;   /* on white: ~4.8:1 ✅ AA */
  --text-disabled: #9ca3af; /* on white: ~2.8:1 ❌ fails AA */
}
```

**Real-world deal-breaker**: Placeholder text is often `#ccc` on white (~1.6:1) — fails all contrast requirements. Use at least `#767676` on white (4.5:1).

### Focus Indicators
```css
/* ❌ Never do this */
*:focus { outline: none; }

/* ✅ Custom focus indicator with :focus-visible */
:focus-visible {
  outline: 2px solid #3b82f6;
  outline-offset: 2px;
  border-radius: 2px;
}

/* Remove focus ring for mouse clicks only */
:focus:not(:focus-visible) {
  outline: none;
}
```

**Real-world trick**: `:focus-visible` shows focus rings only for keyboard navigation, not mouse clicks. This satisfies both keyboard users and designers who dislike focus rings on click.

### Screen Reader-Only Content
```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border-width: 0;
}

/* Modern alternative */
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}
```

### Touch Targets
```css
/* WCAG 2.5.8: minimum 24x24px (AA), 44x44px recommended */
.button {
  min-height: 44px;
  min-width: 44px;
  padding: 0.75rem 1.5rem;
}

/* Expand tap target without changing visual size */
.icon-button::before {
  content: '';
  position: absolute;
  inset: -10px;  /* expands hit area by 10px on all sides */
}
```

### `prefers-contrast`
```css
@media (prefers-contrast: more) {
  :root {
    --text: #000;
    --border: #000;
  }
  .button {
    border: 2px solid currentColor;
  }
}
```

### Text Zoom / Reflow
```css
/* Content must reflow at 320px width without horizontal scroll (WCAG 1.4.10) */
.container {
  max-width: 100%;
  overflow-wrap: break-word;
}

/* Avoid fixed heights that clip content when text zooms */
.card {
  min-height: 200px;  /* ✅ allows growth */
  /* height: 200px;   ❌ clips at 200% zoom */
}
```

### Dark Mode Contrast
```css
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #111827;
    --text: #f9fafb;       /* on #111827: ~15:1 ✅ */
    --text-muted: #9ca3af; /* on #111827: ~6:1 ✅ */
  }
}
```

**Real-world deal-breaker**: Pure white text on pure black (`#fff` on `#000`) causes halation (glowing/blurring) for users with astigmatism. Use `#f9fafb` on `#111827` instead.

### Real-World Deal-Breakers
- **`outline: none` without replacement** → keyboard users can't see where they are. Always provide a visible focus indicator.
- **Hover-only interactions** → touch devices have no hover. Ensure click/tap alternatives.
- **`user-select: none` on content** → prevents users from copying text (accessibility issue for cognitive disabilities).
- **Animations without reduced-motion** → vestibular disorders triggered.
- **Tiny text** → `font-size: 10px` is unreadable for many users. Minimum 16px for body text.
- **Color-only information** → "red = error, green = success" fails for colorblind users. Add icons, text, or patterns.

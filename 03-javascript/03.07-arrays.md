## 3.7 Arrays

### Subtopic Tree
- Creation & initialization
- Access & length
- Mutating methods: `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`, `fill`, `copyWithin`
- Non-mutating methods: `slice`, `concat`, `map`, `filter`, `reduce`, `flat`, `flatMap`, `find`, `findIndex`, `some`, `every`, `includes`, `indexOf`, `at`, `join`
- Iteration: `forEach`, `for...of`, `for...in` (avoid)
- Array destructuring
- Spread
- Sparse arrays
- Typed arrays
- `Array.from()`, `Array.of()`, `Array.isArray()`

### Mutating vs Non-Mutating

| Mutating | Non-Mutating |
|----------|-------------|
| `push()` | `concat()` |
| `pop()` | `slice()` |
| `shift()` | `map()` |
| `unshift()` | `filter()` |
| `splice()` | `reduce()` |
| `sort()` | `flat()` |
| `reverse()` | `flatMap()` |
| `fill()` | `toSorted()` (ES2023) |
| `copyWithin()` | `toReversed()`, `toSpliced()`, `with()` (ES2023) |

```javascript
const arr = [3, 1, 4, 1, 5];

// ❌ sort() mutates in place
arr.sort(); // [1, 1, 3, 4, 5]

// ✅ toSorted() returns new array (ES2023)
const sorted = arr.toSorted((a, b) => a - b);
```

### Essential Array Methods

```javascript
// map — transform each element
const doubled = [1, 2, 3].map(n => n * 2); // [2, 4, 6]

// filter — keep elements matching predicate
const evens = [1, 2, 3, 4].filter(n => n % 2 === 0); // [2, 4]

// reduce — accumulate to single value
const sum = [1, 2, 3, 4].reduce((acc, n) => acc + n, 0); // 10

// find — first matching element
const users = [{ id: 1 }, { id: 2 }, { id: 3 }];
const user = users.find(u => u.id === 2); // { id: 2 }

// findIndex — index of first match
const index = users.findIndex(u => u.id === 2); // 1

// some — at least one matches
const hasEven = [1, 3, 5].some(n => n % 2 === 0); // false

// every — all match
const allPositive = [1, 2, 3].every(n => n > 0); // true

// flat — flatten nested arrays
const nested = [1, [2, [3, [4]]]];
nested.flat();    // [1, 2, [3, [4]]]
nested.flat(Infinity); // [1, 2, 3, 4]

// flatMap — map then flatten one level
const sentences = ['Hello World', 'Goodbye'];
sentences.flatMap(s => s.split(' ')); // ['Hello', 'World', 'Goodbye']

// at — supports negative indexing
const arr2 = [10, 20, 30];
arr2.at(-1); // 30
arr2.at(-2); // 20
```

### Sort Pitfalls
```javascript
// ❌ Default sort converts to strings
[10, 9, 80, 1].sort(); // [1, 10, 80, 9]

// ✅ Numeric sort
[10, 9, 80, 1].sort((a, b) => a - b); // [1, 9, 10, 80]

// ✅ Sort objects
users.sort((a, b) => a.name.localeCompare(b.name));

// ✅ Stable sort (ES2019+)
// Elements with equal sort keys maintain relative order
```

### Sparse Arrays (Avoid)
```javascript
const sparse = [1, , 3]; // hole at index 1
console.log(sparse.length);  // 3
console.log(sparse[1]);      // undefined
console.log(1 in sparse);    // false (hole, not undefined value)

// Methods behave inconsistently with holes
sparse.map(x => x * 2); // [2, , 6] — hole preserved
sparse.forEach(x => console.log(x)); // skips hole
```

### Real-World Tricks
- **`Array.from({ length: 5 }, (_, i) => i)`** → `[0, 1, 2, 3, 4]` (clean range creation).
- **`[...new Set(arr)]`** → deduplicate array.
- **`arr.filter(Boolean)`** → remove all falsy values (`0`, `''`, `null`, `undefined`, `false`, `NaN`).
- **`arr.reduce((acc, item) => ({ ...acc, [item.id]: item }), {})`** → convert array to lookup object.
- **`arr.sort(() => Math.random() - 0.5)`** → shuffle (biased but common; use Fisher-Yates for unbiased).

### Real-World Deal-Breakers
- **`sort()` without comparator** → sorts as strings; `[10, 9, 1].sort()` → `[1, 10, 9]`.
- **Mutating during iteration** → `forEach` with `splice` inside causes skipped elements.
- **`for...in` on arrays** → iterates indices as strings AND inherited properties. Use `for...of` or `forEach`.
- **`Array(n)` creates holes** → `Array(3)` → `[empty × 3]`, not `[undefined, undefined, undefined]`. Use `Array.from({ length: 3 })`.
- **`includes` vs `indexOf`** → `[NaN].includes(NaN)` is `true`; `[NaN].indexOf(NaN)` is `-1`. Use `includes` for NaN.
- **`length` is writable** → `arr.length = 2` truncates the array. `arr.length = 100` creates holes.

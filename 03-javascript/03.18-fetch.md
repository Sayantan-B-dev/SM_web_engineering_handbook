## 3.18 Fetch

### Syntax
```javascript
const res = await fetch('/api/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`,
  },
  body: JSON.stringify({ name: 'Alice' }),
  credentials: 'include', // send cookies
  signal: abortController.signal,
});

if (!res.ok) {
  throw new Error(`HTTP ${res.status}: ${res.statusText}`);
}

const data = await res.json();
```

### Response Methods
```javascript
res.json();    // parse as JSON
res.text();    // parse as text
res.blob();    // binary data (images, files)
res.arrayBuffer(); // raw bytes
res.formData(); // multipart form data
res.clone();   // clone response (body can only be read once)
```

**Critical**: Response body can only be consumed **once**. Calling `res.json()` then `res.text()` throws `TypeError: Body has already been read`. Use `res.clone()` if you need multiple reads.

### Error Handling
```javascript
// fetch only rejects on NETWORK failure (DNS, offline, CORS)
// It does NOT reject on HTTP errors (404, 500)

try {
  const res = await fetch('/api/data');
  if (!res.ok) {
    throw new Error(`HTTP ${res.status}`);
  }
  const data = await res.json();
} catch (err) {
  if (err.name === 'AbortError') {
    console.log('Request cancelled');
  } else {
    console.error('Network or parse error:', err);
  }
}
```

### Streaming Responses
```javascript
const res = await fetch('/api/stream');
const reader = res.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const chunk = decoder.decode(value, { stream: true });
  console.log('Chunk:', chunk);
}
```

### Real-World Tricks
- **Timeout wrapper**:
```javascript
async function fetchWithTimeout(url, options = {}, timeout = 5000) {
  const controller = new AbortController();
  const id = setTimeout(() => controller.abort(), timeout);
  try {
    const res = await fetch(url, { ...options, signal: controller.signal });
    return res;
  } finally {
    clearTimeout(id);
  }
}
```

- **Retry with exponential backoff**:
```javascript
async function fetchWithRetry(url, options = {}, retries = 3) {
  for (let i = 0; i < retries; i++) {
    try {
      const res = await fetch(url, options);
      if (res.ok) return res;
      if (res.status < 500) return res; // don't retry client errors
    } catch (err) {
      if (i === retries - 1) throw err;
    }
    await new Promise(r => setTimeout(r, 2 ** i * 1000));
  }
}
```

### Real-World Deal-Breakers
- **Forgetting `res.ok` check** → `fetch` resolves for 404/500; you must check `res.ok` or `res.status`.
- **Reading body twice** → `res.json()` then `res.text()` throws. Use `res.clone()`.
- **No `Content-Type` header on POST** → server may not parse JSON body correctly.
- **CORS preflight** → custom headers or non-simple methods trigger an `OPTIONS` preflight. Server must respond with proper `Access-Control-Allow-*` headers.
- **No timeout** → fetch waits indefinitely on slow/hung servers. Use `AbortController`.
- **Credentials default is `same-origin`** → cross-origin requests don't send cookies unless `credentials: 'include'`.

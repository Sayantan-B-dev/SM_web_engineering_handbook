## 3.2 Scope

### Subtopic Tree
- Global scope
- Function scope
- Block scope
- Lexical scope (static scope)
- Scope chain
- Module scope
- IIFE (Immediately Invoked Function Expression)
- Variable shadowing
- `'use strict'` mode

### Scope Types

```javascript
// Global scope
const globalVar = 'I am global';

function outer() {
  // Function scope
  const outerVar = 'I am in outer';

  function inner() {
    // Lexical scope: inner has access to outer and global
    const innerVar = 'I am in inner';
    console.log(innerVar, outerVar, globalVar); // all accessible
  }

  inner();
  // console.log(innerVar); // ReferenceError
}

// Block scope
{
  const blockVar = 'I am in a block';
  console.log(blockVar); // ✅
}
// console.log(blockVar); // ReferenceError
```

### Lexical Scope & Scope Chain
JavaScript uses **lexical (static) scoping** — scope is determined by where code is written, not where it's called. When a variable is referenced, the engine walks up the scope chain: local → parent → grandparent → global.

```javascript
const x = 'global';

function outer() {
  const x = 'outer';

  function inner() {
    console.log(x); // 'outer' — closest lexical scope wins
  }

  inner();
}

outer();
```

### Variable Shadowing
```javascript
const name = 'global';

function greet() {
  const name = 'local'; // shadows global
  console.log(name);    // 'local'
}

greet();
console.log(name); // 'global'
```

### IIFE (Immediately Invoked Function Expression)
```javascript
// Classic module pattern (pre-ES modules)
const counter = (() => {
  let count = 0; // private variable

  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count,
  };
})();

counter.increment();
counter.increment();
console.log(counter.getCount()); // 2
console.log(counter.count);      // undefined (private)
```

### `'use strict'` Mode
```javascript
'use strict';

// Prevents:
// - Undeclared variables (x = 10 → ReferenceError)
// - Duplicate parameter names
// - Assignment to read-only properties
// - `this` in functions defaults to undefined (not global)
// - Octal literals (010)
// - `with` statement
```

ES modules are **always strict** — no need for the directive.

### Real-World Deal-Breakers
- **Accidental globals** → `function foo() { x = 10; }` creates a global `x` without `'use strict'`.
- **Loop variable captured in closure** → use `let` or an IIFE to capture the current value.
- **Shadowing bugs** → declaring `let name` inside a function when you meant to use the outer `name`; the inner declaration shadows it.
- **`var` hoisting in blocks** → `var` escapes block scope:
```javascript
if (true) { var x = 10; }
console.log(x); // 10 — var leaks out of block
```

## 3.23 Iterators

### Subtopic Tree
- Iterator protocol (`next()` returns `{ value, done }`)

### Iterator Protocol
An object is an iterator if it has a `next()` method that returns `{ value, done }`.

```javascript
const iterator = {
  current: 0,
  next() {
    if (this.current < 3) {
      return { value: this.current++, done: false };
    }
    return { value: undefined, done: true };
  },
};

iterator.next(); // { value: 0, done: false }
iterator.next(); // { value: 1, done: false }
iterator.next(); // { value: 2, done: false }
iterator.next(); // { value: undefined, done: true }
```

### Iterable Protocol
An object is iterable if it has a `Symbol.iterator` method that returns an iterator.

```javascript
const range = {
  from: 1,
  to: 5,

  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;

    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false };
        }
        return { value: undefined, done: true };
      },
    };
  },
};

for (const n of range) console.log(n); // 1, 2, 3, 4, 5
console.log([...range]); // [1, 2, 3, 4, 5]
```

### Built-in Iterables
```javascript
// Array
for (const x of [1, 2, 3]) console.log(x);

// String
for (const char of 'hello') console.log(char); // 'h', 'e', 'l', 'l', 'o'

// Map
const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) console.log(key, value);

// Set
for (const x of new Set([1, 2, 3])) console.log(x);

// NodeList
for (const el of document.querySelectorAll('div')) console.log(el);
```

### Real-World Tricks
- **Lazy evaluation** → iterators produce values on demand, useful for infinite sequences or large datasets.
- **`for...of` vs `forEach`** → `for...of` supports `break`, `continue`, `return`, and `await`.
- **Custom iterables for pagination**:
```javascript
class PaginatedResults {
  constructor(fetchPage) {
    this.fetchPage = fetchPage;
  }

  async *[Symbol.asyncIterator]() {
    let page = 1;
    while (true) {
      const results = await this.fetchPage(page);
      if (results.length === 0) break;
      yield* results;
      page++;
    }
  }
}
```

### Real-World Deal-Breakers
- **Modifying array during iteration** → `for...of` on an array being spliced causes skipped elements.
- **Objects are not iterable by default** → `for...of obj` throws. Use `Object.entries()`, `Object.keys()`, or `Object.values()`.
- **Iterator is single-use** → once `done: true`, calling `next()` again returns `{ done: true }`. Get a fresh iterator via `[Symbol.iterator]()`.

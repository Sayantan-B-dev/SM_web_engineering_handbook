### Storage APIs
```javascript
// localStorage — persists across sessions, ~5-10MB, synchronous
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme');
localStorage.removeItem('theme');
localStorage.clear();

// sessionStorage — cleared when tab closes
sessionStorage.setItem('token', 'abc');

// IndexedDB — large structured data, async, ~50MB+
const request = indexedDB.open('myDB', 1);
request.onupgradeneeded = (e) => {
  const db = e.target.result;
  db.createObjectStore('users', { keyPath: 'id' });
};
request.onsuccess = (e) => {
  const db = e.target.result;
  const tx = db.transaction('users', 'readwrite');
  tx.objectStore('users').put({ id: 1, name: 'Alice' });
};
```

### IntersectionObserver
```javascript
// Lazy load images
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      observer.unobserve(img);
    }
  });
}, { rootMargin: '200px' });

document.querySelectorAll('img[data-src]').forEach(img => observer.observe(img));
```

### ResizeObserver
```javascript
const observer = new ResizeObserver((entries) => {
  for (const entry of entries) {
    const { width, height } = entry.contentRect;
    console.log(`Element resized: ${width}x${height}`);
  }
});
observer.observe(document.querySelector('.container'));
```

### URL API
```javascript
const url = new URL('https://example.com/path?foo=bar&baz=qux');
console.log(url.hostname); // 'example.com'
console.log(url.pathname); // '/path'
console.log(url.searchParams.get('foo')); // 'bar'
url.searchParams.set('new', 'value');
url.searchParams.append('multi', 'a');
url.searchParams.append('multi', 'b');
console.log(url.searchParams.getAll('multi')); // ['a', 'b']
```

### Real-World Deal-Breakers
- **`localStorage` is synchronous** → blocks the main thread for large data. Use IndexedDB for large datasets.
- **`localStorage` stores strings only** → must `JSON.stringify`/`JSON.parse` for objects.
- **IntersectionObserver not polyfilled** → supported in all modern browsers, but check for IE/older Safari.
- **Clipboard API requires HTTPS and user gesture** → `navigator.clipboard.writeText()` fails on HTTP or without user interaction.
- **Geolocation requires HTTPS** → and user permission; fails silently on HTTP.
- **History API without server support** → `pushState` changes URL but refresh 404s unless server returns `index.html` for all routes.

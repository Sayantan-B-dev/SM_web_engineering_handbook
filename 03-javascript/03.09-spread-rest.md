## 3.9 Spread / Rest

### Subtopic Tree
- Spread in function calls
- Spread in array literals
- Spread in object literals
- Rest in function parameters
- Rest in array destructuring
- Rest in object destructuring
- Shallow copy behavior
- Performance considerations

### Spread (`...` on the right side)
```javascript
// Spread in function calls
const nums = [1, 2, 3];
Math.max(...nums); // 3

// Spread in array literals (shallow copy / merge)
const arr1 = [1, 2];
const arr2 = [3, 4];
const merged = [...arr1, ...arr2]; // [1, 2, 3, 4]
const copy = [...arr1];            // shallow copy

// Spread in object literals (shallow copy / merge)
const user = { name: 'Alice', age: 30 };
const updated = { ...user, age: 31 }; // { name: 'Alice', age: 31 }
const copy2 = { ...user };            // shallow copy

// Spread strings into characters
const chars = [...'hello']; // ['h', 'e', 'l', 'l', 'o']

// Spread Sets/Maps
const unique = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]
```

### Rest (`...` on the left side)
```javascript
// Rest in function params — collects remaining args into array
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}
sum(1, 2, 3, 4); // 10

// Rest must be last parameter
function log(level, ...messages) {
  console.log(`[${level}]`, ...messages);
}

// Rest in array destructuring
const [first, ...rest] = [1, 2, 3, 4];
console.log(first); // 1
console.log(rest);  // [2, 3, 4]

// Rest in object destructuring
const { name, ...others } = { name: 'Alice', age: 30, city: 'Kolkata' };
console.log(others); // { age: 30, city: 'Kolkata' }
```

### Shallow Copy Trap
```javascript
const original = {
  name: 'Alice',
  address: { city: 'Kolkata' },
};

const copy = { ...original };
copy.address.city = 'Delhi';

console.log(original.address.city); // 'Delhi' — MUTATED!
// Spread only copies the top level; nested objects are shared by reference
```

**Deep copy alternatives:**
```javascript
// structuredClone (modern, recommended)
const deep = structuredClone(original);

// JSON hack (loses functions, Dates, undefined, etc.)
const deep2 = JSON.parse(JSON.stringify(original));
```

### Real-World Tricks
- **Immutable update patterns** (React/Redux):
```javascript
// Update nested state immutably
const newState = {
  ...state,
  user: {
    ...state.user,
    address: { ...state.user.address, city: 'Delhi' },
  },
};
```
- **Convert NodeList to array**: `[...document.querySelectorAll('div')]`.
- **Merge with overrides**: `{ ...defaults, ...userOptions }`.
- **Remove a key**: `const { password, ...safeUser } = user;`.

### Real-World Deal-Breakers
- **Shallow copy mistaken for deep copy** → nested mutations affect the original.
- **Spread in hot loops** → creating new arrays/objects every iteration causes GC pressure. Prefer `push` with pre-allocated arrays for performance-critical code.
- **Spread of large arrays as function args** → `fn(...hugeArray)` can exceed the call stack limit (`RangeError: Maximum call stack size exceeded`). Use `fn.apply(null, hugeArray)` or pass the array directly.
- **Rest parameter must be last** → `function fn(...rest, last)` is a syntax error.
- **Spread doesn't copy non-enumerable properties** → `{ ...obj }` skips non-enumerable props and prototype properties.

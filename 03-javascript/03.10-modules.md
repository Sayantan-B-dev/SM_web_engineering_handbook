## 3.10 Modules

### ES Modules (Modern Standard)
```javascript
// math.js — named exports
export const PI = 3.14159;
export function add(a, b) { return a + b; }
export function subtract(a, b) { return a - b; }

// Default export
export default function multiply(a, b) { return a * b; }

// Or export at the end
const divide = (a, b) => a / b;
export { divide };
```

```javascript
// app.js — imports
import multiply from './math.js';                    // default
import { add, subtract, PI } from './math.js';       // named
import { add as sum, subtract as diff } from './math.js'; // rename
import * as math from './math.js';                   // namespace
import multiply, { add, PI } from './math.js';       // both

// Re-export
export { add, subtract } from './math.js';
export * from './math.js';
export { default as multiply } from './math.js';
```

### CommonJS (Node.js legacy)
```javascript
// math.js
const PI = 3.14159;
function add(a, b) { return a + b; }

module.exports = { PI, add };

// app.js
const { PI, add } = require('./math');
const math = require('./math');
```

### ESM vs CJS

| Feature | ESM | CJS |
|---------|-----|-----|
| Syntax | `import`/`export` | `require`/`module.exports` |
| Loading | Static, async | Dynamic, sync |
| Tree-shakeable | Yes | No |
| Top-level `await` | Yes | No |
| `this` at top level | `undefined` | `module.exports` |
| Browser support | Native | Bundler required |
| File extension | `.mjs` or `"type": "module"` | `.cjs` or default |

### Dynamic Imports
```javascript
// Lazy load — returns a Promise
async function loadChart() {
  const { Chart } = await import('./chart.js');
  return new Chart();
}

// Conditional import
if (userWantsPDF) {
  const { generatePDF } = await import('./pdf.js');
  generatePDF(data);
}

// React lazy loading
const HeavyComponent = React.lazy(() => import('./HeavyComponent'));
```

### Circular Dependencies
```javascript
// a.js
import { b } from './b.js';
export const a = 'a';
console.log(b); // may be undefined depending on load order

// b.js
import { a } from './a.js';
export const b = 'b';
console.log(a); // may be undefined
```

**Fix**: Extract shared code into a third module, or use dynamic imports to break the cycle.

### Real-World Tricks
- **Barrel exports** (`index.js`) → re-export from a folder for cleaner imports:
```javascript
// components/index.js
export { Button } from './Button';
export { Card } from './Card';
export { Modal } from './Modal';

// Usage
import { Button, Card, Modal } from './components';
```
**Caveat**: Barrel files can hurt tree shaking and slow down dev server cold starts if overused.

- **`import.meta.url`** → get the current module's URL:
```javascript
console.log(import.meta.url); // file:///path/to/module.js
```

- **Top-level await** (ESM only):
```javascript
const data = await fetch('/api/config').then(r => r.json());
export default data;
```

### Real-World Deal-Breakers
- **Mixing ESM and CJS** → `require()` in ESM throws; `import` in CJS requires dynamic `import()`.
- **Circular dependencies** → one module gets a partially initialized export (`undefined`). Restructure to avoid.
- **Default export naming inconsistency** → `import Foo from './foo'` vs `import foo from './foo'` — team confusion. Prefer named exports.
- **Tree shaking failure** → CommonJS modules, side effects in module scope, and `import *` prevent dead code elimination.
- **No file extension in ESM** → `import './utils'` fails in browsers; must be `import './utils.js'`.

### Core Concept
A closure is a function that **remembers the variables from its lexical scope** even after the outer function has returned. Every function in JavaScript forms a closure over its surrounding scope.

```javascript
function createCounter() {
  let count = 0; // captured by closure

  return {
    increment() { count++; },
    decrement() { count--; },
    value() { return count; },
  };
}

const counter = createCounter();
counter.increment();
counter.increment();
counter.increment();
console.log(counter.value()); // 3
// `count` is not accessible from outside — true privacy
```

### Function Factories
```javascript
function multiplier(factor) {
  return (number) => number * factor;
}

const double = multiplier(2);
const triple = multiplier(3);

console.log(double(5));  // 10
console.log(triple(5));  // 15
// Each closure has its own `factor`
```

### Event Handlers
```javascript
function attachHandlers() {
  const buttons = document.querySelectorAll('button');

  buttons.forEach((button, index) => {
    button.addEventListener('click', () => {
      console.log(`Button ${index} clicked`); // `index` captured per iteration
    });
  });
}
```

### Loop Closure Bug (and Fix)
```javascript
// ❌ var: all closures share the same `i`
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 3, 3, 3
}

// ✅ let: each iteration has its own block-scoped `i`
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 0, 1, 2
}

// ✅ IIFE fix (pre-ES6)
for (var i = 0; i < 3; i++) {
  (function(j) {
    setTimeout(() => console.log(j), 100); // 0, 1, 2
  })(i);
}
```

### Memory Implications
Closures keep their captured variables alive. If a closure is long-lived (e.g., attached to a global event listener), the captured variables cannot be garbage collected.

```javascript
// ❌ Memory leak: huge data captured by long-lived closure
function setup() {
  const hugeData = new Array(1_000_000).fill('x');
  document.getElementById('btn').addEventListener('click', () => {
    console.log(hugeData.length); // hugeData kept alive forever
  });
}

// ✅ Only capture what you need
function setup() {
  const hugeData = new Array(1_000_000).fill('x');
  const length = hugeData.length;
  document.getElementById('btn').addEventListener('click', () => {
    console.log(length); // only the number is captured
  });
}
```

### Real-World Deal-Breakers
- **Unintended sharing** → multiple closures sharing the same variable when you expected separate copies.
- **Memory leaks** → closures holding references to large DOM trees or data structures prevent GC.
- **Stale closures in React** → `useEffect` with empty deps captures initial state; subsequent updates aren't seen.
- **Loop + `var`** → the classic bug that `let` solves.

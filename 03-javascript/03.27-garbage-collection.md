### How GC Works
JavaScript uses **mark-and-sweep** (not reference counting). The GC starts from roots (global object, current call stack, DOM references) and marks all reachable objects. Unmarked objects are swept (freed).

```javascript
// Reachable — global reference
let user = { name: 'Alice' };

// Unreachable — eligible for GC
user = null; // object has no references

// Circular references don't prevent GC
function createCycle() {
  const a = {};
  const b = {};
  a.ref = b;
  b.ref = a;
  return 'done';
}
createCycle(); // a and b are unreachable after function returns → GC'd
```

### Generational GC
Objects are divided into:
- **Young generation (nursery)** → newly allocated objects; collected frequently and quickly.
- **Old generation** → objects that survived multiple young collections; collected less often but slower.

**Trick**: Most objects die young. Keeping objects alive longer promotes them to the old generation, making GC slower.

### `WeakRef` and `FinalizationRegistry` (Modern)
```javascript
// WeakRef — hold a reference that doesn't prevent GC
let ref = new WeakRef(document.querySelector('.target'));

// Later
const target = ref.deref();
if (target) {
  // still alive
} else {
  // garbage collected
}

// FinalizationRegistry — callback when object is GC'd
const registry = new FinalizationRegistry((heldValue) => {
  console.log(`${heldValue} was garbage collected`);
});

let obj = { name: 'temp' };
registry.register(obj, 'temp object');
obj = null; // eventually triggers callback
```

### Real-World Deal-Breakers
- **GC is non-deterministic** → you can't force GC or know exactly when it runs. Don't rely on `FinalizationRegistry` for cleanup — use explicit cleanup.
- **GC pauses** → stop-the-world pauses can cause frame drops. Minimize garbage creation in hot paths (avoid object/array allocation in loops).
- **Memory leaks are not GC failures** → they're unreachable objects that are still referenced somewhere. GC can't free what's reachable.
- **`delete` doesn't free memory immediately** → it removes a property but the object may still be referenced.

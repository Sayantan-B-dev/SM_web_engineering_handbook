## 3.13 Promises

### Subtopic Tree

### Promise States
A Promise is a placeholder for a value that will exist in the future. It's in one of three states: **pending** (initial), **fulfilled** (resolved with a value), or **rejected** (failed with a reason). Once settled (fulfilled or rejected), it cannot change state.

```javascript
const promise = new Promise((resolve, reject) => {
  // Executor runs synchronously
  setTimeout(() => {
    const success = true;
    if (success) resolve('Data loaded');
    else reject(new Error('Failed'));
  }, 1000);
});

promise
  .then(data => console.log(data))     // 'Data loaded'
  .catch(err => console.error(err))
  .finally(() => console.log('Done')); // always runs
```

### Chaining
```javascript
fetch('/api/user')
  .then(res => res.json())
  .then(user => fetch(`/api/posts/${user.id}`))
  .then(res => res.json())
  .then(posts => console.log(posts))
  .catch(err => console.error('Any error in chain:', err))
  .finally(() => console.log('Cleanup'));
```

### Promise Combinators

```javascript
// Promise.all — waits for ALL to fulfill, rejects if ANY rejects
const [users, posts] = await Promise.all([
  fetchUsers(),
  fetchPosts(),
]);
// Fast, but one failure rejects everything

// Promise.allSettled — waits for ALL to settle (never rejects)
const results = await Promise.allSettled([
  fetchUsers(),
  fetchPosts(),
]);
// results: [{ status: 'fulfilled', value: ... }, { status: 'rejected', reason: ... }]

// Promise.race — settles with the FIRST to settle (fulfill or reject)
const fastest = await Promise.race([
  fetchFromServerA(),
  fetchFromServerB(),
]);

// Promise.any — fulfills with the FIRST to fulfill; rejects only if ALL reject
const firstSuccess = await Promise.any([
  fetchFromServerA(),
  fetchFromServerB(),
]);
```

### Error Propagation
```javascript
Promise.resolve(1)
  .then(n => n + 1)           // 2
  .then(n => { throw new Error('boom'); })
  .then(n => console.log(n))  // skipped
  .catch(err => console.log(err.message)) // 'boom'
  .then(() => console.log('recovered')); // runs
```

Errors skip all `.then()` until a `.catch()` is found.

### Real-World Tricks
- **Promisify callback APIs**:
```javascript
const readFile = (path) => new Promise((resolve, reject) => {
  fs.readFile(path, (err, data) => err ? reject(err) : resolve(data));
});
```

- **Timeout wrapper**:
```javascript
function withTimeout(promise, ms) {
  const timeout = new Promise((_, reject) =>
    setTimeout(() => reject(new Error('Timeout')), ms)
  );
  return Promise.race([promise, timeout]);
}
```

### Real-World Deal-Breakers
- **Unhandled promise rejections** → crash Node.js (v15+) or log errors in browser. Always add `.catch()` or use `try/catch` with `await`.
- **`Promise.all` with one failure** → all results lost. Use `Promise.allSettled` if you need partial results.
- **Creating promises unnecessarily** → `new Promise(resolve => resolve(fetch(url)))` is an anti-pattern. Just use `fetch(url)`.
- **Forgetting to return in `.then()`** → breaks the chain; next `.then` gets `undefined`.
- **`async` executor** → `new Promise(async (resolve) => { ... })` swallows errors. Never use async executor functions.

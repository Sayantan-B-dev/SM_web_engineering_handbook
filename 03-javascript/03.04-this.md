## 3.4 `this`

### Subtopic Tree
- `this` in global scope
- `this` in regular functions
- `this` in arrow functions
- `this` in methods
- `this` in constructors
- `this` in event handlers
- `call`, `apply`, `bind`
- `this` in strict vs non-strict mode
- `this` in classes

### `this` Resolution Rules

| Context | `this` value |
|---------|-------------|
| Global scope (non-strict) | `window` / `globalThis` |
| Global scope (strict) | `undefined` |
| Regular function (non-strict) | `window` / `globalThis` |
| Regular function (strict) | `undefined` |
| Method call `obj.fn()` | `obj` |
| Constructor `new Fn()` | new instance |
| Arrow function | Lexical `this` (from surrounding scope) |
| Event handler | Element that fired the event |
| `call`/`apply`/`bind` | Explicitly set |

```javascript
// Global
console.log(this); // window (browser, non-strict)

// Method
const user = {
  name: 'Alice',
  greet() {
    console.log(this.name); // 'Alice'
  },
};
user.greet();

// Detached method
const greet = user.greet;
greet(); // undefined (strict) or window.name (non-strict)

// Arrow function — lexical this
const obj = {
  name: 'Bob',
  greet: () => {
    console.log(this.name); // undefined — `this` is from outer scope
  },
};
obj.greet();

// Constructor
function Person(name) {
  this.name = name;
}
const alice = new Person('Alice');
console.log(alice.name); // 'Alice'
```

### `call`, `apply`, `bind`
```javascript
function introduce(greeting, punctuation) {
  console.log(`${greeting}, I'm ${this.name}${punctuation}`);
}

const user = { name: 'Alice' };

// call: invoke immediately, args spread
introduce.call(user, 'Hello', '!');    // "Hello, I'm Alice!"

// apply: invoke immediately, args as array
introduce.apply(user, ['Hi', '?']);    // "Hi, I'm Alice?"

// bind: return new function with fixed `this`
const boundIntroduce = introduce.bind(user, 'Hey');
boundIntroduce('.');                    // "Hey, I'm Alice."
```

### Arrow Functions & `this`
```javascript
const timer = {
  seconds: 0,
  start() {
    // ✅ Arrow function inherits `this` from `start`
    setInterval(() => {
      this.seconds++;
      console.log(this.seconds);
    }, 1000);
  },
};

// ❌ Regular function: `this` is window/undefined
const timer2 = {
  seconds: 0,
  start() {
    setInterval(function() {
      this.seconds++; // `this` is not timer2
    }, 1000);
  },
};
```

### Real-World Deal-Breakers
- **Losing `this` in callbacks** → `setTimeout(obj.method, 100)` loses `this`. Use `.bind(obj)` or arrow wrapper.
- **Arrow functions as methods** → `{ name: 'x', greet: () => this.name }` → `this` is not the object.
- **Arrow functions as constructors** → `new (() => {})` throws `TypeError: not a constructor`.
- **`this` in class methods passed as callbacks** → React class components required `.bind(this)` for this reason.
- **`this` in nested functions** → regular nested function has its own `this`, not the outer method's.

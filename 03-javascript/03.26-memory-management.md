### Stack vs Heap
```javascript
// Primitives → stack (fixed size, fast)
let x = 42;
let name = 'Alice';
let flag = true;

// Objects/arrays/functions → heap (dynamic size)
const user = { name: 'Alice' }; // reference on stack, object on heap
const arr = [1, 2, 3];
```

### Common Memory Leaks

**1. Accidental globals**
```javascript
function leak() {
  leaked = new Array(1_000_000); // no let/const/var → global
}
```

**2. Forgotten timers**
```javascript
// ❌ Timer keeps running after component unmounts
setInterval(() => {
  updateUI();
}, 1000);

// ✅ Clear when done
const id = setInterval(updateUI, 1000);
clearInterval(id);
```

**3. Forgotten event listeners**
```javascript
// ❌ Listener never removed
element.addEventListener('click', handler);

// ✅ Remove when done
element.removeEventListener('click', handler);
```

**4. Closures holding large data**
```javascript
function createHandler() {
  const hugeData = new Array(1_000_000).fill('x');
  return () => console.log(hugeData.length); // hugeData kept alive
}
```

**5. Detached DOM nodes**
```javascript
let detachedNodes = [];
function removeElement() {
  const el = document.getElementById('target');
  detachedNodes.push(el);      // keeps reference
  el.parentNode.removeChild(el); // removed from DOM but still in memory
}
```

### WeakMap / WeakSet
```javascript
// WeakMap keys are weakly held — can be garbage collected
const cache = new WeakMap();

function process(obj) {
  if (cache.has(obj)) return cache.get(obj);
  const result = expensiveCompute(obj);
  cache.set(obj, result);
  return result;
}
// When `obj` is no longer referenced elsewhere, it's GC'd,
// and the WeakMap entry disappears automatically

// WeakSet — track objects without preventing GC
const visited = new WeakSet();

function traverse(node) {
  if (visited.has(node)) return;
  visited.add(node);
  // ...
}
```

### Detecting Leaks (Chrome DevTools)
1. Open DevTools → Memory tab.
2. Take a heap snapshot.
3. Perform an action (open/close modal, navigate).
4. Take another snapshot.
5. Compare — look for detached DOM nodes, growing object counts.

### Real-World Deal-Breakers
- **Global caches without eviction** → grow unbounded. Use LRU cache or `WeakMap`.
- **Closures in long-lived listeners** → capture large data; keep the closure small.
- **React state updates after unmount** → fetch resolves after component unmounts → setState on unmounted component. Use AbortController or a mounted flag.
- **Detached DOM trees** → removed from document but referenced in JS; entire subtree stays in memory.
- **`console.log` holding references** → DevTools keeps logged objects alive while console is open. Clear console to release.

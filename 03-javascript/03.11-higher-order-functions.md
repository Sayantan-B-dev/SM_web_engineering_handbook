## 3.11 Higher-Order Functions

### Subtopic Tree
- Definition: function that takes/returns a function
- `map`, `filter`, `reduce` as HOFs
- Function composition
- Currying
- Partial application
- Decorators (function wrappers)
- Memoization

### Core Concept
A higher-order function either **takes a function as an argument** or **returns a function** (or both).

```javascript
// Takes a function
function repeat(n, action) {
  for (let i = 0; i < n; i++) action(i);
}
repeat(3, i => console.log(i)); // 0, 1, 2

// Returns a function
function greaterThan(n) {
  return (m) => m > n;
}
const greaterThan10 = greaterThan(10);
greaterThan10(11); // true

// Both
function compose(f, g) {
  return (x) => f(g(x));
}
```

### Function Composition
```javascript
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

const trim = (s) => s.trim();
const lower = (s) => s.toLowerCase();
const exclaim = (s) => `${s}!`;

const format = pipe(trim, lower, exclaim);
format('  HELLO  '); // 'hello!'

const format2 = compose(exclaim, lower, trim);
format2('  HELLO  '); // 'hello!'
```

### Currying
```javascript
// Normal function
function add(a, b, c) { return a + b + c; }

// Curried
function curryAdd(a) {
  return (b) => {
    return (c) => a + b + c;
  };
}
curryAdd(1)(2)(3); // 6

// Generic curry
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) return fn(...args);
    return (...next) => curried(...args, ...next);
  };
}
const curriedAdd = curry(add);
curriedAdd(1)(2)(3); // 6
curriedAdd(1, 2)(3); // 6
curriedAdd(1)(2, 3); // 6
```

### Memoization
```javascript
function memoize(fn) {
  const cache = new Map();
  return (...args) => {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key);
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
}

const expensiveCalc = memoize((n) => {
  console.log('Computing...');
  return n * n;
});

expensiveCalc(5); // "Computing..." → 25
expensiveCalc(5); // 25 (cached, no log)
```

### Real-World Tricks
- **Debounce / Throttle** are HOFs:
```javascript
function debounce(fn, delay) {
  let timeout;
  return (...args) => {
    clearTimeout(timeout);
    timeout = setTimeout(() => fn(...args), delay);
  };
}

function throttle(fn, limit) {
  let inThrottle;
  return (...args) => {
    if (!inThrottle) {
      fn(...args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);
    }
  };
}
```

- **Once**: Run a function only once:
```javascript
function once(fn) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      called = true;
      result = fn(...args);
    }
    return result;
  };
}
```

### Real-World Deal-Breakers
- **Over-abstraction** → wrapping everything in HOFs makes code harder to read and debug (deep stack traces).
- **Memoization with object args** → `JSON.stringify` key generation is slow and fails on circular refs. Use a WeakMap for object keys.
- **Currying everywhere** → not idiomatic in most JS codebases; use sparingly.
- **Losing `this` in HOFs** → passing `obj.method` to `map` loses `this`. Use `obj.method.bind(obj)` or arrow wrapper.

### Single-Threaded, Non-Blocking
JavaScript runs on a **single thread** — one call stack, one thing at a time. Asynchronous behavior is achieved through the event loop + browser-provided Web APIs (which run on separate threads).

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Call Stack  │     │   Web APIs   │     │   Event Loop │
│  (sync code) │────▶│ (timers, IO, │────▶│  (routes     │
│              │     │  fetch, DOM) │     │   callbacks) │
└──────────────┘     └──────────────┘     └──────────────┘
```

### Execution Example
```javascript
console.log('1');

setTimeout(() => console.log('2'), 0);

fetch('/api').then(() => console.log('3'));

Promise.resolve().then(() => console.log('4'));

console.log('5');

// Output: 1, 5, 4, 3, 2
// Sync: 1, 5
// Microtasks: 4, then 3 (fetch resolves later)
// Macrotask: 2
```

### JIT Compilation
Modern JS engines (V8, SpiderMonkey) use **Just-In-Time compilation**:
1. Parse source → AST.
2. Interpret bytecode (fast startup).
3. Identify hot functions → compile to optimized machine code.
4. Deoptimize if assumptions break (e.g., type changes).

```javascript
// ✅ Monomorphic — always same types → optimized
function add(a, b) { return a + b; }
add(1, 2);
add(3, 4);

// ❌ Polymorphic — types change → deoptimized
add(1, 2);
add('a', 'b');
add({}, []);
```

### Hidden Classes
V8 creates hidden classes for objects. Objects with the same shape share a hidden class, enabling fast property access.

```javascript
// ✅ Same shape → same hidden class
const a = { x: 1, y: 2 };
const b = { x: 3, y: 4 };

// ❌ Different shape → different hidden class
const c = { x: 1, y: 2 };
const d = { y: 2, x: 1 }; // different property order
delete c.x;                // creates new hidden class
```

### Real-World Deal-Breakers
- **Blocking the main thread** → long sync operations freeze UI. Use Web Workers.
- **Type instability** → mixing types in hot functions causes deoptimization. Keep functions monomorphic.
- **Deleting properties** → `delete obj.prop` changes hidden class, slowing property access. Set to `null` instead.
- **Adding properties after creation** → changes hidden class. Initialize all properties in the constructor.
- **Sparse arrays** → slower than dense arrays. Avoid holes.

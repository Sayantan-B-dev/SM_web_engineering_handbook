## 3.24 Generators

### Subtopic Tree
- `function*` syntax
- `yield` keyword
- Generator object (`next`, `return`, `throw`)
- Two-way communication (`yield` receives values)
- `yield*` for delegation
- Infinite generators
- Async generators (`async function*`)
- Use cases: lazy evaluation, custom iterators, state machines

### Syntax
```javascript
function* simpleGenerator() {
  console.log('Start');
  yield 1;
  console.log('Resumed');
  yield 2;
  console.log('Resumed again');
  yield 3;
  return 'done';
}

const gen = simpleGenerator();
console.log(gen.next()); // 'Start' → { value: 1, done: false }
console.log(gen.next()); // 'Resumed' → { value: 2, done: false }
console.log(gen.next()); // 'Resumed again' → { value: 3, done: false }
console.log(gen.next()); // { value: 'done', done: true }
```

### Two-Way Communication
```javascript
function* conversation() {
  const name = yield 'What is your name?';
  const age = yield `Hello ${name}, how old are you?`;
  yield `${name}, you are ${age} years old`;
}

const gen = conversation();
console.log(gen.next().value);         // 'What is your name?'
console.log(gen.next('Alice').value);  // 'Hello Alice, how old are you?'
console.log(gen.next(30).value);       // 'Alice, you are 30 years old'
```

### `yield*` Delegation
```javascript
function* inner() {
  yield 1;
  yield 2;
}

function* outer() {
  yield 0;
  yield* inner(); // delegate to inner generator
  yield 3;
}

console.log([...outer()]); // [0, 1, 2, 3]
```

### Infinite Generators
```javascript
function* fibonacci() {
  let a = 0, b = 1;
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}

const fib = fibonacci();
console.log(fib.next().value); // 0
console.log(fib.next().value); // 1
console.log(fib.next().value); // 1
console.log(fib.next().value); // 2
```

### Async Generators
```javascript
async function* fetchPages(url) {
  let nextUrl = url;
  while (nextUrl) {
    const res = await fetch(nextUrl);
    const data = await res.json();
    yield data.items;
    nextUrl = data.next;
  }
}

for await (const items of fetchPages('/api/items')) {
  console.log(items);
}
```

### Real-World Tricks
- **Unique ID generator**:
```javascript
function* idGenerator(prefix = 'id') {
  let id = 0;
  while (true) {
    yield `${prefix}-${++id}`;
  }
}

const nextId = idGenerator('user');
console.log(nextId().next().value); // 'user-1'
```

- **State machine**:
```javascript
function* trafficLight() {
  while (true) {
    yield 'green';
    yield 'yellow';
    yield 'red';
  }
}
```

### Real-World Deal-Breakers
- **Forgetting generators are lazy** → code before the first `yield` doesn't run until `.next()` is called.
- **Generators are single-use** → once `done: true`, you can't restart. Create a new generator.
- **Performance overhead** → generators are slower than plain functions; don't use them in hot paths.
- **`yield` in non-generator** → syntax error. `yield` only works inside `function*`.
- **`return` in generator** → sets `done: true` and the value becomes the `return` value; remaining `yield`s are skipped.

- Recording archive

### What an Event Archive Is
An event archive is a **permanent, searchable record of every React Kolkata event**. It answers: **"What events have happened, and where can I find the recordings?"**

React Kolkata events are currently scattered across Luma, LinkedIn posts, and WhatsApp messages. The archive centralizes them.

### Event Archive Data Model
```text
Event Archive:
─────────────────────────────────
id: uuid
title: string ("React Kolkata Online Meetup - June 2026")

type: enum (online, offline, workshop, buildathon)
venue: string (Techno India University, Indus Net Technologies)
speakers: Member[]
talks: Talk[]
recording_url: string
slide_urls: string[]
attendees: Member[] (opt-in)
description: text
```

### Deeper Explanation: An Archive Is A Search Index For Community History

An event archive turns scattered meetup pages into a searchable history: what was discussed, when, by whom, and where the material lives. Its value is discovery ("has anyone spoken about CRDTs here?"), speaker research, and legitimacy (a visible track record for sponsors and newcomers).

The useful fields are the boring ones: date, venue, format, topics, speakers, attendee count, and links to recordings or slides. Consistency matters more than richness â€” an archive that only covers half the events is confusing, so automation (importing from the event platform) beats manual entry.

### Additional Pitfalls
- **Manual entry forever.** It drifts; automate from the event platform's data.
- **No topic tags.** The main search use case fails.
- **Missing recordings/slides.** Sessions lose most of their value after the room empties.
- **No attendee counts or outcomes.** Sponsors and organisers cannot show impact.
- **Duplicate or inconsistent event records.** Deduplicate on a stable event id.

### Real-World Deal-Breakers
- **No event archive** → past events are forgotten. New members can't discover the community's history.
- **No recording links** → talks happen and disappear. No one can watch them later.
- **No speaker linking** → speakers don't get credit for past talks.
- **No attendee list** → you can't see who was at a past event.

### What a Talk Archive Is
A talk archive is a **searchable index of every talk delivered at React Kolkata events**. It answers: **"Has anyone talked about X? Where can I watch it?"**

The talk archive is the **knowledge layer** of the community platform. Over time, it becomes a **curated library of React knowledge** built by the community.

### Talk Archive Data Model
```text
Talk:
─────────────────────────────────
id: uuid
title: string
speaker: Member
event: Event
date: timestamp
type: enum (lightning, full, workshop)
topic_tags: string[] (React Query, Observability, Next.js, Performance, AI)
recording_url: string
slide_url: string
transcript: text
summary: text
related_talks: Talk[]
```

### Deeper Explanation: Talks Are Community Knowledge Assets

A talk archive is the community's library: recordings, slides, and notes indexed by topic and speaker. Its leverage is that one talk, given once to thirty people, becomes a resource for thousands â€” provided it is findable and has a summary.

The data model is a talk with a canonical topic tag, an abstract (the real value for search), links to video/slides/repo, and a speaker link. Add a transcript or summary so the content is searchable in text; that is what makes the archive usable rather than decorative.

### Additional Pitfalls
- **Video without an abstract.** Nobody watches 40 minutes to find out whether it is relevant.
- **No transcript or summary.** Text search misses everything.
- **No topic vocabulary.** Overlapping tags make browsing unreliable.
- **Broken links.** Hosting is a commitment; check periodically for dead recordings.
- **No speaker attribution.** Credits and contacts are part of the community's value.

### Real-World Deal-Breakers
- **No talk archive** → talks exist only in the moment. They disappear after the event.
- **No topic tagging** → you can't find talks by topic. Search is useless.
- **No transcript** → talks aren't searchable by content.
- **No related talks** → you can't discover similar talks.

## 47.9 Tech Calendar

### Subtopic Tree
- Definition: unified calendar of all community and partner events
- Event sources (React Kolkata, partner communities, conferences)
- Event types (meetups, workshops, conferences, hackathons)
- Subscription (ICS, Google Calendar)
- Event reminders
- Integration with event archive
- Cross-community events (React India, React Nexus, DevConf.IN)

### What a Tech Calendar Is
A tech calendar is a **unified, subscribable calendar of all events relevant to the community**. It answers: **"What's happening next, and when?"**

React Kolkata events are currently announced on Luma. The tech calendar extends beyond React Kolkata to include **partner community events, conferences, and workshops**.

### Calendar Sources
- **React Kolkata** - Meetups, workshops, buildathons
- **Partner communities** - DevPath, React Aligarh, GDG On-Campus
- **Conferences** - React India, React Nexus, DevConf.IN
- **Workshops** - Miro Buildathon, AI Agents Workshop

### Subscription Formats
- **ICS feed** - subscribe in any calendar app
- **Google Calendar** - add to Google Calendar
- **Luma integration** - React Kolkata events auto-sync from Luma

---

### Deeper Explanation: One Calendar Is A Public Good

A tech calendar aggregates community events (meetups, conferences, workshops, CFPs) into one place, with subscription (ICS), reminders, and filters by topic and city. Its value is coordination: organisers avoid clashes, attendees plan, and sponsors see the ecosystem's activity.

Implementation notes: store events in a normalised shape with a stable id so imports do not duplicate, generate an ICS feed (the feature that makes it actually used), and support corrections from organisers. ### Additional Pitfalls
- **Manual entry per event.** It becomes stale within weeks; automate sources.
- **No ICS or subscription.** A web page alone gets forgotten.
- **Duplicates from multiple sources.** Deduplicate on a canonical id.
- **No reminders.** The most useful notification is "the CFP closes in three days".
- **Ignoring time zones.** Remote events break without explicit zones.

### Real-World Deal-Breakers
- **No tech calendar** → members miss events because they didn't see the WhatsApp message.
- **No subscription** → members have to check multiple sources (Luma, LinkedIn, WhatsApp).
- **No partner events** → the calendar is React Kolkata-only. Members miss broader tech events.

### What a Learning Hub Is
A learning hub is a **curated, community-maintained collection of learning resources**. It answers: **"I want to learn X. Where do I start?"**

Unlike a generic resource list, the learning hub is **opinionated and structured**. It has learning paths, not just links.

### Learning Paths
```
Beginner Path:
1. React Fundamentals (official docs)
2. JSX and Components (talk: "React That Reacts")
3. Hooks (useState, useEffect)
4. Project: Build a Todo App

Intermediate Path:
1. State Management (talk: "React Query Is All You Need")
2. Performance Optimization
3. Testing (Vitest + RTL)
4. Project: Build a Dashboard

Advanced Path:
1. Server Components (talk: "Next.js 16 Cache Components")
2. Observability (talk: "Observability for React in Production")
3. Scaling (talk: "Scaling Frontend Development Between Teams")
4. Project: Contribute to React Kolkata's open-source repo
```

### Contribution Model
Any community member can submit a resource. Submissions are reviewed by a small group of maintainers. Approved resources are added to the learning hub with attribution.

### Additional Pitfalls
- **Uncurated link lists.** They age badly and teach nothing.
- **No exercises or outcomes.** Reading without practice does not build skill.
- **No owner.** Content rots; assign an editor.
- **Overwhelming scope.** A small, complete path beats a comprehensive half-built one.
- **Ignoring accessibility and offline use.** Docs should be readable on a phone, on a bus.

### Real-World Deal-Breakers
- **No learning hub** → new members don't know where to start. They ask "how do I learn React?" in the WhatsApp group and get 10 different answers.
- **No curation** → the hub becomes a link dump. Resources are outdated, broken, or low-quality.
- **No learning paths** → resources are unordered. Beginners don't know what to learn first.
- **No contribution model** → the hub is maintained by one person. It stagnates.

## 7.7 Referential Equality

### Subtopic Tree
- `Object.is` semantics
- Reference vs value comparison
- How React compares deps and props
- New object/array/function each render
- Stability of props
- `useMemo`, `useCallback` for stability
- `React.memo` shallow compare

### The Rule
React uses `Object.is` (similar to `===`, but `NaN === NaN` and `-0 !== +0`) to compare deps and props.

- **Primitives** → compared by value.
- **Objects/arrays/functions** → compared by reference.

```jsx
// Primitives: same value → considered equal
Object.is(1, 1);           // true
Object.is('a', 'a');       // true
Object.is(true, true);     // true

// Objects: different references, even with same content
Object.is({}, {});         // false
Object.is([], []);         // false
Object.is(() => {}, () => {}); // false
```

### Effect Deps Example
```jsx
function Component({ userId }) {
  const options = { id: userId }; // new object every render

  useEffect(() => {
    fetchData(options);
  }, [options]); // ❌ runs every render - new reference!
}
```

**Fix:**
```jsx
const options = useMemo(() => ({ id: userId }), [userId]);
useEffect(() => { ... }, [options]); // ✅ runs only when userId changes
```

Or destructure primitives into the deps:
```jsx
useEffect(() => {
  fetchData({ id: userId });
}, [userId]); // ✅
```

### `React.memo` Shallow Compare
```jsx
const Child = React.memo(({ user, onClick }) => { ... });

// Parent
<Child user={{ name: 'Alice' }} onClick={() => {}} />
// ❌ user and onClick are new references every render → memo never works
```

**Fix:**
```jsx
const user = useMemo(() => ({ name: 'Alice' }), []);
const handleClick = useCallback(() => {}, []);
<Child user={user} onClick={handleClick} /> // ✅ stable
```

### Real-World Deal-Breakers
- **Inline objects/arrays/functions as props** → break `React.memo`, run effects every render.
- **`useMemo` return used as dep** → stable only if the memo deps are stable.
- **Assuming `React.memo` compares deeply** → it's shallow.
- **Passing `style={{...}}` inline** → new object every render.
- **Context value object recreated each render** → all consumers re-render.

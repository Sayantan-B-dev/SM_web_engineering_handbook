## 1.7 DOM (Document Object Model)

### Subtopic Tree

### DOM Tree Structure
The DOM is a tree of nodes where every element, text node, and comment has a position and relationships to parent, children, and siblings. It is a **live, programmable representation** of the page that JavaScript can manipulate in real-time — it is **not** your HTML source.

### Core Operations
```javascript
// ✅ Create from top down, attach from bottom up
const table = document.createElement('table');
const tbody = document.createElement('tbody');

for (let i = 0; i < 3; i++) {
  const tr = document.createElement('tr');
  for (let j = 0; j < 2; j++) {
    const td = document.createElement('td');
    td.textContent = `Row ${i}, Col ${j}`;
    tr.appendChild(td);        // attach td to tr first
  }
  tbody.appendChild(tr);        // then tr to tbody
}
table.appendChild(tbody);       // then tbody to table
document.body.appendChild(table); // finally table to body
```
The pattern: **create elements top-down, attach children to parents bottom-up**.

### Real-World Tricks
- **`element.closest('.card')`** → walk up to nearest ancestor matching selector — perfect for event delegation.
- **`element.matches('.active')`** → check if element matches selector without querying.
- **`DocumentFragment`** → build offscreen, append once. Triggers a single reflow instead of N.
- **`classList.toggle('dark', isDark)`** → second arg forces add/remove state.
- **`el.dataset.userId`** → reads `data-user-id`. Setting `el.dataset.userId = '42'` writes it back.
- **`replaceChildren(...nodes)`** → clear and replace all children in one call.
- **`insertAdjacentHTML('beforeend', html)`** → parse HTML string and insert without destroying existing event listeners (unlike `innerHTML +=`).

### Real-World Deal-Breakers
- **Layout thrashing**: Reading `offsetHeight` in a loop, then writing styles, then reading again → forces synchronous reflow each iteration. **Read all, then write all.**
- **`innerHTML +=`** → destroys and recreates all children, losing event listeners and input state.
- **Querying in loops**: `for (...) { document.querySelector(...) }` → cache DOM references outside the loop.
- **`getElementsByClassName` returns a live HTMLCollection** → it updates as DOM changes; `querySelectorAll` returns a static NodeList. Know the difference.
- **`setTimeout` for animations** → use `requestAnimationFrame` for frame-synced updates.
- **Appending in a loop without fragment** → each append triggers reflow; use `DocumentFragment` and append once.

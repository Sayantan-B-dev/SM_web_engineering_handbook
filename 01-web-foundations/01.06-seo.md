## 1.6 SEO

### Subtopic Tree
- Title tag (50–60 chars, unique)
- Meta description (150–160 chars)
- Heading hierarchy (single H1, logical H2/H3)
- Semantic HTML structure
- Image alt text
- Open Graph tags (`og:title`, `og:description`, `og:image`)
- Twitter Cards
- Canonical URLs
- Structured data (JSON-LD, Schema.org)
- Core Web Vitals (LCP, FID/INP, CLS)
- Mobile-friendliness
- Crawlability & indexability

### SEO Checklist (Every Page)
- Title tag: 50–60 characters, unique, descriptive.
- Meta description: 150–160 characters, compelling.
- Single H1 describing main content.
- Logical heading hierarchy (H1 → H2 → H3, no skipping).
- Semantic HTML (`<header>`, `<main>`, `<nav>`, `<article>`, `<footer>`).
- Image alt text: descriptive, not "image1.jpg".

### Syntax Examples
```html
<head>
  <title>React Kolkata — Community & Learning Hub</title>
  <meta name="description"
        content="Join React Kolkata for meetups, workshops, and open-source contribution. Learn React, Next.js, TypeScript, and modern web development.">

  <!-- Open Graph (Facebook, LinkedIn) -->
  <meta property="og:title" content="React Kolkata — Community & Learning Hub">
  <meta property="og:description" content="Meetups, workshops, and open-source contribution.">
  <meta property="og:image" content="https://reactkolkata.com/og-image.jpg">
  <meta property="og:url" content="https://reactkolkata.com">

  <!-- Twitter Card -->
  <meta name="twitter:card" content="summary_large_image">
  <meta name="twitter:title" content="React Kolkata">

  <!-- Canonical -->
  <link rel="canonical" href="https://reactkolkata.com/">

  <!-- Structured Data -->
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Organization",
    "name": "React Kolkata",
    "url": "https://reactkolkata.com",
    "sameAs": ["https://twitter.com/reactkolkata"]
  }
  </script>
</head>
```

### Real-World Tricks
- **JSON-LD over Microdata** → easier to maintain, doesn't mix with visible markup, Google's preferred format.
- **`<link rel="preconnect">`** to critical third-party origins (fonts, analytics) → shaves 100–300ms off LCP.
- **Descriptive alt text as SEO signal** → Google uses alt text for image search ranking.
- **`hreflang` tags** for multi-language sites → prevents duplicate content penalties.

### Real-World Deal-Breakers
- **Multiple H1s** → confuses search engines about page topic.
- **Generic title tags** ("Home", "Page") → poor CTR, no keyword relevance.
- **Skipping heading levels** (H1 → H4) → breaks document outline, hurts accessibility and SEO.
- **Missing alt text** → images won't appear in image search; AT users get nothing.
- **Ignoring Core Web Vitals** → LCP > 2.5s, INP > 200ms, CLS > 0.1 directly affect rankings.
- **Client-side rendering without SSR/SSG** → crawlers may see empty HTML shell.
